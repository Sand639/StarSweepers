## ルール（エージェントに渡したもの。再開時も同じにする）

- **動作を変えない。** バグに気づいても直さず、下の「バグの疑い」に書き足す。
- **名前を変えないもの**：クラス名・ファイル名、enum の値、public / protected / internal のメンバー、`[SerializeField]` と public のフィールド（シーン・プレハブに名前で保存されている。`FormerlySerializedAs` も使わない）、Unity のメッセージ、RPC と `NetworkVariable`、`[MenuItem]`、`[Test]`、インターフェースのメンバー、`AssetDatabase` やオブジェクト名などの文字列。
- private メンバーを改名する前に、`grep -rn '"名前"' --include=*.cs` と `grep -rln 'm_MethodName: 名前' --include=*.unity --include=*.prefab --include=*.asset` で文字列参照（UnityEvent・`Invoke`・リフレクション・`FindProperty`）が無いことを確かめる。
- **他のメンバーが最後に編集したファイル（★）は、コメント追加と軽い整理だけ**（メソッド分割・private 改名はしない）。`git log -1 --format=%an -- ファイル` で確かめる。大槻さん・Claude Code 以外なら★。
- 新しいファイルを作らない・移動しない。**LangVersion 9**（C# 10 以降の構文は不可）。ファイル全体のフォーマットを変えない。既存のコメント（日付・経緯）を消さない。`Debug.Log`・`Header`・`Tooltip`・画面の文字列を変えない。
- コメントは既存の流儀（`Common/GamePause.cs` が見本）。日本語で、専門用語を避け、「何をするか」より「なぜそうしているか」。
- **ソースの編集は Read / Edit ツールで行う。** この環境では Bash に渡した `\\` が `\` に化けるので、sed / perl での置換は使わない。

## コンパイルの確かめ方（Unity を開かずに）

本体の Unity は開いたままでよい。本体が最後に開いたときの csproj を作業場所に写し、`Library` だけ本体のものを借りる。

1. 下の `fixcsproj.pl` を作業用フォルダ（scratchpad）に置き、Git Bash で実行する（**バックスラッシュを一切書かない**ために `chr(92)` を使っている）。

   ```perl
   # fixcsproj.pl : Library の相対パスを本体の絶対パスに、ProjectReference を DLL 参照に置き換える
   my $bs = chr(92);
   my $from = '<HintPath>Library' . $bs;
   my $to = '<HintPath>' . $ENV{ORIG_LIB} . $bs;
   my $refFrom = '<ProjectReference Include="Assembly-CSharp.csproj" />';
   my $refTo = '<Reference Include="Assembly-CSharp"><HintPath>$(RuntimeDllDir)' . $bs . 'Assembly-CSharp.dll</HintPath></Reference>';
   while (<STDIN>) {
       s{\Q$from\E}{$to};
       s{\Q$refFrom\E}{$refTo};
       print;
   }
   ```

   ```bash
   export ORIG_LIB='D:\010_GitHub\StarSweepers\StarSweepers\Library'
   cd /d/010_GitHub/StarSweepers-refactor/StarSweepers
   perl 作業用フォルダ/fixcsproj.pl < /d/010_GitHub/StarSweepers/StarSweepers/Assembly-CSharp.csproj > Assembly-CSharp.csproj
   perl 作業用フォルダ/fixcsproj.pl < /d/010_GitHub/StarSweepers/StarSweepers/Assembly-CSharp-Editor.csproj > Assembly-CSharp-Editor.csproj
   ```

   （csproj は `.gitignore` 済みなので作業場所に置いてもコミットされない。**本体の csproj より後に増えた .cs があれば `<Compile Include>` を手で足す**。2026/10/20 時点では 224 本すべて載っている。）

2. ビルドする（出力先を分ければ、複数のエージェントが同時に走らせても衝突しない）。

   ```bash
   OUT=作業用フォルダ/build/タグ
   dotnet build Assembly-CSharp.csproj -nologo -v:q -clp:ErrorsOnly -p:BaseIntermediateOutputPath="$OUT/obj-rt/" -p:OutputPath="$OUT/bin-rt/"
   dotnet build Assembly-CSharp-Editor.csproj -nologo -v:q -clp:ErrorsOnly -p:BaseIntermediateOutputPath="$OUT/obj-ed/" -p:OutputPath="$OUT/bin-ed/" -p:RuntimeDllDir="$OUT/bin-rt"
   ```

   初回は 2 分弱、2 回目からは 1 分ほど。エラーは `error CS` で grep する。
