# 使用素材とライセンス

外部から持ってきた素材（画像・音・BGM・効果音・フォント・Unityアセット・ライブラリ）を記録する場所。

> ⚠️ **素材を入手した時点で、その場で記入すること。**
> 展示直前にまとめて調べ直すのは非常に手間がかかり、出典が分からなくなった素材は**使えなくなる**。

## 書き方のルール

- 1素材につき1行。**改変した場合は、その内容も「条件・備考」に書く**（例：`色を変更して使用`）。
- **入手元は必ずURLで残す**。「ネットで拾った」は出典として使えない。
- **種別**は次から選ぶ … `画像` / `BGM` / `効果音` / `フォント` / `3Dモデル` / `Unityアセット` / `ライブラリ`
- ライセンスは正式名称で書く（例：`CC BY 4.0` / `CC0` / `Unity Asset Store 標準EULA` / `個人利用可・商用不可`）。
- **商用不可・クレジット表記必須・改変禁止**などの条件があれば「条件・備考」に必ず書く。
- 使えるか判断に迷う素材は、**使う前に**プロジェクトリーダー（デザイナー）に相談する。

> ⚠️ **フォントは特に注意。** 「表示に使うのは無料」でも、**ゲームに埋め込んで配布するには別の許諾が必要**なフォントが多い。
> 本作は本編ビルドを配布する予定のため、フォントを入れる前に必ずライセンス条文の「埋め込み（embedding）」の項目を確認すること。

## Unityパッケージ（標準機能）

Unity公式パッケージ（URP、Input System など `Packages/manifest.json` に記載のもの）は
Unityのライセンスに含まれるため、ここへの記載は不要。

外部から追加したアセット・ライブラリは**すべて上の表に記載する**こと。

> **2026/9/14時点で `StarSweepers/Assets/` の中を確認したところ、外部から持ってきた素材は入っていなかった。**
> マテリアル・シェーダー（`Glass.shader`）・プレハブはすべてAIがこのプロジェクト用に作ったもの。`Assets/Audio/` は空。
> `Assets/TutorialInfo/`（URPのアイコンなど）と `Assets/Settings/` は、**Unityで新しいプロジェクトを作ったときに最初から付いてくるもの**なので記載不要（本番で使わないなら、あとで Unity エディタ上で消してよい）。

## パソコンに入っているフォントを借りている件

ポーズ画面とレースの画面表示は、日本語を出すために**遊ぶ人のパソコンに入っているフォント**（游ゴシック・メイリオなど）を、再生したときに借りて使っている（`Assets/Scripts/Common/UiFont.cs`）。

- **フォントのファイルはゲームに入れていない**ので、いまの形なら配布しても「埋め込み」にはあたらない
- ただし、**そのフォントから TextMeshPro のフォント（`.asset`）を作ってゲームに入れると「埋め込み」になる。**
  游ゴシックやメイリオは Windows に付いてくるフォントで、**ゲームに入れて配ってよいとは限らない。**
  見た目を凝るためにフォントを作る場合は、**配布してよいフォント（Noto Sans JP など）を選び、この表に記載すること**

## 生成AIで作ったものの扱い

> 📄 **学校の公式ガイドラインが `Documents/作品制作およびAI活用ガイドライン.pdf` にある。**
> （学務室・企画本部発行。卒業制作展の作品制作ガイドライン）
> 以下はその要点だが、**判断に迷ったら必ずPDF本文を読むこと。**

### 学校のガイドラインの基本方針（3点）

| | 内容 |
| --- | --- |
| **1. 生成AIは「創作を支援するツール」** | AIが制作者の代わりに作品を作るツールではない。**生成結果をそのまま作品にせず**、自分で検討・編集・加工・検証したうえで使う |
| **2. 責任は制作者本人が負う** | 生成AIを使った場合でも、作品内容・著作権などの権利・倫理・社会的影響の責任は**すべて制作者本人**にある。ツールや第三者は責任を負わない |
| **3. 各サービスの利用規約を守る** | 生成AIサービスごとに規約や権利条件が異なる。**作品制作に使う前に、そのサービスの利用規約を必ず確認する** |

### このプロジェクトでの運用

| 対象 | 基準 |
| --- | --- |
| **デザイン・グラフィック** | 生成AIの出力をそのまま使用せず、**加工を施したうえで**使用する |
| **プログラム** | 担当者がそのコードの**意図と動作を説明できる状態**であれば使用してよい |

生成AIを使って作った素材も、**どのAIで作ったかを「条件・備考」に書く**こと（例：`生成AI（○○）で生成後、加工して使用`）。
使ったサービスの利用規約を確認したかどうかも、あわせて書いておくと後で困らない。

## 展示・掲載が認められない作品の条件

学校のガイドラインでは、次に該当すると判断された作品は**会場展示・学校HP・SNS等への掲載が認められない**。
素材を選ぶ時点で引っかからないよう、全員が把握しておくこと。

| 分類 | 該当するもの |
| --- | --- |
| **権利侵害のおそれ** | 第三者の著作権・商標権・肖像権などを侵害するおそれがあるもの／**他者の作品との類似性が高く、独創性に欠けるもの** |
| **誤認を招く** | 実在する人物・団体・企業について誤認を招く表現／虚偽または事実と異なる内容 |
| **人権・倫理上の問題** | 差別的表現／誹謗中傷／ハラスメントに該当するもの |
| **プライバシーの侵害** | 個人情報を含むもの／プライバシーを侵害するおそれがあるもの |
| **社会通念上不適切** | 公序良俗に反するもの／その他、学校が展示・掲載に不適切と判断したもの |

> 特に**「他者の作品との類似性が高く、独創性に欠けるもの」**は、生成AIを使うときに起こりやすい。
> 生成結果が既存の作品に似ていないか、使う前に確認すること。
