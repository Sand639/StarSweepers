## この機能は何か

**物資（点数になる箱）と爆発物を、マップのあちこちに次々と出す仕組み。**

以前は「決まった場所に最初から置いてあり、ゴールに入ったり爆発で消えたりすると、少しあとに元の場所へ戻ってくる」形だった。
これをやめて、**スポナー（出す係）が一定の間隔でランダムな場所に落とす**形にした。

- 物資と爆発物は、**物資5：爆発物1** の割合で出る（Inspector で変えられる）
- **マップにある数が100以上のときは出さない**
- **消えた物は戻ってこない。**ゴールに入った・爆発に巻き込まれた・場外に落ちた物は、そのまま削除される
- **勢いよく枠の外へ飛び出して下へ落ちた物は、自動で消える**

---

## 遊ぶ人から見た動き

| 場面 | どうなるか |
| --- | --- |
| 試合が始まる | 少し待ってから、**14個まとめて**マップに降ってくる |
| 試合中 | **1秒に1個**、ランダムな場所の少し上から降ってくる |
| マップに100個以上ある | 降ってこなくなる（減ればまた降り始める） |
| 物資をゴールに入れた | 点が入り、物資は消える（戻ってこない） |
| 爆発に巻き込まれた | 物資・爆発物とも消える（戻ってこない） |
| 枠の外へ飛び出して落ちた | 高さ -5m より下で消える |
| 試合が終わった（オンライン） | 降ってこなくなる |

降ってくる場所に、すでに物やプレイヤー・障害物があるときは、別の場所を探す。

## 設定できる値（インスペクターの項目）

シーンの **`FishingObjectSpawner`** を選ぶと変えられる。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Supply Prefab / Bomb Prefab | 出す物資・爆発物のプレハブ。**オンライン会場ではオンライン用を入れる** | ツールが設定 |
| **Supply Weight** | 物資の出やすさ | **5** |
| **Bomb Weight** | 爆発物の出やすさ | **1** |
| **Max Objects** | マップにこの数以上あったら出さない | **100** |
| Initial Spawn Count | 始まった直後にまとめて出す数 | 14 |
| Spawn Interval Seconds | 何秒ごとに1つ出すか | 1 |
| Start Delay Seconds | 始まってから出し始めるまでの秒数 | 0.5 |
| Area Half Size | スポナーの位置を中心に、X・Z それぞれ何mの範囲に出すか | 16 × 16 |
| Drop Height | 何mの高さから落とすか | 3 |
| Clear Radius | 出す場所の周りに、この半径で何かあったら避ける | 0.8 |
| Placement Tries | 空いた場所を探す回数 | 8 |

> **割合は「物資：爆発物」ではなく、それぞれの重みの比。**
> 爆発物を多くしたいなら Supply Weight を 1、Bomb Weight を 6 にすればよい。

プレハブ側（`HookableObject`）：

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Respawn Seconds | 消えてから元の場所に戻るまでの秒数。**スポナー用は0（戻らない）** | 0 |
| **Fall Vanish Height** | この高さより下に落ちたら消える | **-5** |

## 仕組み（分かる人向け）

- **数え方**：`HookableObject` が有効になったときに静的な一覧 `All` に自分を入れ、無効になったら抜ける。
  スポナーは `HookableObject.CountActive()`（消えかけの物を除いた数）で上限を判定する。
  スポナーが出した物だけでなく、**シーンに置いてある物資も数に入る。**
- **出す場所**：範囲内のランダムな点で、落とす高さから床の少し上まで `Physics.CheckCapsule` で調べ、
  何も無ければそこに出す。
- **オンライン**：出すのは**ホストだけ**（`NetworkManager.IsServer`）。`Instantiate` してから `NetworkObject.Spawn(true)`。
  試合が終わったら `FishingMatch.PlayAllowed` が false になるので出さない。
- **消し方（オンライン）**：参加者のPCで勝手に `Destroy` すると通信側がエラーになる。
  そこで `HookableObject.Vanish()` は、**見た目と当たり判定を消すだけ**にして、
  **ホストが `FishingNetSupply.ServerDespawnSoon()` で全員の画面から消し、1秒後に `Despawn`** する。
  - 1秒待つのは、爆発物を各PCがそれぞれ数えて爆発させているため。すぐ削除すると、
    少し遅れて数えている参加者の画面では**爆発する前に消えてしまう**。
  - 参加者のPCだけが「爆発に巻き込まれた」と判断した場合（位置のずれ）は、3秒待ってもホストに消されなければ見た目を戻す。
- **場外判定**：`HookableObject.Update()` で高さを見て、`Fall Vanish Height` より下なら `Vanish()`。

## できていないこと・既知の問題

- **再生しての確認がまだ。** コンパイルとシーンへの組み込みまでは、Unityを自動で動かして確認済み。
- **割合は「物資5：爆発物1」にしてある**（2026/9/16に、爆発物が多すぎたため入れ替えた）。
  多い・少ないを変えたいときは、Supply Weight と Bomb Weight の数字を変えるだけでよい。
- 物資が多いので、**点が入りやすく、マップが物資で埋まりやすい。** 遊んでみて多すぎれば、間隔（Spawn Interval Seconds）や上限（Max Objects）で調整する。
- オンラインで、**参加者が引っ掛けている最中の物が場外で消えた**場合、ホスト側の「誰が掛けているか」は消える直前に解除しているが、
  引っ掛けていた本人の画面の後始末は「物が消えた」扱い（フックが戻る）に頼っている。
- 範囲はスポナーの位置を中心にした四角。**ステージの形を変えたら Area Half Size も合わせる**こと（壁やゴールの中に出さないため）。
