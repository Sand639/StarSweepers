## この機能は何か

**狙っている場所・指している場所を、マウスでもコントローラーでも同じ「スコープレンズ」の絵で表す機能。**

- **Windows のカーソルはいつも隠す。** 代わりにスコープレンズを出す
- **遊んでいる間**：地面にスコープレンズが出る（前はコントローラーのときだけだった。マウスのときも出るようにした）
- **タイトル画面・ロビーの設定画面（マップ選びなど）・ポーズ画面**：画面にスコープレンズのポインターが出る。
  **コントローラーでも、マウスと同じように指して押せる**（前はロビーの設定画面はマウスでしか操作できなかった）

## 遊ぶ人から見た動き

### 画面（タイトル・ロビーの設定・ポーズ）

| 操作 | 結果 |
| --- | --- |
| マウスを動かす | ポインターがマウスの位置に動く。クリックは今までどおり |
| コントローラーの**右スティック** | ポインターが動く（マウスで最後に指していた場所から動き出す） |
| コントローラーの **LT**（左クリックと同じ）か **A** | ポインターの先を押す。押したまま動かすとスライダーを動かせる |
| コントローラーの**十字キーの上下** | ポインターの先の一覧をスクロールする |
| マウスを触る | マウスに戻る |

- 入力欄（名前・パスワード・数字）は、コントローラーで押すと選ばれる。文字はキーボードで打つ
- **B** で戻る・閉じるのは今までどおり

### 遊んでいる間

| 操作 | 結果 |
| --- | --- |
| マウス／右スティック | 地面のスコープレンズが動く（狙う場所） |
| マウスを左下のカメラのパネルなど（OnGUI の小さな枠）に重ねる | その間だけ、画面にポインターが出る（枠のボタンを押せるように） |

- 操作タイプ B（左スティックで向きを決める）のときは、指す場所が無いので地面には出さない

## 設定できる値（インスペクターの項目）

### `Resources/UiPointer.prefab`（UiPointer）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Pointer Sprite | ポインターの絵 | ScopeLens |
| Pointer Size | 大きさ（画面の高さ 1080 のときのピクセル） | 56 |
| Pointer Color | 色（白なら絵の色のまま） | 白 |
| Stick Speed | 右スティックを倒しきったときに1秒で動く量（画面の高さに対する割合） | 1.2 |
| Stick Dead Zone | これより小さい倒し方は無視する | 0.2 |
| Scroll Notches Per Second | 十字キーの上下で、1秒にどれだけスクロールするか（ホイールの目盛り） | 8 |

**決まり（変えると壊れる）**

- プレハブは **`Assets/Resources/` に `UiPointer` という名前**で置く（ゲームの開始時に名前で読み込む）
- シーンには置かない（置かなくても自動で1つ作られる。置いても2つ目は自分で消える）

地面のスコープレンズの絵と大きさは、プレイヤーのプレハブの `PlayerAimController`（Reticle Sprite・Reticle Size）で変える（`釣りフックの操作.md`）。

## 仕組み（分かる人向け）

- `UiPointer` は `RuntimeInitializeOnLoadMethod` でゲームの開始時に作られ、`DontDestroyOnLoad` でシーンをまたいで残る。
  毎フレームの最後（`LateUpdate`。実行順を一番後ろにしてある）に `Cursor.visible = false` にするので、ほかの画面がカーソルを出しても最後に隠れる
- **コントローラーで押せる仕組み**：コントローラー用に**見えないマウス**（Input System の Mouse 装置）を追加し、右スティックで位置を、LT／A で左ボタンを、十字キーでホイールを送っている。
  画面の部品は Input System の UI 入力（`InputSystemUIInputModule`）で動いており、**マウスが2つあっても1つのポインターとして扱う設定（初期設定）**なので、ボタン・入力欄・スライダー・スクロールが本物のマウスと同じように反応する
- 見えないマウスは、**画面のポインターを出している間だけ**作り、遊びの照準に戻ったら消す（`Mouse.current` が見えないマウスのままだと、照準がマウスの位置を読み違えるため）
- コントローラーで押している間は、**選ばれている部品（十字キーで選ぶ操作の選択）を外す**。外さないと、A でポインターの先と選ばれた部品の両方が押される。入力欄だけは外さない（選ばれていないと文字を打てない）
- 画面のポインターを出すかどうか：
  - 画面が開いている（`UiPointer.MenuActive`：タイトル・ロビーの設定・ポーズ）→ 出す。右スティックはポインターに使い、照準は動かさない
  - 遊びの照準が地面に出ている（`PlayerAimController` が毎フレーム `UiPointer.ReportGameplayAim()` で知らせる）→ 出さない。ただし本物のマウスが OnGUI の枠の上にあれば出す
  - どちらでもない（結果の画面など、照準を出していないとき）→ 出す。右スティックで動かして押せる
  - カーソルを画面に閉じ込めている（一人称視点の検証シーン）→ 出さない

## できていないこと・既知の問題

- **遊んでの確認がまだ。** とくに、コントローラーで押せるか（ボタン・入力欄・スライダー・マップの一覧のスクロール）と、エディタの Game 画面で位置がずれないか
- OnGUI の小さな枠（カメラのパネル・通信の様子など）は、**コントローラーでは押せない**（OnGUI は見えないマウスを読まないため）。マウスでは押せる
- 地面のスコープレンズは、狙いが地面に当たらない（空を指す）と消え、その間は画面のポインターが出る
- エディタで再生中は、Game 画面の上で Windows のカーソルが消える（ほかのウィンドウの上では出る）
