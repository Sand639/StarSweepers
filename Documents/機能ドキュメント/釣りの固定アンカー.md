## この機能は何か

釣り竿のフックを引っ掛けられる、ステージ用の固定ギミックです。

見た目は今は**青いキューブ**ですが、機能は `AnchorGimmick` という部品に分けてあるため、あとからモデルや大きさを変えても同じように使えます。釣り竿のチャージが大きいほど引っ張る速さが上がり、プレイヤーがアンカーの位置まで着くとフックが戻ります。移動中はプレイヤーの入力移動と重力を止めます。

| 場面 | 起きること |
| --- | --- |
| フックがアンカーに当たる | フックと糸がアンカーにつながる |
| 引っ張り中 | **アンカーは一切動かず、プレイヤーの入力移動と重力を止めてアンカーへ移動する** |
| プレイヤーがアンカー位置に着く | フックが外れて手元へ戻る |

通常の物資のような、引き寄せ・スキルチェック・投げる処理は行いません。

## 検証シーンの作り方・確かめ方

1. Unityで、スクリプトのコンパイルが終わるまで待つ。
2. メニュー **`Tools > StarSweepers > 釣りのアンカー検証シーンを作る`** を実行する。
3. `Assets/Scenes/Test/FishingAnchorTest.unity` が開く。
4. 再生し、青いキューブへ左クリック長押し→離すでフックを飛ばす。
5. アンカーが動かず、プレイヤーが青いキューブへ引っ張られたら成功。

検証シーンは製品のビルドには入れません。

## 見た目や動きを変えるには

`FishingAnchor.prefab` をUnityで開き、青いキューブの見た目を好きなモデルやマテリアルに差し替えられます。
その際、ルートにある `HookableObject`、`AnchorGimmick`、`Rigidbody` と当たり判定（Collider）は残してください。

`AnchorGimmick` の設定値は次のとおりです。

| 項目 | 意味 | 初期値 |
| --- | --- | --- |
| Pull Point | プレイヤーを寄せる先。空ならアンカーの中心 | 空 |
| Min Pull Speed | チャージ0のときの引っ張る速さ（m/秒） | 4 |
| Max Pull Speed | チャージ最大のときの引っ張る速さ（m/秒） | 16 |
| Stop Distance | この距離まで近づくと終了。プレイヤーが当たり判定に重なる場合は、安全に離れるため自動で広がる | 1.2 |

中間のチャージ量では、最小値と最大値の間で引っ張る速さがなめらかに変わります。たとえばチャージ50%なら、速さは最小値と最大値のちょうど中間です。

見た目の中心とは別の場所へ引っ張りたいときは、アンカーの子に空オブジェクトを作り、`Pull Point` に指定します。

## 仕組み

- アンカーは既存の `HookableObject` を持つため、釣りフックは通常の物資と同じ判定で引っ掛けられる。
- `AnchorGimmick` が付いた相手だけ、`ThrowController` は物資を動かす処理へ進まず、プレイヤーの `CharacterController` をアンカー方向へ動かす。
- アンカーの `Rigidbody` はキネマティックかつ全方向固定で、物理的な力でも動かない。
- プレイヤーを `CharacterController.Move` で動かすため、壁などの当たり判定は通常の移動と同じように働く。
- プレイヤーがアンカーまで移動している間は重力を止め、到着または引っ張りの中断時に重力を戻す。
- アンカーへ移動している間はプレイヤーの通常の入力移動も止め、到着または中断時に再開する。
- アンカーの当たり判定とプレイヤーの大きさから、めり込まずに止まれる距離を計算する。到着後にアンカーから離れられなくなるのを防ぐ。
- 壁やアンカーの当たり判定でプレイヤーが進めなくなった場合は、引っ張りを終えて通常操作を戻す。

## 既知の注意

- 壁との間など、プレイヤーが入れない場所にアンカーを置くと、途中で引っ張りが終わることがある。プレイヤーが通れる場所に置く。
- オンライン対戦用の位置同期は未対応。オンラインのマップへ置く前に、全員に同じ引っ張り結果を配る方法を決める必要がある。
