## この機能は何か

**液体の糸（フック）が物資にくっつくと、くっついた所から液体が左右2本に分かれて物資のふちを回りこみ、約0.5秒で反対側で合わさって、物資をぐるっと「液体の枠」で囲う演出。**
「この物資を確保した」と一目で分かるようにするためのもの。

- 枠は外から**きゅっと締めつける**ように縮みながら回りこみ、閉じた瞬間に**ぷるんと揺れて、合わさった所からしぶき**が飛ぶ
- つかんでいる間は、枠が物資についていき、**波打ちながら流れ続ける**（ときどき、しずくが落ちる）
- はなす（投げる・糸が消える・物資が消える）と、**枠が外へはじけて消える**
- 枠の色は、つかんだあとの糸の色（チームの濃い色）と同じ

枠は**いつもカメラのほうを向いた面**に描く。どの角度から見ても枠に見え、**物資の見た目の大きさに合わせて**形（角の丸い四角）が変わる。細長い物には細長い枠になる。

形はプログラムで毎フレーム作っている（外部の素材は使っていない）。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| フックで物資をつかむ | 糸の色が先端から濃く染まるのと同時に、物資のまわりを液体が回りこみ、約0.5秒で枠が閉じる |
| つかんだまま引き寄せる | 枠が物資についてくる |
| 投げる・はなす | 枠がはじけて、しぶきが飛ぶ |

### 検証シーン `LiquidBeamTest.unity` で試す（シーンの作り直しは不要）

| 操作 | 結果 |
| --- | --- |
| F を長押しして離す | 液体のビームを撃つ（出しっぱなし） |
| **G** | **先端に箱をくっつけて、液体の枠で囲う**（箱はくるくる回るので、枠が形に合わせて変わるのも見られる）。もう一度 G で、はなす（枠がはじける） |
| F（流れが出ている間） | 流れを止める。箱もはなす |

フックで試すなら、釣りや宇宙ごみ集めのシーン（`FishingHookTest.unity` など）でそのまま物資をつかめばよい。

## 設定できる値（インスペクターの項目）

枠そのものは実行時に作るので、インスペクターでは**値を変えられない**（いまは `LiquidWrap.cs` の初期値を書き換える）。
フック側（`HookLine`）で変えられるのは次の3つ。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Use Wrap | オンなら、物資をつかんだときに枠で囲う（Use Liquid がオンのときだけ） | オン |
| Wrap Search Radius | つかんだ物資を探す範囲（フックの先からの距離。m） | 0.8 |
| Wrap Max Size | これより大きな物（大きな板など）は囲わない（m）。物資（HookableObject）には効かない | 5 |

`LiquidWrap.cs` の主な値（目安）：

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Wrap Seconds | くっついてから枠が閉じるまでの時間（秒） | 0.5 |
| Start Scale | 囲い始めの枠の大きさ（何倍か）。外から締めつけて見える | 1.3 |
| Width / Highlight Width | 枠の太さ／真ん中の明るい筋の太さ（m） | 0.14 / 0.035 |
| Squareness | 枠の形（2 で楕円、大きいほど四角） | 3.5 |
| Padding | 物資のふちから枠までのすき間（m） | 0.18 |
| Close Squeeze | 閉じた瞬間にぷるんと縮む強さ | 0.08 |
| Wobble / Bulge | 枠が波打つ大きさ（m）／太さのムラ | 0.04 / 0.35 |
| Burst Seconds / Burst Scale | はじけて消えるまでの時間（秒）／どこまで広がるか（倍） | 0.3 / 1.5 |

## 仕組み（分かる人向け）

- **状態**：待機 → 回りこみ（`Wrapping`）→ 閉じている（`Held`）→ はじける（`Bursting`）→ 待機
- **何をつかんだか**：`HookLine.SetGrabbing(true)` の瞬間に、フックの先の近くから探す。物資（`HookableObject.All`）を優先し、無ければ `Physics.OverlapSphere`（自分の体とフックの先は除く）。
  **ほかの人のフックには「何をつかんだか」が通信で届かない**ので、自分のときも同じ探し方にしてある（どの画面でも同じように枠が出る）
- **大きさ**：毎フレーム、物資の `Renderer.localBounds` の8つの角をカメラの右・上・前の向きへ投影して、縦横の大きさを測る（物の向きに沿った箱なので、回転しても大きさががたつきにくい。さらに少しなめらかに追いかける）。
  枠は**物資のいちばん手前（カメラ側）の深さ**に置く（真ん中だと物資の手前側に隠れることがあるため）
- **形**：スーパー楕円（`x = sign(cos)·|cos|^(2/n)`）。n＝Squareness。くっついた所の角度は、その逆の式で求める
- **回りこみ**：くっついた角度から左右へ `π × 進み具合` だけのびた**開いた線**を1本の `LineRenderer` で描く。進み具合は `1 − (1 − t)²`（最初は速く、合わさる直前はゆっくり）。両端は太くふくらませる。
  回りこんでいる途中は、分かれ目が**糸の先（`SetContactPoint`）についていく**ので、糸と枠がつながって見える
- **閉じたあと**：`LineRenderer.loop` で1周の輪にする。波と太さのムラは**角度の整数倍の sin** で作るので、1周してもつなぎ目がずれない
- **しぶき**：液体のビームと同じ作りの `ParticleSystem`（ワールド基準・重力あり）を `Emit` で出す
- **見た目の素材**：液体のビームと同じマテリアル（`LiquidBeam.LineMaterial`）と質感のテクスチャ（`LiquidBeam.LiquidTextures`）を使う

## できていないこと・既知の問題

- **人がまだ再生して確かめていない。**（AIはコンパイルと、画面なしで起動した Unity の静止画で見た目だけ確認した。動き・ブルームの光り方は未確認）
- 枠の細かい値はインスペクターで変えられない（`LiquidWrap` を実行時に作っているため）。調整したくなったら、`LiquidWrap` をプレハブにして `HookLine` に入れる形にする
- 物資の見た目に `Renderer` が無い場合は当たり判定の箱、どちらも無ければ 1m の箱として囲う
- `Physics.OverlapSphere` で探すとき、「自分の体」は `transform.root` の下にある物として除いている。プレイヤーがマップ全体の親の下に置かれていると、物資以外（大きな板など）は見つからなくなる（物資は `HookableObject.All` から探すので影響しない）
- 物資を投げたあとに別の物資をすぐつかむと、前の枠がはじける途中でも、新しい物資の枠に切り替わる
