## この機能は何か

**踏むと合図を送るボタン**と、**その合図で上下する壁**の2つ。

ボタンは土台の上に赤いボタンが乗った形で、

- **上に乗るとボタンが沈み、合図が1回送られる**
- **降りるとボタンが浮き上がる**
- **浮き上がりきるまでは、もう一度踏んでも合図は送られない**（沈みはする）
- **浮き上がったあとに踏めば、また合図が送られる**

**ボタンは「何を動かすか」を知らない。** 動かす相手はインスペクターで選ぶ。
そのため、**扉を開ける・音を鳴らす・敵を出すなど、何にでも使い回せる。**
今回はその相手として「上下する壁」を一緒に作ってある。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ボタンの上に乗る | **ボタンが沈み、壁が動く**（下がる） |
| 乗ったまま動かない | **何も起きない。** 合図は乗った瞬間の1回だけ |
| ボタンから降りる | **ボタンがゆっくり浮き上がる。** 浮くまでの間、ボタンの色は暗いまま |
| 浮き上がる前にもう一度踏む | **沈むが、合図は送られない**（色が暗いのが目印） |
| 浮き上がったあとに踏む | **また合図が送られる**（壁がもう一度動く。今度は上がる） |

- **押せるのはロボットだけではない。** 持てる箱を乗せても押せる。
  **箱を乗せっぱなしにすれば、押しっぱなしにできる**
- **合図を受けた壁は、踏むたびに上下が入れ替わる**（下がる → 上がる → 下がる …）

## ステージに置く手順

Unityのメニューから置ける。**手で組み立てる必要はない。**

1. 置きたいシーンを開く
2. シーンビューを、置きたい場所の近くまで動かす
3. メニューの **`Tools > StarSweepers > アーカイブ > ロボットステージ > 踏むボタンと動く壁を置く`** を実行

**ボタンと壁が繋がった状態**で置かれるので、そのまま再生すれば動く。
壁はボタンの4m先に立つので、位置は好きに動かしてよい。

### 別の物を動かしたいとき

ボタンの **`Pressed`** の欄が「踏まれたときにすること」。
ここに**動かしたい物を入れて、呼びたい機能を選ぶ**だけでよい。

| やりたいこと | 選ぶもの |
| --- | --- |
| 壁を上下させる | 壁を入れて `MoveObject > Toggle()` |
| 壁を下げるだけ（戻さない） | 壁を入れて `MoveObject > Open()` |
| 止めてある機能を動かす | ボタンの `Toggle Objects` にその物を入れる（出し入れが切り替わる） |
| プレハブを出す | ボタンの `Spawn Prefab` にプレハブを入れる |

**`Pressed` には、いくつでも繋げられる。** 壁と音と演出を同時に動かすこともできる。

## 設定できる値（インスペクターの項目）

### ボタン（`PressButton`）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Button Visual | 沈む赤い部分。土台ではないほう | 自動で入る |
| Detect Size | 反応する箱の大きさ（この中に物が入ると踏まれた扱い） | 1.2 × 0.5 × 1.2 |
| Detect Offset | 反応する箱の位置 | (0, 0.45, 0) |
| Detect Mask | 反応させたい物の種類 | すべて |
| Press Depth | どれだけ沈むか（m） | 0.07 |
| Press Time | 沈みきるまでの時間（秒） | 0.08 |
| **Rise Time** | **浮き上がるまでの時間（秒）。この間は合図が出ない** | 0.8 |
| Dim While Used | 合図を送れない間、色を暗くするか | ON |
| Used Color | 暗くするときの色 | 暗い赤 |
| Pressed | **踏まれたときにすること** | 空 |
| Ready Again | また踏めるようになったときにすること | 空 |
| Toggle Objects | 踏まれたときに出し入れする物 | 空 |
| Spawn Prefab / Spawn Point | 踏まれたときに出すプレハブと、その場所 | 空 |

> **連打できない間隔は `Rise Time` で決まる。** 長くすると、踏み直すまでの待ちが長くなる。

### 動く物（`MoveObject`）

**壁専用ではない。** 位置だけでなく、**回転と大きさも変えられる**ので、
扉・足場・仕掛けなど、動いてほしい物なら何にでも付けられる。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Move Time | 動き終わるまでの時間（秒） | 1.2 |
| Start Open | 最初から開いた状態で始めるか | OFF |
| **Position Offset** | 開いたときに**どれだけ動くか**（差分） | (0, −3.2, 0) |
| Position Result | 開いたときの**位置そのもの** | 自動で計算 |
| **Rotation Offset** | 開いたときに**どれだけ回るか**（度・差分） | (0, 0, 0) |
| Rotation Result | 開いたときの**角度そのもの** | 自動で計算 |
| **Scale Offset** | 開いたときに**どれだけ大きさが変わるか**（足し算） | (0, 0, 0) |
| Scale Result | 開いたときの**大きさそのもの** | 自動で計算 |

**位置・回転・大きさは同時に使える。** 回りながら縮む、なども作れる。

| 設定 | 動き |
| --- | --- |
| 位置 (0, −3, 0) | **床に沈む壁** |
| 位置 (3, 0, 0) | **横にスライドする扉** |
| 回転 (0, 90, 0) | **横に90度開く扉**（蝶番のように開く） |
| 大きさ (0, −3, 0) | 縦に縮んで消える壁 |

> **回転で開く扉を作るときは、扉の「軸」の位置に気をつけること。**
> 物の中心を軸に回るので、蝶番のように開かせたい場合は、
> **空の物を蝶番の位置に置いて、その子に扉を入れ、親のほうを回す。**

#### 「差分」と「変更後の値」の2つの欄

位置・回転・大きさには、それぞれ**2つの欄**がある。
**どちらかを入れると、もう一方が自動で計算される。** 好きなほうで入力すればよい。

| いまの値 | 入れた欄 | 入れた値 | もう一方 |
| --- | --- | --- | --- |
| 位置X = 10 | **差分** | −2 | 変更後 = **8** |
| 位置X = 10 | **変更後** | −2 | 差分 = **−12** |

**実際に動くときに使っているのは「差分」のほう。**
そのため、**物を置き直しても同じだけ動く**（プレハブを別の場所に置いても同じ動きになる）。
物を動かすと「変更後の値」のほうが計算し直される。

## 仕組み（分かる人向け）

### 「重なっているか」で判定している

`OnTriggerEnter` のような**ぶつかった合図は使っていない。**
**毎フレーム、ボタンの上の箱の中に物があるかを調べている**（`Physics.OverlapBoxNonAlloc`）。

合図に頼ると、乗っている物が消えたり、当たり判定が切られたりしたときに
**「乗ったまま」で固まってしまう。**
通信の実装でも同じ失敗をしているので、同じ考え方を採っている。

**赤いボタンには当たり判定を付けていない。**
付けると、沈むたびに乗っている物を押し上げてしまうため。
当たり判定を持つのは土台だけ。

### 合図が出る条件

沈み具合を 0〜1 の数で持っていて、乗っている間は1へ、降りている間は0へ動かしている。

**合図が出るのは「乗った瞬間」かつ「送れる状態」のときだけ。**
送ると「送れない状態」になり、**沈み具合が0に戻ったとき**にまた送れるようになる。

つまり **`Rise Time` がそのまま「次に押せるまでの時間」**になる。
浮き上がる前に踏み直すと、沈み具合は1へ戻るが、送れる状態には戻らない。

### 何を動かすかを知らない作り

ボタンは `UnityEvent`（インスペクターで繋ぐ仕組み）で相手を呼んでいる。
**相手の型を一切知らない**ので、あとから作る機能にもそのまま使える。

> このプロジェクトで `UnityEvent` を使ったのは、この機能が初めて。
> 「Aを踏んだらBが動く」を**コードを書かずに繋ぎ変えられる**ため、
> ステージのギミックには向いている。

## できていないこと・既知の問題

- **まだ実際に遊んで確かめていない。** 沈み具合や、浮き上がるまでの時間は調整前の値
- **動く壁の上に乗っている物は、一緒に運ばれない。**
  ロボットは `CharacterController` で動いているので、床が動いても付いてこない。
  「壁に乗って上がる」遊びをしたい場合は、別の作りが要る
- **壁が閉じるときに、間に物がいても止まらない。** そのまま押し込む（めり込む）
- **ボタンの上に物を置いたままにすると、押しっぱなしになる。**
  遊びとして使えるが、意図せず置いてしまうと壁が開かなくなる
- **合図は「乗った瞬間」の1回だけ。** 「乗っている間ずっと」は今の作りでは出せない
  （必要なら `Ready Again` と組み合わせるか、作りを足す）
- 通信（マルチプレイ）には**未対応**。いまは1人用の作り
