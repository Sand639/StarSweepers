## この機能は何か

**通信が遅れて、状態がずれたまま残るのを防ぐ仕組み。**

通信の知らせ（「引っ掛けた」「離した」など）は必ず届くが、**遅れて届くと、そのとき相手の準備ができておらず、ずれたまま残る**ことがある。
原因が何であっても、ずれが残り続けないように、**決まった区切り・1秒ごとに答え合わせをして直す。**

決まりは3つ。

| 決まり | 理由 |
| --- | --- |
| **ホストが正しい** | 両方が直し合うと、ずれが行ったり来たりするため。参加者はホストの記録に合わせる |
| **続けてずれていたときだけ直す** | 引っ掛けた直後など、知らせが届く途中の一瞬のずれまで直すと、かえっておかしくなるため |
| **直したら必ずログを出す**（`[NET][答え合わせ]` で始まる） | 黙って直すと、本当の原因（どこで取りこぼしているか）が見えなくなるため |

## 答え合わせの一覧

| # | 確かめること | 誰のPCで・いつ | ずれていたら |
| --- | --- | --- | --- |
| 1 | **物の引っ掛け**：ホストの記録では自分が引っ掛け中なのに、手に持っていない | 本人のPC・1秒ごと | ホストへ「離した」を送り直す（爆発の回数が食い違っていても受け付ける） |
| 1 | 〃：手に持っているのに、ホストの記録では別の人・誰でもない | 本人のPC・1秒ごと | 自分の引っ掛けを外す |
| 1 | 〃：引っ掛けた人がもういない | ホスト・1秒ごと | 外す |
| 1 | 〃：物の持ち主（物理を動かす人）と、引っ掛けた人が食い違う | ホスト・1秒ごと | 引っ掛けた人を持ち主にする |
| 1 | 〃：「引っ掛け中」に見える物が、実は自分の引っ掛け | フックが当たったとき | **つかみ直してよい**（前はフックがはじかれ、本人もつかめなかった） |
| 2 | **席（チーム）**：抜けた人の席が残っている／席の無い人がいる | ホスト・1秒ごと | 消す／作る |
| 3 | **マップに移ったときの場所** | 本人のPC・シーンを読み込んだとき | 下の「3の詳しい動き」 |
| 4 | **動けなくなっていないか**：動けるべきなのに動けない／止まっているべきなのに動ける | 本人のPC・1秒ごと | 「動けるべきか」に合わせる |

### 3の詳しい動き（マップに移ったときの場所）

前は「シーンを読み込んでから2フレーム待って置き直す」決め打ちだった。通信が遅いと、その時点ではまだ**自分のチーム・ゴールの持ち主**が届いておらず、**ゴールが無いとき用の場所（中心のまわり）に置かれ、ドーナツの穴や床の無い帯の上だと落ちていた。**

今はこう動く。

1. シーンを読み込んだら、**その場で止めて待つ**（動けない・落ちない）
2. ラウンドの係と**自分のチームのゴール**が届いたら、ゴールの近くに置く
3. **4秒待っても届かなければ、床がある所を探して置く**（ログが出る）
4. そのあと6秒以内にゴールが届いたら、ゴールの近くへ置き直す（ログが出る）

ゴールが無いとき用の場所も、**真下に床があるかを確かめて**から使うようにした（無ければまわりを順に探す）。

### 4の「動けるべきか」

| 状態 | 動けるか |
| --- | --- |
| マップに移って置き直しを待っている | 動けない |
| 復活待ち（R キー・落下のあと3秒） | 動けない |
| ラウンド中 | 動ける |
| ラウンドの結果発表中 | 動けない |
| ロビーで、ホストが設定端末を開いている | 動けない |
| それ以外のロビー | 動ける |

スタンは「残り時間」で止めているので、ここでは見ない（時間が過ぎれば自然に戻る）。
