## この機能は何か

**乗っている人と物を、決まった向きに運ぶベルトコンベア。** 一定時間ごとに向きが逆になるようにもできる。
これを使ったステージを2つ作ったが、**いま残っているのは STAGE_06（もとの A）だけ**。

| ステージ | 設計 | 中身 |
| --- | --- | --- |
| **STAGE_06**（もとの STAGE_06_A。ベルトコンベアA） | **大槻さん**（イラレの図。1m＝10px。**2026/10/6 に SVG で小さく作り直した**） | **42m×42m** の床。外の赤いスポナーから素材が流れ込み、ベルトでぐるっと運ばれて、**床の無い帯（幅4.5m）へ落ちる**。帯の中を**動く壁**（7.5m×3.75m）が左右に10.5mずつ動き、落ちる物を受け止めたり通したりする。180度回すと同じ形。ベルトの向きは**変わらない** |
| ~~STAGE_06_B~~（**削除済み**。記録として残す） | Claude Code の案 | 44m×30m の床。**真ん中に東西向きのベルト**（8秒ごとに向きが入れ替わり、素材が自陣や敵陣のゴールへ運ばれる）。**北と南に外へ向かうベルト**（物を場外へ落とす。真ん中と4秒ずらして向きが変わる） |

素材5種類に加えて**スタン爆弾**が出る（最大の数は下の「スポナーの設定」）。

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| ベルトの上に立つ・物が乗る | ベルトの向きに運ばれる（秒速4m）。物資は**転がらずに、ベルトと一緒に滑って**進む（2026/11/4 から） |
| まっすぐのベルトの先に、横向きのベルトを置く | 物資は横のベルトに乗り移ると、前の向きの勢いが消えて**横へまっすぐ流れる**（2026/11/4 から。前は転がる勢いで前へ進み続けて不自然だった） |
| 重心が偏った物・段差・ぶつかる | 傾く・倒れる・回る動きは、前と同じように物理のまま起きる |
| 向きが逆になる1.5秒前 | ベルトの帯（横の筋）が**黄色く点滅**して予告する |
| ベルトの端から先に床が無い | 運ばれた物・人は落ちる（人は高さ -8m で戻る。物は消えて補充される） |

- 帯が流れて見えるので、どちらへ流れているか一目で分かる

## 使い方

プレハブ **`Assets/Prefabs/SpaceJunk/Gimmick/ConveyorBelt.prefab`** を置く。

- **置いた場所がベルトの上面の真ん中。** 置いた物の青い矢印（Z）の向きに流れる。シーン画面では黄色い矢印で見える
- 東へ流すなら Y 回転 90、南は 180、西は 270
- 床と同じ高さに置くと見た目がちらつくので、**床より少し上（0.05m）**に置いている

動く壁は **`Assets/Prefabs/SpaceJunk/Gimmick/MovingWall.prefab`**（釣りの `MovingObstacle` を使用。**プレハブの初期値は**置いた場所から左右に14mずつ動く。STAGE_06 では10.5mずつに変えてある。道すじは Points で変える）。

## 設定できる値（SpaceJunkConveyor）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Speed | 流れる速さ（m/s）。マイナスにすると最初の向きが逆 | 4 |
| Reverse Interval Seconds | 何秒ごとに向きが逆になるか。**0 なら逆にならない**（STAGE_06 は 0） | 8 |
| Warning Seconds | 逆になる何秒前から予告するか | 1.5 |
| Time Offset Seconds | 逆になるタイミングをずらす秒数 | 0 |
| Item Grip | 物資をベルトの速さに合わせる強さ | 6 |
| Carry Height | ベルトの上面から、どの高さまでを「乗っている」とみなすか | 1.2 |
| Belt Size | 大きさ（幅・厚み・長さ）。当たり判定・見た目・帯の数が自動で合う | (4, 0.5, 20) |
| Slat Spacing / Slat Color / Warning Color | 帯の間隔・色・予告の色 | 1.5 / 灰 / 黄 |

## スポナーの設定（SpaceJunkSpawner。2026/10/6 に作り直した）

**出す物は「Spawn List」の1つのリストにまとめた。** 素材も爆弾も、プレハブと出やすさを並べるだけ。インスペクターの ＋／− で足したり消したりできる。

| 項目名 | 意味 | STAGE_06 の値 |
| --- | --- | --- |
| Spawn List | 出すプレハブと出やすさ（Weight）の一覧。出やすさは**ほかとの割合**（全部 1 なら同じくらい） | 素材5種類（各 1）＋スタン爆弾 `FishingOnlineBomb`（1.25 ＝ だいたい5回に1回） |
| Max Bombs | マップの爆弾がこの数以上なら、爆弾は選ばない（素材の Max Objects とは別に数える） | 5（大槻さんが調整） |
| Max Objects / Initial Spawn Count / Spawn Interval Seconds | 素材の最大数・最初にまとめて出す数・何秒ごとに出すか | 16 / 4 / 2.5（大槻さんが調整） |
| **Cycle Zones** | **ON：Spawn Zones に1回ずつ出すのを1巡とする**（1巡ごとに順番をシャッフル。テトリスの7種1巡と同じ）。OFF：毎回ランダムなゾーン（広いゾーンほど出やすい） | **ON** |

- 1巡法で、選ばれたゾーンが埋まっていて出せなかったときは、そのゾーンを次の回に回す（1巡の中で抜けが出ない）
- 1巡法が効くのは **Spawn Zones が2つ以上**のとき。種類ごとの範囲（Kind Zones）には効かない
- **前の書き方（3種類＋追加の素材＋爆弾の確率）のシーンは、自動で Spawn List に移し替える。** シーンを開くとインスペクターでも新しいリストで見え、保存すると新しい書き方で残る。爆弾の確率は、同じ割合になる出やすさに直す

## 仕組み（分かる人向け）

- ベルトは通信しない。**`NetworkManager.ServerTime.Time` から、いまの向きを各PCが計算する**（列車・回転する床と同じ）
- プレイヤーは `CharacterController.Move` で運ぶ（自分のPCで動かしている人だけ）。物資は `FixedUpdate` で、ベルトの速さとの差のぶん `AddForce(VelocityChange)` する（物理を動かしているPCだけ。ほかのPCでは Is Kinematic なので何もしない）
- 帯は再生したときに作る（当たり判定なし）。帯の色は土台のマテリアルを複製して変えている
- **物資を転がさない仕組み（2026/11/4）**：前は止まっている床の上で物資だけを押していたので、底が床にこすれて転がりながら進んでいた。
  - 再生したときに、ベルトに**動かない Rigidbody（Is Kinematic）**を付ける（プレハブ・シーンは書き換えていない）。物理の更新ごとに、ベルトを一度うしろへ戻してから `MovePosition` で元の場所へ動かす。**位置は変わらないが、物理の計算ではベルトの面が流れる速さで動いている**ことになり、底がこすれない
  - 物資の速さは、流れる向きだけでなく**ベルトの面に沿った向きぜんぶ**をベルトの速さに合わせる（上下は物理に任せる）。重心に力をかけるので回る勢いは変わらず、**重心の偏り・段差・衝突で回る動きは残る**
  - 画面なしの Unity で、L字に置いた2本のベルトに箱と燃料（`SpaceJunkFuel`）を乗せて試した：まっすぐの間は回転がほぼ 0 のまま秒速4mで進み、横のベルトに乗り移ってから約0.5秒で横向きの秒速4mになり、横のベルトから落ちずに流れた（エラーなし）
  - ほかの部品（ボットの床探し・スポナーの床探し）は「Is Kinematic の Rigidbody は床」とみなしているので、ベルトに Rigidbody が付いても床のまま

## できていないこと

- STAGE_06 には、**特殊デブリ（高得点）はまだ置いていない**
- ステージの見た目（色・飾り）は仮
