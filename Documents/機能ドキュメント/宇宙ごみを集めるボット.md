## この機能は何か

**プレイヤーの代わりに、宇宙ごみ（素材）を集めて自分のチームのゴールへ運ぶコンピューターのキャラクター。**
人数が足りないときの穴埋め役を想定した、最初の簡易版（大槻さんの依頼。「最初は簡易的なものでよい」）。

ボットは次のくり返しで動く。

1. いちばん近い素材へ歩いていく
2. 手が届いたら**頭の上に持ち上げる**
3. 自分のチームのゴールへ歩き、近くまで来たら**山なりに放り込む**
4. 1 に戻る

点の入り方はプレイヤーが入れたときと同じ（ゴールの中に少しいつづけたら1点）。

## 遊ぶ人から見た動き

| こんなとき | ボットはどうするか |
| --- | --- |
| ラウンド中 | 近くの素材を拾って、自分の色のゴールへ放り込み続ける |
| ラウンドの始まりの演出中・ラウンドの合間 | 止まる（持っている素材はその場に落とす） |
| ボットが持っている素材を、プレイヤーがフックで引っ掛けた | **横取りできる。** ボットは手を離し、次の素材を探しに行く |
| ゴールのすぐ近くにある素材 | 拾わない（もうすぐ点になる物を持ち出さないため） |
| 重いデブリ（イベントの特殊デブリ） | 拾わない |
| 壁や穴で進めなくなった | しばらくその素材をあきらめて、別の素材を探す |
| 下まで落ちた | 最初に置いた場所へ戻る |

### 試し方

1. Unity のメニュー **`Tools > StarSweepers > 宇宙ごみのボット > 検証シーンを作り直す`** を押す
   （ボットのプレハブが無ければ、先に自動で作られる）
2. できた `Assets/Scenes/Test/SpaceJunkBotTest.unity` を再生する
3. 青と赤のボットが、箱（素材）を頭に乗せて、自分の色の丸い印へ放り込めば成功

> 検証シーンのゴールは**ただの印**なので、点は数えない（箱は印の上にたまっていく）。
> 点が入るかどうかは、マップに置いてタイトルから遊んで確かめる（下の「マップに置く」）。

### マップに置く（ゲームで試す）

1. 置きたいマップ（例：`Stage/STAGE_01.unity`）を開く。**人と共有しているマップなので、触る前に Discord で一声かける**
2. シーンビューで置きたい場所を見ながら、**`Tools > StarSweepers > 宇宙ごみのボット > 開いているシーンに置く`** を押す
3. インスペクターで **Team**（0=青 / 1=赤 / 2=緑 / 3=黄）を決めて、`Ctrl+S` で保存
4. `MainScene/TitleScene.unity` から遊ぶ

## 設定できる値（インスペクターの項目）

`SpaceJunkBot` の項目。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Team | どのチームのゴールへ運ぶか（**決まり：0=青 / 1=赤 / 2=緑 / 3=黄**）。そのチームのゴールが無いマップでは、持ったまま待つ | 0 |
| Goal Override | ゴールを直接決める（検証シーン用）。入っていれば Team に関係なくここへ運ぶ。**マップでは空にしておく** | 空 |
| Body Renderer | チームの色に塗る見た目 | プレハブの Body |
| Move Speed | 歩く速さ（m/秒） | 3.5 |
| Turn Speed | 向きを変える速さ（度/秒） | 540 |
| Pickup Distance | 素材にここまで近づいたら持ち上げる（m） | 1.6 |
| Carry Height | 持ち上げた素材の高さ（足元から、m）。低くしすぎると体にめり込む | 2.6 |
| Ignore Near Goal Distance | ゴールからこの距離より近い素材は拾わない（m） | 2.5 |
| Throw Distance | ゴールまでこの距離に来たら投げる（m） | 4 |
| Throw Horizontal Speed | 投げた素材の横向きの速さ。小さいほど高く山なりに飛ぶ | 6 |
| After Throw Pause | 投げたあと、次を探し始めるまでの秒数 | 0.6 |
| Stuck Seconds | この秒数のあいだ近づけなかったら、その素材をあきらめる | 3 |
| Give Up Seconds | あきらめた素材を、また狙うまでの秒数 | 6 |
| Fall Reset Height | この高さより下に落ちたら最初の場所へ戻る | -8 |

## 仕組み（分かる人向け）

- **考えるのはホストだけ。** `IsSpawned` なら `IsServer` のときだけ動く。つないでいない（`NetworkManager` が無い／動いていない）ときは、そのPCで動く（検証シーン用）
- ボットの位置は `NetworkTransform`（**Authority = Server**）で全員に配る。素材はもともと `FishingNetSupply` ＋ `NetworkTransform` で、**引っ掛けられていない素材はホストが持ち主**なので、ホストが動かせば全員に届く
- 歩くのは `CharacterController`。**目的地へまっすぐ**歩くだけで、道は探さない
- 持ち上げるときは素材の `Rigidbody` を止め（kinematic）、`FixedUpdate` で頭の上へ `MovePosition` し続ける。ボットの体とは `Physics.IgnoreCollision` でぶつからないようにする
- 横取りの判定：素材が `IsHooked`（1人用）か `FishingNetSupply.IsClaimed`／持ち主がホストでなくなった（オンライン）なら、**物理には触らずに**手を離す（物理はもう引っ掛けた人の係なので）
- 投げるとき：飛ぶ時間 `t = 水平の距離 ÷ Throw Horizontal Speed` を決め、`t` 秒でゴールの真ん中にちょうど届く速度を素材に入れる
- 2体以上いても同じ素材を取り合わないよう、狙っている素材を `static` の一覧（`Reserved`）で共有している
- 点は `SpaceJunkGoal` がいつもどおり数える（ボットは何もしない）。運ぶ先は `SpaceJunkGoal.All` から `OwnerTeam == Team` のものを探す

## できていないこと・既知の問題

- **Unity でまだ一度も動かしていない**（AI は Unity を開けないため。コンパイルだけ確認済み）
- **オンラインでの確認もまだ。** 特に「参加者がボットから横取りしたとき」に素材がガタつかないかは要確認（`リスクリスト.md`）
- 道を探さないので、**ゴールとの間に穴や壁があるマップではうまく運べない**。動く床・回る床・列車にも対応していない
- ゴールが穴の向こうにあるマップで、投げた素材が届かず落ちることがある
- プレイヤーの人数やチーム分けとは関係なく、**置いた数だけ出る**（人数が足りないときに自動で足す仕組みはまだ無い）
- 名前タグ・得点の表示（誰が入れたか）には出てこない
- 見た目は仮（カプセルと顔の板）
