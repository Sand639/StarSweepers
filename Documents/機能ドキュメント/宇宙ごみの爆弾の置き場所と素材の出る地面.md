## この機能は何か

2つある。

1. **爆弾の置き場所** … 決まった場所に爆弾を置く。爆弾が**動かされたか消えたら、3秒後に同じ場所へ新しい爆弾が出る。**
2. **素材の出る地面** … 素材（デブリ）を、**指定した地面の上にだけ**出す。STAGE_02 では**左右の細長い地面だけ**に出て、**真ん中の地面と穴（列車の通り道）には出ない。**

---

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| ラウンドが始まる | 左右の地面の手前と奥、計4か所に爆弾が出る |
| 爆弾をフックで引っ張る・押して動かす（置いた場所から横に1m以上） | 3秒後、元の場所に新しい爆弾が出る。動かした爆弾はそのまま使える |
| 爆弾が爆発する・場外に落ちる | 3秒後、元の場所に新しい爆弾が出る |
| ラウンドの結果が出る | もう出さない |
| 素材が降ってくる | 左右の地面の上にだけ出る（真ん中の地面・穴には出ない） |

- 爆弾は**素材の数に入らない**（爆弾4つで素材の上限が減らない）

## 使い方（STAGE_02）

1. Unityで `Assets/Scenes/Prototype/SpaceJunk/Stage/STAGE_02.unity` を開く
2. メニュー **`Tools > StarSweepers > 開いているマップに STAGE_02 の爆弾と素材の出る地面を設定する`** を実行する
   - `BombPoints` というオブジェクトと、その子に置き場所4つ（`BombPoint_1`〜`4`）ができる
   - `SpaceJunkSpawner` の **Spawn Grounds** に、左右の地面（`1` と `2`）が入る。範囲（Area Half Size）は 15×15 になる
   - シーンは自動で保存される
3. 再生して確かめる

何度実行してもよい（置き場所は作り直す。**手で動かした置き場所も初期位置に戻る**ので注意）。

### 置き場所を変えたいとき

`BombPoints` の子（`BombPoint_1` など）を動かす。**子を増やせば置き場所も増える。**
シーン画面では赤い丸で見える。地面の少し上（高さ0.6くらい）に置く。

### 素材の出る地面を変えたいとき

`SpaceJunkSpawner` の **Spawn Grounds** に、出したい地面（当たり判定のある物）をドラッグして入れる。
**空にすると、今までどおり範囲のどこにでも出る**（ほかのマップは空のままなので、今までと同じ）。

## 設定できる値（インスペクターの項目）

### `BombPoints`（SpaceJunkBombPoints）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Bomb Prefab | 出す爆弾。スタンさせる `FishingOnlineBomb`、吹き飛ばす `KnockBackBoom` のどちらでもよい | `FishingOnlineBomb` |
| Respawn Seconds | 動かされた・消えてから次を出すまでの秒数 | 3 |
| Move Threshold | 置いた場所から横に何m離れたら「動かされた」とみなすか | 1 |
| Start Delay Seconds | 始まってから最初の爆弾を出すまでの秒数 | 0.5 |

### `SpaceJunkSpawner`（追加した項目だけ）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Spawn Grounds | ここに入れた地面の上にだけ素材を出す。空ならどこにでも出す | 空 |

## 仕組み（分かる人向け）

- 爆弾の置き場所：子1つ＝1か所。置いた爆弾の `HookableObject` を覚えておき、**消えた（null または IsVanished）か、XZ の距離が Move Threshold を超えたら**追いかけるのをやめ、Respawn Seconds 後に新しく Instantiate する。通信中は**ホストだけ**が出して `Spawn(true)` する（`SpaceJunkSpawner` と同じ）
- 素材の出る地面：出す候補の場所から真下へ、Spawn Grounds の各 Collider に `Collider.Raycast` し、どれかに当たれば採用
- メニューは「`Ground` の子のうち、原点の真上にかかっていない Collider」を Spawn Grounds に入れる（STAGE_02 では真ん中の `3` が外れる）

## 未対応（企画メモにあるが、まだやっていないこと）

- 列車（10秒に1回、真ん中を高速で通過する箱）
- デブリ5種類・最大10個（いまは素材3種類・最大15個のまま）
- 特殊高価値デブリを真ん中に出す
