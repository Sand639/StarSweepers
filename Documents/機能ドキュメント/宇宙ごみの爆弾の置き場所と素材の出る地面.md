## この機能は何か

STAGE_02 の企画メモ（呉さん）にある仕掛けのうち、次の4つ。

1. **爆弾の置き場所** … 左右の床の手前と奥、計4か所に**ノックバック爆弾**を置く。**爆発したら（場外に落ちても）、3秒後に同じ場所へまた出る**
2. **真ん中の特殊デブリ** … 真ん中に**大きくて金色に光る、得点の高いデブリ**（1個で10点）を置く。**消えたら（ゴールに入れた・爆発・場外）3秒後に真ん中へまた出る**
3. **素材を出す範囲** … 素材は**左右の床の緑の範囲の中にだけ**出る（真ん中の床・列車の通り道・床のふちには出ない）
4. **素材の数と種類** … 最大**10個**。種類は**5種類**（装甲板・回路基板・燃料タンク＋**アンテナ（ピンク）・エンジン（灰）**）

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| ラウンドが始まる | ノックバック爆弾4つと、真ん中に特殊デブリが出る |
| 爆弾を引っ張る・押して動かす | **出し直さない**（前は1m動かすと出し直していたが、少し動いただけで増えたため変えた） |
| 爆弾が爆発する・場外に落ちる | 3秒後、元の場所に新しい爆弾が出る |
| 特殊デブリを動かす | **出し直さない**（動かすたびに増えないように） |
| 特殊デブリをゴールに入れる | **10点**（ふつうの1点＋9点）。3秒後に真ん中へまた出る |
| 素材が降ってくる | 左右の緑の範囲の中にだけ。マップにある素材が10個になったら止まる |
| ラウンドの結果が出る | もう出さない |

- 爆弾と特殊デブリは、**素材の10個に数えない**
- 特殊デブリは、レーダーでも大きな金色の点で出る

## 使い方（STAGE_02）

**STAGE_02 にはもう置いてある**（2026/10/6 にプレハブ化して置いた）。ほかのステージで使うときは、プレハブをドラッグして置く。

| 置く物 | プレハブ | 中身 |
| --- | --- | --- |
| 爆弾の置き場所 | `Assets/Prefabs/SpaceJunk/Gimmick/BombPoints.prefab` | 置き場所4つ（子 `BombPoints_1`〜`4`）。**ノックバック爆弾（`KnockBackBoom`）**を出す。**爆発する（か場外に落ちる）と、3秒後に同じ場所へ出し直す**（動かしただけでは出し直さない） |
| 特殊デブリの置き場所 | `Assets/Prefabs/SpaceJunk/Gimmick/SpecialDebrisPoint.prefab` | 真ん中1か所（子 `SpecialDebrisPoint_1`）。消えたら3秒後に出し直す |

素材の範囲（`SpawnZones`）と、スポナーの設定（最大10個・5種類）は、プレハブにせずシーンに直接置いてある（スポナーが中の四角を指しているため）。

### 位置や範囲を変えたいとき

- 爆弾・特殊デブリの場所 … `BombPoints` / `SpecialDebrisPoint` の子を動かす。**子を増やせば場所も増える**。シーン画面では赤い丸で見える。
  プレハブごとの変更にしたいときは、変えたあとインスペクターの Overrides → Apply All
- 素材の範囲 … `SpawnZones` の子の**位置と Scale の X（横幅）・Z（長さ）**で四角が決まる。`SpaceJunkSpawner` を選ぶと緑の枠で見える

> ⚠️ **プレハブをエクスプローラーでコピーしないこと。** 通信で使う番号がかぶり、オンラインで正しく動かない。
> 増やすときは Unity の中で Ctrl+D する。

> 以前あったメニュー `開いているマップに STAGE_02 の爆弾と素材の出る地面を設定する` は**廃止した**（プレハブで置くようにしたため）。
> アンテナ・エンジン・特殊デブリのプレハブ（`Assets/Prefabs/SpaceJunk/Online/`）は、そのメニューで作ったものがそのまま残っている。

---

## 素材を5種類にしたことの影響（ほかのマップ）

- **ほかのマップは今までどおり3種類**（スポナーの Extra Materials が空のため）
- イベント（お題・期間限定高価値デブリ）は、**そのマップで出る種類の中から**選ぶようにした（3種類のマップで、出ないアンテナ・エンジンがお題にならない）
- 画面の「集めた種類」の表示も、そのマップで出る種類だけ
- 種類集めのルール（Collect）では、**そのマップで出る種類を全部**そろえたら勝ち

## 設定できる値（インスペクターの項目）

### `BombPoints` / `SpecialDebrisPoint`（SpaceJunkBombPoints）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Spawn Prefab | 出す物。爆弾は吹き飛ばす `KnockBackBoom`（スタンさせる `FishingOnlineBomb` に変えてもよい）、特殊デブリは `SpaceJunkSpecial` | ― |
| Respawn Seconds | 動かされた・消えてから次を出すまでの秒数 | 3 |
| Respawn When Moved | ON：動かされたら出し直す。OFF：消えた（爆発・ゴール・場外）ときだけ出し直す。**爆弾も特殊デブリも OFF** | プレハブでは OFF |
| Move Threshold | 置いた場所から横に何m離れたら「動かされた」とみなすか | 1 |
| Start Delay Seconds | 始まってから最初に出すまでの秒数 | 0.5 |

### `SpaceJunkSpecial.prefab`（SpaceJunkBonusDebris）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Bonus Points | ふつうの1点に足す点数 | 9（合計10点） |
| Glow Color | 光らせる色 | 金色 |

### `SpaceJunkSpawner`（追加した項目）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Extra Materials | 基本の3種類のほかに出す素材と、その出やすさ | 空 |
| Spawn Zones | この四角の中にだけ出す。空なら Area Half Size の範囲 | 空 |
