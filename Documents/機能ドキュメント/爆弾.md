## この機能は何か

**触れた瞬間に爆発して、触れた人を吹っ飛ばす爆弾。**

| 決まり | 内容 |
| --- | --- |
| 置き方 | **空中にも置ける。落ちてこない** |
| 爆発 | **人が触れたら、その瞬間に爆発する** |
| 飛ぶ向き | **爆弾の中心 → 触れた人の中心** の向き |
| 飛ぶ強さ | **重力が重いほど弱く、軽いほど強い** |

浮いていると分かるように、**ゆっくり上下に揺れている。**

## 遊ぶ人から見た動き

| 重力 | 飛ぶ速さ（**大槻さんが調整した値**：Launch Speed 15、Min 0.2、Max 1.2） |
| --- | --- |
| 2 | **18**（計算上は約74だが、1.2倍で止めている） |
| 5 | **18**（計算上は約29だが、1.2倍で止めている） |
| 地球（9.81） | **15** |
| 10 | **約14.7** |
| 15 | **約9.8** |

**軽いときは、飛ぶ速さが上がるうえに落ちてくるのも遅い**ので、ずっと遠くまで飛ぶ。
**重いときは、弱く飛んですぐ落ちる。**

- **爆弾が下にあれば上へ、横にあれば横へ**飛ぶ
- **ただし、地面からの角度は Max Launch Angle（初期値45度）まで。** 爆弾を踏んでも真上には飛ばず、**ななめに飛ぶ**。
  真上に乗っていて横の向きが決まらないときは、**動いていた向き**（止まっていたら**向いている向き**）へ飛ぶ
- **爆弾が頭の上にあるときは、下向きには押し込まれない**（地面にめり込まないよう、横向きだけ効く）
- 分離中は、**触れた体だけ**が飛ぶ

## すぐ試す方法

1. Unityで `Assets/Scenes/Test/BombTest.unity` を開く
2. **再生ボタンを押す**
3. 前に並んでいる爆弾に触る

| 並び | 高さ |
| --- | --- |
| 手前の列 | 0.6m（地面すれすれ） |
| 真ん中の列 | 1.3m（腰の高さ） |
| 奥の列 | 2.2m（**跳ばないと届かない**） |

- 重力が **2 / 5 / 10 / 15** の中から7〜9秒ごとに変わる（**大槻さんが調整した値**）
- このシーンのロボットだけ、**空中での操作（Air Control）が 0.1** になっている（ふつうは0.3。大槻さんが調整）
- **地面の白線は5mごと。** 重力による飛び方の違いを見比べられる
- このシーンの爆弾だけ、**爆発して3秒で元に戻る**

## 自分のシーンで使う方法

**メニューの `Tools > StarSweepers > アーカイブ > 爆弾 > 爆弾を置く`** を実行する（シーンビューで見ている場所の少し上に置かれる）。
**プレハブ（`Assets/Prefabs/GravityRace/Bomb.prefab`）をドラッグして置いてもよい。** 好きな高さに動かしてよい。

## 設定できる値（インスペクターの項目）

### 触れたと判定する範囲

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| **Touch Radius** | **爆弾の中心からこの距離まで人が近づいたら爆発する** | 0.6m |

見た目の直径は 0.8m（半径0.4m）なので、**見た目より少し手前で爆発する。**
選択するとシーンビューに**赤い球**が出る。そこが判定の範囲。

### 吹っ飛ばす強さ

**プレハブの値は、大槻さんが遊んで調整したもの（2026/9/14）。元に戻さないこと。**
（スクリプトに書いてある初期値とは違う。プレハブの値が優先される）

| 項目名 | 意味 | プレハブの値 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- | --- |
| **Launch Speed** | **ふつうの重力（9.81）のときに飛ばす速さ** | **15** | 9 |
| **Gravity Influence** | **重力にどれだけ左右されるか。** 1＝反比例、0.5＝ゆるやか、0＝重力に関係なし | **1** | 1 |
| **Min Multiplier** | どれだけ重くても、ふつうの何倍までしか弱くしないか | **0.2** | 0.25 |
| **Max Multiplier** | **どれだけ軽くても、ふつうの何倍までしか強くしないか** | **1.2** | 3 |
| **Upward Bias** | 飛ぶ向きに足す上向きの量。0なら「爆弾から人へ」そのまま | **0.3** | 0 |

> **Upward Bias は 0.3 に調整済み。** 0 だと地面の爆弾に横から触ったときに
> 真横に滑るだけになりやすいので、少し浮き上がるようにしてある。

### 飛ぶ角度

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| **Max Launch Angle** | **飛ぶ向きの、地面からの角度の上限（度）。** これより上を向くときは、この角度までねかせる。45＝ななめ45度、90＝上限なし（真上にも飛ぶ） | **45** |

> 横の勢いはだんだん弱まる（`Launch Damping`）ので、**見た目の飛び方は45度より少し急になる。**
> もっと横に飛ばしたいときは、角度を小さくする。

### 見た目・戻る

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Blast Material | 爆発の見た目のマテリアル | `BombBlast` |
| Blast Size | 爆発の見た目の大きさ（直径） | 2.5m |
| Blast Seconds | 爆発の見た目が消えるまで | 0.35秒 |
| Bob Height | 浮いていると分かるように上下させる幅。0で止まる | 0.08m |
| **Respawn Seconds** | **爆発してから元に戻るまでの秒数。0なら戻らない** | **0** |
| Log Explosions | 爆発のたびにコンソールへ書き出す | ON |

**Respawn Seconds が 0 でも、レースの R（やり直し）では元に戻る**（`StageReset`）。

## 仕組み（分かる人向け）

### 飛ぶ強さの計算

```
飛ぶ速さ ＝ Launch Speed × （ふつうの重力 ÷ いまの重力）の Gravity Influence 乗
```

その結果を **Min Multiplier 〜 Max Multiplier 倍**の間に収めている。

月の重力（1.6）は地球の約6分の1なので、反比例だと**約6倍**になる。
さすがに飛びすぎるので、**プレハブでは1.2倍で止めている**（重いほうは0.2倍まで）。

**計算していなくても、軽い重力ではもともと遠くへ飛ぶ。** 落ちてくるのが遅いため。
その上に「速さ」も足しているので、**重力による差はかなり大きく出る。**
差が大きすぎると感じたら、**Gravity Influence を 0.5** にするとよい。

### 爆弾に当たり判定を付けていない理由

**付けると、触れる前に止まってしまう。**
人（CharacterController）は当たり判定があると押し戻されるので、
爆弾に「ぶつかって止まる」だけで、触れたことにならない。

さらに、カメラが壁の裏に回らないようにする処理（`カメラが壁を抜けないようにする.md`）が
爆弾を壁と勘違いして、**カメラが寄ってきてしまう。**

そこで**当たり判定は付けず**、爆弾のほうから
**「周りの球の中に人が入ったか」を毎フレーム調べている。**
割れるガラスの床と同じやり方。

### 吹っ飛ばせる相手（ILaunchable）

爆弾は、触れた相手が **`ILaunchable`（吹っ飛ばせるもの）** を持っていれば、その `Launch` を呼ぶ。
**相手がロボットかどうかを、爆弾は知らない。**

- **ロボットの体（`RobotBody`）は、もともと「外から勢いを与える」処理を持っていた**（切り離したときに上半身を飛ばす処理）。
  それにこの目印を付けただけなので、**ロボットの動きは変わっていない**
- **本番用のプレイヤーを作ったら、そこにも `ILaunchable` を付ければ爆弾で飛ぶ**

### 飛んだあとの動き

飛ぶ処理はロボット側のもの（`RobotBody.Launch`）をそのまま使っている。

- **横向きの勢いは、だんだん弱まる**（`RobotBody` の `Launch Damping`）
- **上向きの勢いは、ジャンプと同じ扱い**（重力で落ちてくる）
- **下向きの勢いは使わない**（地面にめり込まないように）
- **角度の上限は、上向きの量（Upward Bias）を足したあとにかける。** 横の向きが0.1未満（真上から約6度以内）のときは、
  向きがぶれやすいので、人の動いていた向き → 向いている向きの順で横の向きを決める

## できていないこと・既知の問題

- **遊んで確認済み**（2026/9/14、大槻さん）。上限・下限・上向きの量はそのときに調整した値
- **吹っ飛ぶのはロボットだけ。** `PlayerRig`（カプセル）とカートは `ILaunchable` を持っていないので飛ばない（爆発はする）
- **ロープにつかまっている間は飛ばない。** ロープ側が毎フレーム勢いを消しているため
- **爆風の範囲は無い。** 爆発した瞬間に**触れていた人だけ**が飛ぶ。「近くにいた人も巻き込む」はまだ無い
- **連鎖しない。** 爆弾の近くの爆弾は爆発しない（`Explode` は外から呼べるので、足すのは簡単）
- **音が鳴らない**
- **通信（マルチプレイ）には未対応。** 各自の画面で別々に爆発する。重力・割れる床と同じく、**ホストが決めて配る**必要がある（`リスクリスト.md`）
