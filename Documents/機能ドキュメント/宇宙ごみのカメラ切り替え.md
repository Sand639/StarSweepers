## この機能は何か

**ゲーム中に、カメラを「全体カメラ」と「自陣カメラ」で切り替えられる。最初は全体カメラ。**

| モード | 見え方 |
| --- | --- |
| **全体カメラ**（最初はこちら） | ステージ全体が画面に収まる位置から、北向きに見下ろす。動かない |
| **自陣カメラ** | 自分のプレイヤーを追いかけ、**自陣が画面の手前に来る**ように回る（前に作った `SpaceJunkMap01TeamCam` と同じカメラ） |

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **`C` キー**（コントローラーは **Back**） | 全体カメラ ⇔ 自陣カメラ を切り替える。カメラはなめらかに移る |

- 切り替わるのは**自分の画面だけ**（ほかの人のカメラは変わらない）
- 画面の左上（「落ちたら［R］で戻れます」の下）に「［C／Back］でカメラ切り替え（全体／自陣）」と出る
- どちらのカメラでも、**W＝画面の奥**に進む（移動がカメラの向きに合わせて回るため）
- 全体カメラの位置は、**シーンが始まったときにステージの大きさを測って自動で決める**。ステージの形を変えても直さなくてよい（プレイヤー・素材・爆弾・アンカー・列車など、動く物や拾える物は測る対象に入れない）

---

## 使い方

STAGE_01〜05 のカメラは、**`Assets/Prefabs/SpaceJunk/Online/SpaceJunkStageCamera.prefab`** に差し替えてある。
新しいステージでも、このプレハブを置けば切り替えられる。

> 前は釣りのカメラ（`Fish/Online/System/TopDownFollowCamera.prefab`）を使っていた。
> 釣りのカメラは変えていない（宇宙ごみ用のプレハブを別に作った）。

## 設定できる値（SpaceJunkCameraModeSwitch）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Start Mode | 始まったときのモード。Whole Stage（全体）／Team（自陣） | Whole Stage |
| Toggle Key | 切り替えるキー | C |
| Toggle Button | 切り替えるコントローラーのボタン | Select（Back） |
| Whole Pitch | 全体カメラの見下ろす角度 | 60 |
| Screen Margin | 全体カメラで、画面の端に空けるすき間 | 0.04 |
| Ignore Larger Than | これより大きい物はステージの大きさに入れない（遠くの背景など） | 200 |
| Move Sharpness | 切り替えたときにカメラが移るなめらかさ | 6 |

自陣カメラの高さ・角度は、同じカメラの `SpaceJunkTeamFollowCamera`（Offset・Pitch など）で変える。

## 仕組み（分かる人向け）

- カメラには自陣カメラ（`SpaceJunkTeamFollowCamera`）と切り替え部品が付いている。全体モードでは**自陣カメラの部品を止め**、切り替え部品が全体の位置へカメラを寄せる
- プレイヤーが生まれたとき、`SpaceJunkPlayerSetup.FollowWithCamera` が自陣カメラに追いかける相手を渡す。止めてあるときはカメラを動かさない
- 全体の位置は、宇宙ごみの全体固定カメラのマップを作ったとき（`SpaceJunkFixedCameraSetup`）と同じ求め方（ステージの見た目の範囲の角8つが全部画面に入る、いちばん近い距離を二分探索）。こちらは実行したときの画面の縦横比で測る
- 新しいプレハブは、釣りのカメラのプレハブの**中の番号をそのまま残して**複製したので、シーン側のカメラの位置・名前の設定はそのまま使えている
