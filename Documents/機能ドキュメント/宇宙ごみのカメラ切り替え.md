## この機能は何か

**ゲーム中に、カメラの種類を切り替えられる。最初は全体カメラ。**

| 種類（切り替えの順） | 見え方 |
| --- | --- |
| **全体**（最初はこちら） | ステージ全体が画面に収まる位置から、北向きに見下ろす。動かない |
| **チーム**（2026/10/7 追加） | 自陣が手前のまま、**自分と味方がいつも画面に入る**ように映す。詳しくは `宇宙ごみのチームカメラ.md` |
| **自分** | 自分のプレイヤーを追いかけ、**自陣が画面の手前に来る**ように回る（前は「自陣カメラ」と呼んでいた。`SpaceJunkMap01TeamCam` と同じカメラ） |

> 2026/10/7（小野田さん）に、**カメラの種類ごとに部品を分けた。** 種類ごとに値を細かく変えられ、新しい種類も部品を1つ足すだけで増やせる。

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **`C` キー**（コントローラーは **Back**） | 全体 → チーム → 自分 → 全体 … の順に切り替える。カメラはなめらかに移る |

- 切り替わるのは**自分の画面だけ**（ほかの人のカメラは変わらない）
- 画面の左上（「落ちたら［R］で戻れます」の下）に「［C／Back］でカメラ切り替え　いま：全体（全体／チーム／自分）」と出る
- どのカメラでも、**W＝画面の奥**に進む（移動がカメラの向きに合わせて回るため）
- 全体カメラの位置は、**シーンが始まったときにステージの大きさを測って自動で決める**。ステージの形を変えても直さなくてよい（プレイヤー・素材・爆弾・アンカー・列車など、動く物や拾える物は測る対象に入れない）

## 使い方

STAGE_01〜05 のカメラは、**`Assets/Prefabs/SpaceJunk/Online/SpaceJunkStageCamera.prefab`** に差し替えてある。
新しいステージでも、このプレハブを置けば切り替えられる。

- **切り替えの順は、カメラに付いている部品の順。** インスペクターで部品を上下に動かすと順が変わる
- 種類ごとの **In Cycle** を OFF にすると、その種類は切り替えで飛ばす（部品を外さなくてよい）
- 始まったときの種類は、切り替え部品の **First Mode** に種類の部品をドラッグして決める
- **新しい種類を作るとき**：`SpaceJunkCameraMode` を継いだ部品を作り、`TryGetPose`（置きたい位置と向きを返す）を書いて、カメラに付ける
- 部品が足りないプレハブには、`Tools > StarSweepers > 宇宙ごみのステージのカメラにチームカメラを足す` で全体・チームの部品を足せる（**すでにあれば足さない**）

> 前は釣りのカメラ（`Fish/Online/System/TopDownFollowCamera.prefab`）を使っていた。
> 釣りのカメラは変えていない（宇宙ごみ用のプレハブを別に作った）。

## 設定できる値

### 切り替え（SpaceJunkCameraModeSwitch）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| First Mode | 始まったときの種類（部品をドラッグ）。空なら切り替えの順でいちばん上 | 全体（SpaceJunkWholeStageCamera） |
| Toggle Key | 切り替えるキー | C |
| Toggle Button | 切り替えるコントローラーのボタン | Select（Back） |
| Blend Seconds | 切り替えたときに、前のカメラから移り終わるまでの秒数 | 0.6 |

### 種類ごとに共通

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Display Name | 画面の案内に出す名前。空なら決まった名前（全体／チーム／自分） | 空 |
| In Cycle | 切り替えに入れるか | ON |

### 全体（SpaceJunkWholeStageCamera）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Pitch | 見下ろす角度 | 60 |
| Screen Margin | 画面の端に空けるすき間 | 0.04 |
| Ignore Larger Than | これより大きい物はステージの大きさに入れない（遠くの背景など） | 200 |
| Face Own Side | ON にすると、自陣が手前に来る向きで全体を映す（OFF は全員北向き） | OFF |
| Turn Sharpness | 自陣向きにするとき、向きが変わるなめらかさ | 4 |
| Manual Pose | **ON にすると、下の3つで全体カメラを置く**（2026/10/29・大槻さん）。OFF はステージの大きさから自動で決める（今までどおり）。ON のときは Pitch・Screen Margin・Face Own Side は使わない。**下の3つのどれかを変えると自動で ON になる**。再生していないときに ON にすると、自動で決まる見え方が下の3つに入る | OFF |
| Look Target | 1. 見る先（カメラが向く点） | (0, 0, 0) |
| Distance | 2. 見る先からの距離（m）。**変えると、カメラの位置が今の向きのまま近づく・離れる**（Camera Position も合わせて変わる） | 40 |
| Camera Position | 3. カメラの位置。**変えると、見る先からの距離（Distance）が合わせて変わる**。Look Target を変えたときも、位置はそのままで距離が変わる | (0, 34.64, -20) |

> **全体カメラの位置の調整のしかた**（2026/10/29）
>
> **Look Target・Distance・Camera Position のどれかを変えると、Manual Pose は自動で ON になる**（前は先に ON にしないと、再生中は自動の値で毎フレーム上書きされ、変えても元に戻った。大槻さん「位置が固定されてた」）。
>
> **A. 再生しないで決める（おすすめ。値がそのまま残る）**
>
> 1. マップのシーン（例：`Stage/STAGE_01`）を開き、Hierarchy の `Main Camera`（`SpaceJunkStageCamera`）を選ぶ
> 2. インスペクターの「Space Junk Whole Stage Camera」の **Manual Pose を ON** にする。**いまの自動の見え方が Look Target・Distance・Camera Position に入り、カメラがその位置へ動く**
> 3. 値を変えると、カメラがすぐその位置へ動く。**Game ビューで見え方を確かめる**
> 4. シーンを保存する（そのマップだけに効く。シーンのファイルが変わる）
>
> **B. 遊びながら決める**
>
> 1. ゲームを再生して、マップに入る。Manual Pose が OFF の間も、3つの欄に自動で決めた値が出る
> 2. Hierarchy の `Main Camera` を選び、3つの欄を変える（Manual Pose は自動で ON になる）
> 3. **再生を止めると、再生中に変えた値は消える。** 気に入ったら、止める前に部品の右上の︙ →「Copy Component」→ 再生を止めてから、同じ部品の︙ →「Paste Component Values」
>
> 全マップに効かせたいときは `Assets/Prefabs/SpaceJunk/Online/SpaceJunkStageCamera.prefab` に入れる（プレハブの編集画面にはステージが無いので、ON にしても自動の見え方は入らない。A で決めた値を Copy Component → プレハブに Paste Component Values が楽）。
> マップごとに大きさが違うので、プレハブで決めると、マップによっては端が切れたり小さく映ったりする。マップごとに決めるなら、シーンのカメラで決める。

## 仕組み（分かる人向け）

- カメラには、種類ごとの部品（`SpaceJunkCameraMode` を継いだもの）と切り替え部品が付いている。**種類の部品は「置きたい位置と向き」を返すだけ**で、カメラを動かすのは切り替え部品（選ばれている種類の `TryGetPose` を毎フレーム呼ぶ）
- 切り替えた瞬間の位置を覚えておき、Blend Seconds かけて新しい種類の位置へなめらかに移す（相手が動いていても、移り終わりがずれない）
- 切り替え部品が無いカメラ（`SpaceJunkMap01TeamCam`）では、種類の部品が自分でカメラを動かす
- 自分のプレイヤーは、`SpaceJunkPlayerSetup.FollowWithCamera` が自分カメラに渡す。ほかの種類は `FishingNetPlayer` から自分のプレイヤーを自分で探す
- 全体の位置は、宇宙ごみの全体固定カメラのマップを作ったとき（`SpaceJunkFixedCameraSetup`）と同じ求め方（ステージの見た目の範囲の角8つが全部画面に入る、いちばん近い距離を二分探索）。2026/10/7 から、カメラを実際に動かさずに投影の計算だけで判定している（向きを変えても毎フレーム測り直せるように）
- 新しいプレハブは、釣りのカメラのプレハブの**中の番号をそのまま残して**複製したので、シーン側のカメラの位置・名前の設定はそのまま使えている
