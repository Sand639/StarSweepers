## この機能は何か

**マウスで狙いをつけなくても、フックが物資へ飛んでいくようにする機能。**

狙い方を3つから選べる。**十字キーで切り替える。**

- **近くを狙う** … 届く範囲で一番近い物資へ飛ぶ
- **遠くを狙う** … 届く範囲で一番遠い物資へ飛ぶ
- **手動** … 今までどおり、マウスの方向へ飛ぶ（**始まったときはこれ**）

いま狙っている物資の上には、**黄緑の逆三角の目印**が出る（デバッグ用）。
**オンラインでは、他の人が狙っている物資の目印も見える。**

コントローラーで遊ぶとマウスで狙えないので、そのための土台でもある
（操作は基本コントローラーの方針。`README.md` の作品概要）。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 十字キー**左**（キーボードは **1**） | 「**近くを狙う**」に切り替わる |
| 十字キー**上**（キーボードは **2**） | 「**手動**」に切り替わる（今までの動き） |
| 十字キー**右**（キーボードは **3**） | 「**遠くを狙う**」に切り替わる |
| 左クリック長押し→離す（近く／遠くのとき） | **目印の付いた物資へフックが飛ぶ。** チャージ量に関係なく届く。物資が動いていても追いかける |
| 左クリック長押し→離す（届く範囲に物資が無いとき） | 手動と同じく、マウスの方向へ飛ぶ |

> **キーボードの矢印キーは使っていない。** 矢印キーは移動（WASDと同じ Move）に割り当て済みで、
> 押すとプレイヤーが動いてしまうため。**コントローラーの十字キー**と、**キーボードの 1・2・3** で切り替える。

### 画面の表示

| 場所 | 出るもの |
| --- | --- |
| **左下** | 十字キーの形に「↑ 手動」「← 近く」「遠く →」が並ぶ。**いまの狙い方が黄緑**になる。自分の画面だけに出る |
| **狙っている物資の上** | **黄緑の逆三角**。小さく上下に揺れる。オンラインでは横に「P1」のように**誰の目印か**が出る |

目印が出るタイミング：

| フックの状態 | 目印 |
| --- | --- |
| 待機・チャージ中・戻ってくる途中 | 「**いま撃ったらどれに飛ぶか**」を出す（プレイヤーが動くと切り替わる） |
| 飛んでいる途中 | **撃ったときに決めた物資のまま**（途中で切り替わらない） |
| 引っ掛けて引き寄せている間 | 出ない |
| 手動のとき | 出ない |

**何人かが同じ物資を狙っていると、目印が上に積み重なって**全員ぶん見える。

### 狙う相手の決まり

- **届く範囲**（フックの `Max Range`、初期値16m）の中から選ぶ。距離は**真上から見た水平の距離**で測る
- **消えている物資・誰かが引き寄せている物資は狙わない**
- **爆発物も狙う**（普通の物資と同じ扱い）。狙わないようにもできる（下の `Include Explosives`）

## 設定できる値（インスペクターの項目）

### HookAimAssist（プレイヤーに付く）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Start Mode | 始まったときの狙い方（Manual／Nearest／Farthest） | Manual（手動） |
| Include Explosives | 爆発物も狙うか | ON |
| Nearest / Manual / Farthest Bindings | 切り替えのキー（Input System の書き方） | 近く `<Gamepad>/dpad/left` `<Keyboard>/1`／手動 `<Gamepad>/dpad/up` `<Keyboard>/2`／遠く `<Gamepad>/dpad/right` `<Keyboard>/3` |
| Show Panel | 左下の表示を出すか | ON |
| Show Marker | 目印を出すか | ON |
| Ui Scale | 表示の大きさ（1920×1080 のときの倍率。窓が小さいと自動で縮む） | 1.6 |
| Marker Size | 目印の幅 | 18 |
| Marker Height | 物資のてっぺんから目印までの高さ（m） | 0.4 |

届く範囲は、フック側の `HookController > Max Range`（`釣りフックの操作.md`）をそのまま使う。

## 仕組み（分かる人向け）

- **選ぶ**：`HookAimAssist.PickTarget()` が `HookableObject.All` を回し、`Max Range` 以内で一番近い／遠いものを返す。
  `IsVanished` `IsHooked`、オンラインでは `FishingNetSupply.IsClaimed` のものは除く。
- **撃つ**：`HookController.Fire()` が発射の瞬間に `PickTarget()` を呼ぶ（1フレーム古い結果を使わないため）。
  相手がいれば発射方向をそちらへ向け、飛距離を `Max Range + 1.5m` にする。
- **追いかける**：飛んでいる間は毎フレーム「相手の当たり判定の中心」へ向きを取り直す（高さの違いや、動いている物資にも当たる）。
  当たり判定は今までと同じ `SphereCast` に加えて、**相手の中心の近くまで来たら引っ掛けた扱い**にしている
  （`SphereCast` は、球が相手の中から始まると当たらないため）。
  相手が途中で消えた・先に取られたときは、そこからまっすぐ飛ぶ。
- **他の人に見せる**：自分のプレイヤーの `HookAimAssist` が、狙っている物資の `NetworkObjectId` を
  `FishingNetPlayer.SetAimTarget()` で `NetworkVariable`（**本人が書く**）に入れる。値が変わったときだけ送られる。
  他の人のPCでは、そのプレイヤーに付いた `HookAimAssist` が `AimTarget` を読んで目印を描く。
  **`HookAimAssist` は `ownerOnlyScripts` に入れていない**（他の人のぶんでも目印を描くため）。
- **目印の絵**：素材を用意しなくて済むように、逆三角の画像をコードで1回だけ作り、`OnGUI` で物資の画面上の位置に描く。
  3Dの物ではないので、壁の向こうでも隠れない（デバッグ用なのでその方が見やすい）。

## できていないこと・既知の問題

- **⚠ 遊んで確かめていない。** コンパイルが通ることだけ確認した。特に**オンラインで他の人の目印が見えるか**は、
  検証用ビルドを複数起動して確かめる必要がある（`釣りのオンライン対戦.md` の「1台のPCで4人プレイを試す方法」）。
- **投げる向きは今までどおりマウスの方向。** オートエイムは「フックを当てる」ところだけ。コントローラーだけで遊ぶには、投げる向きの決め方も別に要る。
- **体の向きもマウスの方向のまま。** 背中側の物資を狙うと、フックが体の後ろへ飛んでいく見た目になる。
- **近くを狙うとき、同じくらいの距離の物資が2つあると、目印が行ったり来たりする**ことがある。
- 爆発物は物資6個に対して1個の割合で降ってくる（`釣りの物資のスポナー.md`）ので、**爆発物も狙う設定だと爆発物に飛ぶことが多い**かもしれない。遊んでみて `Include Explosives` を決める。
- **壁の向こうの物資も狙う。** フックはもともと壁をすり抜けるので、今の作りとは合っている。
- 他の人の目印は、通信の遅れのぶん**少し遅れて切り替わる**。
