---

## 目的

`MovableBlock` と `PullAblePlate` の処理を分け、Block の既存動作を変えずに、移動床だけへ次の規則を追加する。

- 移動床どうし、および固定地図へ進んだ時は衝突面の直前で止まり、互いに貫通しない。
- Player、物資、動く障害物とは衝突する。
- 移動床が動くと、その上に立っている Player も同じ距離だけ動く。
- 移動床に8方向の柱を持たせ、Inspector の checkbox で柱ごとに使用するか選べる。
- 移動床の上にいる Player は、その床自身の柱をフックで引っ掛けられない。
- 床の外に置く専用 Anchor を引っ張ると、床と Player が Anchor の方向へ一緒に動く。

## 実装結果

2026年10月6日に設計どおり実装し、10月8日に床本体を Plane から厚みのある Cube へ変更した。`PullAblePlate.prefab` は専用スクリプト、8本の柱、PassengerArea、`PlateBody` Cube と BoxCollider を持つ。`PullAblePlateAnchor.prefab` も同じ Gimmick フォルダへ追加したが、Scene には置いていない。

EditMode 自動テストでは、8方向、柱のON／OFF、同じ床の Player からの拒否、複数乗員の移動、Anchor、固定 Cube／別 Plate の手前での停止、Prefab 構造を確認済み。残る確認は Unity Play Mode の操作感とネットワーク同期。

## 遊ぶ人から見た動き

| 状況・操作 | 結果 |
| --- | --- |
| Plate の外にいる Player が有効な柱を引っ張る | 柱の方向へ Plate が動き、Plate 上の Player も一緒に動く |
| Plate 上の Player が同じ Plate の柱へフックを当てる | その柱には引っ掛からず、フックは通常どおり先へ進む |
| Plate 上の Player が場外の Anchor を引っ張る | `Plate 中心 → Anchor` の水平方向へ Plate と Player が動く |
| Plate に乗っていない Player が Anchor を狙う | Anchor には引っ掛からない |
| Plate が別の Plate や固定地図へ進む | 衝突面の直前で止まり、相手の中へ入らない |
| Plate が Player や Rigidbody を持つ物資へ進む | 通常の衝突を行う |

## 採用する構成

### 1. Block は既存動作へ戻す

`MovableBlock` と `MovableBlockPullPoint` は Block 専用とする。

- 移動モードは `TowardPlayer` と `FourDirections` の2種類。
- 引っ掛け場所は Front／Back／Left／Right の4方向。
- Plate 用の `FourCorners` と斜め4方向を削除する。
- `Assets/Scenes/Test/Sou/MovableBlock.prefab` の動きは変えない。

### 2. Plate 専用スクリプト

`Assets/Scripts/SpaceJunk/` に次のスクリプトを追加する。

| スクリプト | 責任 |
| --- | --- |
| `PullAblePlate.cs` | Plate の移動、8方向の有効／無効、乗っている Player の管理、衝突前の停止を担当する |
| `PullAblePlatePullPoint.cs` | 8本の柱をフックの引っ掛け場所にする。自分の Plate 上にいる Player からのフックは拒否する |
| `PullAblePlatePassengerArea.cs` | Plate 上面の Trigger で Player を見つけ、本当に床上に立っているか確認する |
| `PullAblePlateAnchor.cs` | 場外の Anchor。Player が乗っている Plate を探し、その Plate を Anchor 方向へ動かす |

共通の `IHookPullable` は引き続き使う。Player ごとに使用可否が変わる物だけが実装する、追加の小さいインターフェースを用意する。`HookController` はそのインターフェースがある場合だけ Player を渡して確認するため、Block の判定は変わらない。

### 3. 8方向の柱

柱の名前と方向は次の8種類に固定する。

| 名前 | Plate のローカル方向 |
| --- | --- |
| Front | `+Z` |
| FrontRight | `+X +Z` |
| Right | `+X` |
| BackRight | `+X -Z` |
| Back | `-Z` |
| BackLeft | `-X -Z` |
| Left | `-X` |
| FrontLeft | `-X +Z` |

`PullAblePlate` の Inspector に8個の checkbox を表示する。OFF にした柱は GameObject ごと非表示・無効にし、フックにも当たらなくする。Prefab の初期値は8本すべて ON とする。

## 処理の流れ

### 柱を引っ張る場合

1. Hook が `PullAblePlatePullPoint` に当たる。
2. Hook を撃った Player が、その柱と同じ Plate の上にいるか確認する。
3. 同じ Plate 上なら拒否する。別の場所にいる Player なら従来のゲージを開始する。
4. 2回目の入力で引っ張りが完成した時だけ、柱の8方向へ Plate を移動する。
5. Plate が1フレームで進んだ差分を、上にいる有効な `CharacterController` に `Move` で渡す。

### 場外 Anchor を引っ張る場合

1. Hook が `PullAblePlateAnchor` に当たる。
2. Hook を撃った Player が乗っている `PullAblePlate` を探す。
3. Plate が見つからない場合は Anchor への接続を拒否する。
4. 引っ張り完了時にもう一度乗っている Plate を確認する。
5. `Anchor位置 - Plate中心` の Y を0にした方向へ Plate と Player を移動する。

Player がゲージ中に Plate から降りた場合は移動させず、Hook を解除する。

---

## Player を床と一緒に動かす方法

このゲームの Player は Rigidbody ではなく `CharacterController` で動く。そのため、キネマティック Rigidbody の床を `MovePosition` しても Player は自動では運ばれない。

Plate 上面の Trigger で候補を管理し、Player の足元から短い Raycast を下へ出して、実際にその Plate の表面へ立っていることを確認する。Plate の各移動ステップで次を行う。

1. 今回の Plate の移動差分を計算する。
2. Plate を `Rigidbody.MovePosition` で動かす。
3. その Plate 上の有効な `CharacterController` へ同じ差分を `Move` で渡す。

オンライン上の他人用 Player は `CharacterController` が無効になっているため、そのクライアントでは動かさない。

---

## 衝突面の直前で止める方法

固定地図や別の Plate に対する `Physics.IgnoreCollision` は使わない。Plate が1ステップ動く直前に、子の `PlateBody` を含む Rigidbody 全体を進行方向へ Sweep する。

- 進行方向に非 Trigger Collider が無ければ、予定どおり移動する。
- Collider があれば、最も近い衝突面の0.01m手前までだけ移動し、今回の移動を終了する。
- `CharacterController` と自分自身の子 Collider は Sweep の停止対象から外す。
- Hook、柱、PassengerArea などの Trigger は判定に含めない。

Layer や既存 Scene の設定は変更しない。固定 Cube と別の `PullAblePlate` の両方について、移動後に Collider が重ならないことを自動テストする。

## Prefab

### `PullAblePlate.prefab`

次の構造へ更新する。

- Root
  - `PullAblePlate`
  - キネマティック Rigidbody
- PlateBody
  - 10m × 0.5m × 10m の Cube（中心 Y=-0.25m、上面 Y=0m）
  - 表示用 MeshRenderer
  - 床の実体 BoxCollider
- PassengerArea
  - Plate 上面を覆う Trigger
  - `PullAblePlatePassengerArea`
- 8方向の柱
  - 各柱に Trigger と `PullAblePlatePullPoint`

既存 Scene 内の Prefab instance は Scene を編集せず、Prefab 側の変更を継承させる。Scene 固有の位置・大きさの override は維持する。

### `PullAblePlateAnchor.prefab`

`Assets/Prefabs/SpaceJunk/Gimmick/` に新規作成する。場外へ複数配置でき、置いた位置がそのまま移動方向になる。今回 Scene へは配置しない。

## 設定できる値

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Move Distance | 1回の引っ張りで動く距離 | 2m |
| Move Duration | 移動にかける時間 | 0.35秒 |
| Front～FrontLeft Active | 8方向それぞれの柱を使うか | すべて ON |
| Passenger Ground Check Distance | Player が Plate 上にいると判断する足元確認距離 | 実装時に Player の大きさから決定 |

## テスト

実装はテストを先に追加し、失敗を確認してから行う。

- `MovableBlock` が従来の2モード・4方向だけで動く。
- Plate の8方向がローカル回転を含めて正しい方向になる。
- Plate prefab に8本の正しい名前の柱と Trigger がある。
- checkbox をOFFにした柱が Hook 対象にならない。
- 同じ Plate 上の Player は柱を使用できず、別の Player は使用できる。
- Anchor は Plate 上の Player だけが使用できる。
- Anchor の方向が `Plate中心 → Anchor` になる。
- Plate prefab の Root に旧 Plane／Collider が無く、`PlateBody` に Cube Mesh と実体 BoxCollider がある。
- 固定 Collider と別の Plate の手前で停止し、移動後に Collider が重ならない。
- Plate の移動差分が乗っている CharacterController に渡される。
- 最後に Unity 6000.3.14f1 で全 EditMode テストを実行する。

実際の操作感、Player が端に立った時、複数 Player が同時に乗った時は Unity の再生で担当者が確認する。

---

## 今回行わないこと

- Scene の編集と Anchor の配置。
- Plate のネットワーク位置同期。従来と同じくローカル動作までとし、オンライン正式運用前に別途対応する。
- 物資を Plate と同じ差分で強制的に運ぶ処理。物資は物理衝突に任せる。
- Block の操作感や移動距離の変更。

---

## 検討した別案

| 案 | 採用しない理由 |
| --- | --- |
| Plate／Player／Map 専用 Layer を追加する | Player prefab と Project Settings 全体へ影響し、既存機能を壊す範囲が大きい |
| Plate 移動中だけ Collider を無効にする | Player が床を失って落下し、再有効化時に重なった物が弾かれる可能性がある |
| Player を Plate の子 Transform にする | CharacterController、カメラ、NetworkObject の Transform 管理と衝突しやすい |
