## この機能は何か

**マウスのホイール（中ボタン）を長押しすると、画面の真ん中に8つに分かれた円が出て、
選んだリアクション（「いいね」「助けて！」など）がプレイヤーの頭の上に少しの間だけ出る機能。**
スマホのバトルロイヤルゲームによくある、円形のクイックメニューの形。

いまは**仮の見た目**（色の丸に文字）で、**自分の画面にしか出ない**（ほかの人には見えない）。

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| マウスのホイールを長押し（約0.15秒） | 画面の真ん中に8分割の円が出る |
| 押したままマウスを動かす | 動かした方向の項目が明るくなる（真ん中の白い点が動く） |
| ホイールを離す | 選んだリアクションが頭の上に約2.5秒出る |
| 真ん中のあたりで離す | 何も出さずに閉じる（取り消し） |
| ホイールを短く押しただけ | 何も起きない |

## 設定できる値（インスペクターの項目）

### `ReactionWheel`

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Bubble | 頭の上に出す係（プレイヤーに付けた ReactionBubble） | ― |
| Entries | 8つのリアクション（文字・色・画像）。**0 が真上で、時計回り**。画像を入れると、文字の代わりに画像が出る | いいね／ナイス！／こっち！／ありがと／助けて！／ごめん／笑／？ |
| Hold Seconds | 何秒押し続けたら開くか | 0.15 |
| Pointer Sensitivity | マウスの動きの何倍で選ぶ点を動かすか | 1 |
| Dead Zone | 真ん中の何割までを「選んでいない」とするか | 0.3 |
| Radius | 円の半径（1920x1080 の画面での大きさ） | 300 |
| Gap Degrees・Segment Color・Selected Color | 区切りのすき間・区切りの色・選んだ区切りの色 | 2度 |

### `ReactionBubble`（プレイヤーに付ける）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Head Height | 足元から何mの高さに出すか | 2.3 |
| Size | アイコンの大きさ（m） | 0.9 |
| Display Seconds | 出しておく秒数 | 2.5 |
| Pop Seconds・Fade Seconds | 出るときに弾む秒数・消える前にうすくなる秒数 | 0.2・0.4 |

## 仕組み（分かる人向け）

- 選ぶときは**マウスの位置ではなく、動いた量**を足していく。カーソルが画面に固定されていても選べる
- 方向は「真上を0度として時計回り」の角度を45度ずつに区切って決める（真上の項目は -22.5〜22.5度）
- 区切りの見た目は、丸の画像を `Image` の Filled（Radial360）で43度ぶんだけ塗り、項目ごとに回している
- 選んだら `ReactionWheel.Chosen`（項目の番号）が呼ばれる。**通信で知らせる係は、ここにつなげばよい**
- 開いている間は `ReactionWheel.IsOpen` が true になる

---

## できていないこと・既知の問題

- **ほかの人の画面には出ない。** 通信で知らせる係（ホストへ番号を送り、全員の画面の同じプレイヤーで `ReactionBubble.Show` を呼ぶ）がまだ無い
- **本番のプレイヤー（`NetworkPlayer.prefab`）には、まだ付けていない。** 検証シーンのカプセルでだけ動く
- 開いている間も、マウスでカメラや狙いが動いてしまう（本番に入れるときは、カメラや狙いの側で `ReactionWheel.IsOpen` を見て止める）
- コントローラーと、1台のPCで複数人（席ごとの入力）には対応していない
- 画像は仮（色の丸に文字）。本番の画像ができたら Entries の Icon に入れる
