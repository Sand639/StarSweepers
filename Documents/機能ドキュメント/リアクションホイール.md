## この機能は何か

**マウスのホイール（中ボタン）を長押しすると、画面の真ん中に8つに分かれた円が出て、
選んだリアクション（「いいね」「助けて！」など）を全員に知らせる機能。**
スマホのバトルロイヤルゲームによくある、円形のクイックメニューの形。

知らせたリアクションは、マリオパーティのように**全員の画面の右端に「名前＋スタンプ」の札**で出る。
試合中は全体を映すカメラになり、頭の上は見づらいため（大槻さんの依頼）。

いまのスタンプは**仮の見た目**（色の丸に文字）。

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| マウスのホイールを長押し（約0.15秒） | 画面の真ん中に8分割の円が出る |
| 押したままマウスを動かす | 動かした方向の項目が明るくなる（真ん中の白い点が動く） |
| ホイールを離す | **全員の画面の右端**に「自分の名前＋スタンプ」の札が約3.5秒出る（新しいものほど上。5枚まで） |
| 真ん中のあたりで離すと | 何も出さずに閉じる（取り消し） |
| ホイールを短く押しただけ | 何も起きない |
| ポーズ画面などのメニューを開いている間 | 円は開かない |
| タイトル画面（つないでいないとき） | 円は開かない |

## ゲームで使う・使わない

- **ゲームで試すには**：Unity のメニュー `Tools > StarSweepers > リアクション > ロビーに置く（ゲームで試す）` を1回押す。
  ロビーのシーン（`SpaceJunkLobby`）に `ReactionSystem` が置かれ、ロビーと試合中に使えるようになる
- **使わないときは**：ロビーの `ReactionSystem` の**チェックを外す（無効にする）だけ**。円も開かず、通信もしない
- ロビーに置いた `ReactionSystem` は、マップを移っても消えずに残る（ロビーへ戻ってきても増えない）

## 設定できる値（インスペクターの項目）

すべて `ReactionSystem.prefab` の中。

### `ReactionWheel`

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Bubble | 頭の上に出す係（プレイヤーに付けた ReactionBubble）。空でよい（検証シーンだけ入れている） | ― |
| Entries | 8つのリアクション（文字・色・画像）。**0 が真上で、時計回り**。画像を入れると、文字の代わりに画像が出る | いいね／ナイス！／こっち！／ありがと／助けて！／ごめん／笑／？ |
| Hold Seconds | 何秒押し続けたら開くか | 0.15 |
| Pointer Sensitivity | マウスの動きの何倍で選ぶ点を動かすか | 1 |
| Dead Zone | 真ん中の何割までを「選んでいない」とするか | 0.3 |
| Radius | 円の半径（1920x1080 の画面での大きさ） | 300 |
| Gap Degrees・Segment Color・Selected Color | 区切りのすき間・区切りの色・選んだ区切りの色 | 2度 |

> **決まり**：Entries の**並び順は全員で同じ**であること（通信では「何番目か」だけを送るため）。
> ビルドしたゲームどうしなら同じプレハブなので気にしなくてよい。

### `ReactionFeed`（画面の右端の札）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Display Seconds | 札を出しておく秒数 | 3.5 |
| Max Cards | 一度に並べる札の数 | 5 |
| Slide Seconds | 札が滑り込む・出ていく秒数 | 0.2 |
| First Card Offset | いちばん上の札の位置（右端からの距離・画面の上下の真ん中からの高さ） | (24, 160) |
| Card Size・Spacing・Card Color | 札の大きさ・すき間・色 | 360x96・10 |

### `ReactionRelay`（通信の係）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Allow Offline | ON なら、つないでいなくても自分の画面だけで使える（検証シーンだけ ON） | OFF |
| Keep Across Scenes | ON なら、シーンを移っても残る（ロビーに置くとき） | ON |
| Min Interval Seconds | 同じ人が続けて送れる間隔。連打で画面が埋まらないよう、ホストが間引く | 0.5 |

### `ReactionBubble`（検証シーンのプレイヤーに付いている）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Head Height・Size | 足元から何mの高さに、何mの大きさで出すか | 2.3・0.9 |
| Display Seconds・Pop Seconds・Fade Seconds | 出しておく秒数・出るときに弾む秒数・消える前にうすくなる秒数 | 2.5・0.2・0.4 |

## 仕組み（分かる人向け）

- 選ぶときは**マウスの位置ではなく、動いた量**を足していく。カーソルが画面に固定されていても選べる
- 方向は「真上を0度として時計回り」の角度を45度ずつに区切って決める（真上の項目は -22.5〜22.5度）
- 区切りの見た目は、丸の画像を `Image` の Filled（Radial360）で43度ぶんだけ塗り、項目ごとに回している
- 通信は **NetworkObject を使わず、NGO の「名前付きメッセージ」**（`CustomMessagingManager`）で送る。
  ネットワーク用のプレハブ一覧（`DefaultNetworkPrefabs`）に入れなくてよく、無効にすれば受け口も作らない
  1. 参加者 → ホスト：`StarSweepers.Reaction.Send`（何番目か）
  2. ホスト → ほかの全員：`StarSweepers.Reaction.Show`（何番目か・名前）。ホスト自身は直接出す
- 名前はホストが `SpaceJunkSession.NameOf`（タイトル画面で入れた名前）で調べる。試合の係がいなければ仮の名前
- つなぎ直すと NetworkManager の通信の係が別物になるので、変わったら受け口を作り直す

## できていないこと・既知の問題

- **円が開いている間も、マウスの位置で狙い（向き）が動く。** 狙いの側（`PlayerAimController`）で `ReactionWheel.IsOpen` を見て止めれば直る（他の人の担当のファイルなので、まだ触っていない）
- 試合中は、頭の上のアイコン（`ReactionBubble`）は出ない（プレイヤーごとに付けていないため）
- コントローラーと、1台のPCで複数人（席ごとの入力）には対応していない。1台で複数人のときは、1人目の名前で出る
- スタンプは仮（色の丸に文字）。本番の画像ができたら Entries の Icon に入れる
- **人が実際に複数台で試していない**（AIは Unity の再生や通信を確かめられない）
