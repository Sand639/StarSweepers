## この機能は何か

**タイトル画面で入れた「ゲーム内で表示する名前」を、ほかの人にも見えるようにする機能。**

- ロビーの左上の参加者の一覧と、ゲーム設定のチーム分けの欄に、その名前が出る（`ロビーの画面.md`）
- ゲーム中（ロビー・マップとも）、**プレイヤーの頭の上に名前のタグ**が出る。文字は**その人のチームの色**で、黒い影付き
- タグは**いつもカメラのほうを向く**

名前を入れていない人は、仮の名前（今までどおりの「プレイヤー○」など）になる。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| タイトルの「サーバーを作る」で名前を入れて部屋を作る | ホストの名前として全員に見える |
| 名前を入れてからサーバーに参加する | 参加した直後にホストへ名前を送り、全員に配られる |
| チームが変わる | 頭の上のタグの色も、新しいチームの色になる |

## 設定できる値（インスペクターの項目）

`Assets/Resources/PlayerNameplate.prefab` を選ぶと変えられる。**プレハブの名前と置き場所は変えないこと**（名前で読み込んでいるため。無いと初期値で作る）。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Height | 足もとから、どれだけ上に出すか（m） | 2.6 |
| Character Size | 文字の大きさの倍率。0.05 で文字の高さがだいたい 0.3m | 0.05 |
| Font Size | フォントの細かさ（大きいほどきれいだが重い） | 64 |
| Use Team Color | ON：チームの色／OFF：Fixed Color | ON |
| Fixed Color | Use Team Color が OFF のときの色 | 白 |
| Shadow Color / Shadow Offset | 文字の影の色と、ずらす量 | 黒（少し透明）／0.035 |
| Show Own Name | 自分の頭の上にも出すか | ON |

## 仕組み（分かる人向け）

- 名前は `SpaceJunkPlayerSlot.Name`（`FixedString64Bytes`）に入れ、席の一覧（NetworkList）ごと全員に配る
- 参加者は接続したら `SubmitNameServerRpc` で名前を送る。ホストは自分の名前を `GameSettings.PlayerName` から入れる
- **答え合わせ**：参加者は2秒ごとに「自分の席の名前が、設定の名前と同じか」を見て、違えば送り直す（`[NET][答え合わせ]` のログが出る）
- 表示は `SpaceJunkSession.NameOf(clientId)`（席の名前 → 無ければ `FishingNetPlayer.DisplayName`）
- タグは `TextMesh` を2枚（文字と影）。日本語なので、フォントは `UiFont.Find` で実行時に借りる
- タグはプレイヤーの子にする（ネットワークのプレイヤーはシーンをまたいで残るので、タグも一緒に残る）

---

## できていないこと・既知の問題

- 名前に使える文字のチェックは、長さ（16文字）と前後の空白だけ。不適切な言葉の対策はしていない
- 壁の向こうのプレイヤーのタグも見える（重なって読みにくければ、見え方を考え直す）
- スコアボード（釣りの部品）にはまだ名前を出していない
