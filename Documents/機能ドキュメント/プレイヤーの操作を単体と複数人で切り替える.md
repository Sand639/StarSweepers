## この機能は何か

宇宙ごみ・釣りのプレイヤー（移動・狙い・フック・投げる）が読む操作を、**1つの「読み口」にまとめた**。
読み口の「席の番号」を変えるだけで、同じプレイヤーが2通りの遊び方に対応する。

| 席の番号（Seat Index） | 遊び方 | どの機器で動くか |
| --- | --- | --- |
| **-1（初期値）** | **単体操作**（今までどおり） | つないであるどのキーボード・マウス・コントローラでも動く |
| **0 以上** | **1台のPCで複数人** | その席（0 = P1、1 = P2）に入ったキーボード・マウス・コントローラ**だけ**で動く |

**初期値が「今までどおり」なので、今あるシーン・プレハブ・オンライン対戦の動きは変わらない。**
読み口はプレイヤーに付いていなくても、操作のスクリプトが起動時に自動で付ける（プレハブを直す必要はない）。

席そのもの（どのキーボード・マウス・コントローラが P1 か）は、`席ごとの入力と機器の固定登録.md` の仕組みで決まる。

## 遊ぶ人から見た動き

検証シーン `Assets/Scenes/Test/PlayerSeatTest.unity` での動き（宇宙ごみのプレイヤーが2人いる）。

| 操作 | 結果 |
| --- | --- |
| キーボードのキーを押す／マウスを動かす／コントローラのボタンを押す | 押した順に P1・P2 に入る（固定登録していないとき） |
| WASD／矢印、または左スティック | その席のプレイヤーだけが動く |
| マウス、または右スティック | その席のプレイヤーだけがその方向を向く。**地面に照準マークが出る**（画面のマウスカーソルは1つしか無いので） |
| 左クリック／LT・右クリック／RT | その席のプレイヤーだけがフックを撃つ（宇宙ごみ式：左＝引っ張る、右＝投げる） |
| F6 | キーボード・マウスの固定登録（`席ごとの入力と機器の固定登録.md`） |

## 設定できる値（インスペクターの項目）

`PlayerInputSource`（プレイヤーに付く。無ければ再生したときに自動で付く）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Seat Index | -1 = 単体操作（今までどおり）。0 以上 = その席の機器だけで動く。**席で動かすときは、シーンに `InputSeatManager` が要る** | -1 |

### 使い方（プログラマー向け）

```csharp
// 1台のPCで複数人にするとき：プレイヤーごとに席を決める（遊んでいる途中で変えてもよい）
PlayerInputSource.Get(player).SeatIndex = 0;   // P1
PlayerInputSource.Get(player2).SeatIndex = 1;  // P2

// プレイヤーの操作スクリプトで読むとき（Mouse.current や Gamepad.current を直接読まない）
PlayerInputSource input = PlayerInputSource.Get(this);
Vector2 move = input.ReadMove(moveAction);   // 単体なら Input Actions の Move、席ならその席の移動
Gamepad pad = input.Gamepad;                  // 単体なら Gamepad.current、席ならその席のコントローラ
input.TryReadPointer(out Vector2 screen);     // 単体ならマウスの位置、席ならその席のカーソル
bool fire = input.PullPressed;                // 左クリック／LT（席では Attack ボタン）
bool hold = input.ThrowPressed;               // 右クリック／RT（席では Aim ボタン）
```

新しい操作を足すときは、**`PlayerInputSource` に1つ足して、単体のときは今までの読み方、席のときは `Seat` から読む**ように書く。

## 仕組み（分かる人向け）

- 設計の方針：**「操作タイプを切り替える仕組み」を別に作らず、プレイヤーが読む入力の口を1つにまとめた**（小野田さんの2案のうち「ラップ関数」のほう）。
  席の番号が -1 か 0 以上かが、そのまま「単体操作」と「1台で複数人」の切り替えになる。
  - 変更を小さくするため、各スクリプトの読み方は**1行ずつ置き換えただけ**（`Gamepad.current` → `input.Gamepad`、`moveAction.ReadValue` → `input.ReadMove(moveAction)` など）。
  - 単体操作のときは、置き換える前と**まったく同じもの**を読む（Input Actions・`Mouse.current`・`Gamepad.current`）。
  - `ThrowController` の `PullPressed()` などは、これまで誰の入力か区別しない `static` だったので、体ごとの読み口を使うふつうのメソッドに変えた（呼んでいたのは `HookController` だけ）。
- 席で読む設定なのに席が見つからない（`InputSeatManager` が無い・`Seat Count` が足りない）ときは、**何も入力しない**（全員が同じ機器で動いてしまわないように）。警告を1回だけ出す。
- 読み口はプレイヤーの体（CharacterController の付いた物）に1つだけ付く。どのスクリプトが先に起動しても同じ物を使う。
- 狙い（`PlayerAimController`）：席のときは、マウスと右スティックのカーソルを席の側（`InputSeat.Cursor`）がまとめているので、マウス／スティックの切り替えはしない。画面のマウスカーソルを隠したりもしない。

## できていないこと・既知の問題

- **キーボード2台・マウス2台・コントローラをつないで、2人で動かす確認はまだ**（コンパイルと検証シーンの作成までは確認済み）。
- **オンライン対戦（宇宙ごみのロビー・マップ）では、まだ1台のPCに1人しか出てこない。** プレイヤーは「つないだPC1台につき1人」作られる作りのため。
  1台で複数人を本番で遊ぶには、**ホストのPCで席の数だけプレイヤーを出し、それぞれに席の番号を渡す**仕組みが別に要る（チーム分け・カメラ・画面の表示も1人前提）。
- 次の操作は、まだ読み口を通していない（どの席の機器で押しても効く）。
  - 狙い方の切り替え（`HookAimAssist`：1・2・3 キー、十字キー）※オンラインでつないでいないプレイヤーでは、もともと動かない
  - 自分だけ戻る（`SpaceJunkPlayerSetup`：R キー／コントローラのボタン）
  - カメラの切り替え（`SpaceJunkCameraModeSwitch`：C キー）。カメラは画面に1つなので、これは全員共通でよい
- フックのチャージのゲージ（`HookChargeUI`）は画面に1つしか無いので、2人が同時に使うと取り合いになる。検証シーンには置いていない。
- 操作タイプB（`GameSettings` の設定）は全員共通。席ごとには変えられない。
