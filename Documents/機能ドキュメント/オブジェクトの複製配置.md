## この機能は何か

**目の前にある物を複製して、好きな場所に置ける機能。**

脱出ゲームの核になる遊びとして作った。
**置いた物を足場にして高い所へ登る**、という遊び方を想定している。

置ける数には上限があり、超えると**一番古いものから消えていく**。
そのため「どこに置くか」を考える必要が生まれる。

## 遊ぶ人から見た動き

画面の中央に**照準（レティクル）**が出ている。これが狙いの位置。

**狙った物は色が変わる**ので、「これに対して操作できる」と一目で分かる。

| 狙っている物 | 色の変化 |
| --- | --- |
| **複製できる物**（`Duplicable`） | **水色**になる。Eで複製できる |
| **自分が置いた物**（`PlacedClone`） | **橙色**になる。Rで消せる |
| それ以外 | 変わらない |

色が変わると、あわせて**レティクルも同じ色になり、少し大きくなる**。

| 操作 | 結果 |
| --- | --- |
| **E** | 見ている物を複製する。半透明ではなく**緑色**の状態で出てくる（まだ置いていない印） |
| **マウスを動かす** | 複製した物が、**視線の先に付いてくる**（向きは変わらない） |
| **マウスホイール** | **自分との距離を前後に動かす**（0.5m〜12m。0.25mずつ） |
| **Z / X / C を押しながらマウス移動** | **置く前に回す**（それぞれ X軸・Y軸・Z軸まわり） |
| **マウス中ボタンを押しながら移動** | **3軸まとめて自由に回す** |
| **Q** | **押すたびに切り替え。** ONだと視点に合わせて向きも回る。OFFだと向きは固定 |
| **T** | **XYZすべて0の、地面と平行なまっすぐの向きに戻す** |
| **左クリック** | その場所に**確定して置く** |
| ~~**Escape**~~ | ~~置くのをやめる（複製した物は消える）~~ → **いまは効かない。** 2026/9/8から Escape は**ポーズ画面が先に受け取る**ため、押すとポーズ画面が開く（置きかけの物は残る）。やめるキーは `Cancel Key` で変えられる。**閉じ方によっては置きかけの物が消える・置かれる可能性がある**（`リスクリスト.md`） |
| **R** | 自分が置いた物を見て押すと、**その物を消す** |

### 空中にも置ける

地面に貼り付けるのではなく、**視線の先の一定の距離に固定**している。
そのため**面が無いところにも置ける**。

ただし**壁や物にめり込む場所には置けない**。次の3段構えで防いでいる。

1. **正面に壁があると、その手前で止まる。** 壁の向こう側には置けない
2. **他の物と重なる場所を狙ったときは、一番近い置ける場所へ自動でずれる。**
   狙った所に置けなくても、すぐ横や上の空いている場所に吸い付くように収まる
3. 近く（初期設定で1.5m以内）に置ける場所がまったく無いときだけ、
   **直前に置けた位置でプレビューが止まる**

物が傾いていても厚みを計算しているので、斜めに置いても刺さらない。

> **ずれた先が壁の向こうにならないよう**、自分からその場所まで壁が無いことも確認している。
> 薄い壁をすり抜けて反対側に置かれることはない。

> プレビューが完全に動かなくなったら、それは**周りに置ける場所が無い**という合図。
> 少し下がるか、マウスホイールで距離を変えると動き出す。

置いた瞬間に**物理が働く**ので、空中に置けばそこから落ちる。
落として当てる・積み上げる、といった遊びはそのままできる。

> 落とさずに**その場へ固定したい**場合は、インスペクターの `Keep Floating After Place` を ON にする。
> 空中に浮いたままの足場が作れるようになるが、**落ちなくなるので物同士がぶつかる遊びはできなくなる**。

### 向きを自分で決める

**Q を押すたびに、2つのモードが切り替わる。**

| モード | 動き |
| --- | --- |
| **向き固定**（初期状態） | 視点を動かしても**位置だけが動き、向きは変わらない**。<br>複製した物は**地面と平行**な状態で出てくる（見上げていても傾かない） |
| **視点追従**（Qで切り替え） | 視点を動かすと**向きも一緒に回る**。見上げながら複製すれば傾いた状態になる |

押しっぱなしにする必要はなく、**1回押すたびに切り替わる**。
複製する前に切り替えておけば、その状態で複製できる。

> 地面と平行で出てくるのは、**箱を積んで足場にする**使い方で毎回まっすぐ置き直すのが面倒なため。
> 傾けたいときだけ、下の回転操作か視点追従モードを使う。

`Align To Camera` を OFF にすると、向き固定のときに**複製元と同じ向き**で出てくるようになる。

### 軸ごとに回す

**キーを押しながらマウスを動かす。**

| 操作 | 回る向き | マウスを動かす方向 |
| --- | --- | --- |
| **Z を押しながら** | X軸まわり（前後に倒れる） | **上下** |
| **X を押しながら** | Y軸まわり（その場で左右に向きを変える） | **左右** |
| **C を押しながら** | Z軸まわり（左右に倒れる） | **左右** |
| **マウス中ボタンを押しながら** | **3軸まとめて自由に回る**（つかんで転がす感じ） | 上下・左右 |

**押している間、回る向きを示す輪が出る。** どの向きに回るかが一目で分かる。

| 輪の色 | 軸 |
| --- | --- |
| **赤** | X軸 |
| **緑** | Y軸 |
| **青** | Z軸 |

中ボタンでの自由回転のときは、**3色すべての輪**が出る。

- **回している間は、視点が動かなくなる。** 物だけが回る
- **T** を押すと、**XYZすべて0の完全にまっすぐな向き**に戻る（地面と平行、向きも正面）。
  このとき**視点追従は自動でOFF**になる。ONのままだと、次の瞬間に視点の向きへ戻ってしまうため
- 回る速さは `Rotation Sensitivity` で変えられる
- **`Rotation Snap` に `15` などを入れると、その角度単位で止まる**（初期値は0＝滑らかに回る）
- 回した分は**複製するたびにリセット**される

回した向きは、壁や重なりの判定にもそのまま使われる。
**斜めに倒した板は、その傾いた形で置ける場所を探す**ので、隙間にも差し込める。

### 置ける数の制限

- 初期設定では**5個**まで置ける
- 6個目を置くと、**一番最初に置いた物が消える**
- 消える前に**0.5秒間、赤く点滅して知らせる**（いきなり消えると理由が分からないため）

### 物によって重さが違う

| 複製元 | 重さ | 特徴 |
| --- | --- | --- |
| **CloneSourceLightBox**（黄色い箱） | 1 | 軽い。押すと動く |
| **CloneSourceHeavyBox**（灰色の箱） | 30 | 重い。安定した足場になる |
| **CloneSourceFragilePlank**（桃色の板） | 2 | **強くぶつかると壊れる**。上から重い物を落とすと砕ける |

壊れやすい板は、**軽い物を静かに乗せる分には壊れない**。
重い箱を上から落とすと壊れる。「重さを考えて積む」遊びを作るための仕掛け。

> ⚠️ `Keep Floating After Place` を **ON にすると置いた物が落ちなくなるため、板は壊れません。**
> 空中に浮いた足場を作る遊びと、物を落として壊す遊びは**両立しません**。
> 初期設定は「落ちる」側（OFF）にしてあります。

| --- | --- |

## 自分のシーンで使う方法

1. `PlayerRig` をシーンに置く
2. `PlayerRig` に **`ObjectCloner`** コンポーネントを追加する
3. インスペクターで次の3つをつなぐ
   - `Aim Camera` … `PlayerRig` の中の `PlayerCamera`
   - `Player Root` … `PlayerRig` 自身
   - `Input Actions` … `Assets/InputSystem_Actions`
4. 複製させたい物に `Duplicable` タグと `Rigidbody` を付ける

### どこで設定するか

1. `Assets/Scenes/Prototype/ObjectCloner/ObjectClonerTest.unity` を開く
2. 左の**ヒエラルキー**で **`PlayerRig`** を選ぶ
3. 右の**インスペクター**に **`Object Cloner`** が出るので、そこで調整する

**再生中でも動かせて、その場で結果を確認できる**（ただし再生を止めると元に戻るので、

## 仕組み（分かる人向け）

- 設計は依頼時の参考コードを踏襲している。
  **プレビュー中は物理オフ（`isKinematic = true` / `Collider.enabled = false`）、確定時に有効化**、
  配置順は **`Queue<GameObject>`** で管理する
- 狙いは**画面中央からのRaycast**。参考コードは `ScreenPointToRay(Input.mousePosition)` だったが、
  一人称でカーソルを画面中央に固定しているため、**カメラ正面へのRayに変更**した
- **自分自身とプレビュー中の物はRayの対象から外している。** 除外しないと、
  カメラがキャラクターのカプセルの内側にあるため自分に当たって前に進まない
- 置く位置は **照準（画面中央）の線の上**で決めている。
  当初は当たった面に貼り付ける方式だったが、**空中に置けるようにするため固定距離方式に変更**した
- ただし**距離はカメラからではなく「自分の頭（CameraPivot）から」数えている。**
  TPSではカメラが後ろに下がっているため、カメラから数えると**置く位置が自分の足元になってしまう**。
  カメラから頭までの距離を足すことで、**FPSでもTPSでも同じ感覚で置ける**ようにしている
- 狙える距離（複製・削除）も同じ理由で、自分からの距離で測っている。
  また、**カメラと自分の間にある物**（＝自分の背後にある物）は狙いの対象から外している
- 置く向きは、複製した瞬間の向きを基準として持ち、**視点追従がONの間（Qで切り替え）だけカメラの向きで更新**する。
  そこに自分で回した分（`manualRotation`）を掛け合わせて最終的な向きを出している
- 重なりの判定は **`Physics.OverlapBoxNonAlloc`**。物を置いたときの箱の形で、
  中に他の物が入っていないかを調べている。傾きもそのまま渡しているので斜めでも正しい
- 置けないときは、狙った場所を中心に**14方向（上下左右前後＋斜め）× 距離を少しずつ広げて**調べ、
  最初に見つかった場所を使っている。近い順に調べるので、**最初に見つかったものが一番近い場所**になる。
  この探索は**置けないときだけ**走るので、普段は負荷にならない
- 壊れる判定は `OnCollisionEnter` の **`collision.impulse`**（ぶつかった瞬間の勢い）で見ている。
  質量と速度の両方が効くので、**重い物ほど遅くても壊せる**

### 参考コードから変えたところ

| 変えた点 | 理由 |
| --- | --- |
| `Input.GetKeyDown` → **Input System** | このプロジェクトは Input System に統一する決まりのため |
| マウス位置のRay → **画面中央からのRay** | 一人称でカーソルを固定しているため |
| 自分自身をRayから除外 | カメラがカプセルの内側にあり、自分に当たってしまうため |
| 色を戻す処理を作り直し | **一度 `renderer.material` に触ると `sharedMaterial` も複製側を指すようになり、元の色を取り出せなくなる**ため、変える前に色を控える方式にした |
| 削除時にキューを作り直す処理を修正 | 元のコードは新しいキューを作って差し替えていたが、`readonly` で保持する形にしたため中身を詰め直す方式にした |

## できていないこと・既知の問題

- **動作確認はUnityの再生で行っていない。** コンパイルが通ることと、
  参照が正しくつながっていることまでは確認済み。**実際の操作感は未確認**
- **回すキー（Z / X / C / T）は他の操作と重ならないように選んでいる**が、
  今後キーを増やすときは重複しないか確認すること
- **狙った場所と実際に置かれる場所がずれることがある**（近くの空いている場所へ自動で移動するため）。
  意図した動きだが、**ずれた理由は画面に出ていない**（色を変えるなどの表示は入れていない）
- **探す方向は14方向・刻みは0.25mの決め打ち**なので、細かい隙間にはうまく入らないことがある。
  `Search Step` を小さくすると入りやすくなるが、処理は重くなる
- **空中に浮いたままの足場は、初期設定では作れない**（置いた物は落ちる）。
  作りたい場合は `Keep Floating After Place` を ON にするが、その場合は質量ギミックが働かなくなる
- **プレビュー中は半透明ではなく色だけ変えている。** 半透明にするにはマテリアルの
  設定変更が必要で、複製元ごとに影響が出るため避けた
- **置ける数を画面に表示していない。** いま何個置いてあるかは見えない。
  `ObjectCloner.PlacedCount` と `MaxPlacedObjects` を公開してあるので、UIから読める
