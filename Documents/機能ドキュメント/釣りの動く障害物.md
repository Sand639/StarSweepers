## この機能は何か

**釣りのステージの中を、決まった道すじで動き続ける長めの長方形の障害物。**

プレイヤーは障害物を**通り抜けられない。** 障害物が動いてきたら、プレイヤーは**押し出される。**
床に転がっている物資や、投げた物資も押しのけられる。

「ここを通りたいけど、障害物が来るタイミングを見ないといけない」という駆け引きを作るためのもの。

---

## 遊ぶ人から見た動き

| 場面 | 結果 |
| --- | --- |
| 障害物に向かって歩く | ぶつかって止まる（通り抜けられない） |
| 動いてきた障害物に当たる | 障害物の外へ押し出される |
| 物資が障害物の通り道にある | 押しのけられる |
| 投げた物資が障害物に当たる | 跳ね返る |

### 動き方は2種類

| 動き方（Mode） | 動き | 例 |
| --- | --- | --- |
| **PingPong** | 最後の場所まで行ったら、**来た道を戻る** | A → B → C → B → A → … |
| **Loop** | 最後の場所まで行ったら、**最初の場所へ直行してぐるぐる回る** | A → B → C → A → B → … |

それぞれの場所に着いたら、少し止まる（止まる秒数は変えられる）。

## 検証シーンの作り方・確かめ方

1. Unityで、スクリプトのコンパイルが通るのを待つ（Consoleに赤エラーが無いこと）。
2. メニュー **`Tools > StarSweepers > 釣りの障害物の検証シーンを作る`** を実行。
3. Console に「【障害物】釣りの障害物の検証シーンを作りました。」が出れば成功。
4. `Assets/Scenes/Test/FishingObstacleTest.unity` が開くので、再生する。

シーンの中身は「ステージ」検証シーン（四方のポケット・物資8個）に、**紫の障害物を3つ**足したもの。
障害物だけを確かめやすいように、爆発物は置いていない。

| 名前 | 場所 | 動き |
| --- | --- | --- |
| `Obstacle_NorthSlide` | 北側 | 東西に行って戻る（速め） |
| `Obstacle_SouthLoop` | 南側 | 四角くぐるぐる回る。角で少し止まる |
| `Obstacle_WestSlide` | 西側 | 南北に行って戻る。**ゆっくり止まって、ゆっくり動き出す** |

> 障害物を選ぶと、**シーン画面に道すじが橙の線で出る**（通る場所ごとに箱の輪郭も出る）。ゲーム画面には出ない。

このシーンは**検証用なので、ビルドには入れない**こと。

## 自分のステージに置くには

1. `GameObject > 3D Object > Cube` で箱を置き、長めの形に伸ばす（例：Scale `6, 1.2, 1`）。
2. `MovingObstacle` を付ける（Rigidbody も自動で付く）。
3. Inspector の **Points** に通る場所を入れる。

- **Points は「置いた位置からのずれ」**（メートル）。障害物ごと移動させると、道すじも一緒についてくる。
- 向きは置いたときのまま変わらない。**傾けずに、Y（水平）の回転だけ**で置くこと。
- **壁との間は、プレイヤーが通れる幅（1m以上）をあけて置く。** 挟まるとめり込む（`リスクリスト.md`）。

### オンライン対戦で使うとき

**そのままシーンに置けばよい。NetworkObject も要らない。**
位置を「時計」から計算しているので、全員で共有している時計を読むだけで、どのPCでも同じ場所に来る。
（ただし、いまのオンライン会場 `FishingOnline.unity` はツールで作り直すと上書きされる。
**障害物を置いたオンラインのマップは、`釣りのマップ作りとマップ選び.md` の手順で作ったマップ（`FishingMap〜`）に置くこと。**
雛形には見本の障害物が1つ入っているので、複製して使うのが簡単。）

## 設定できる値（インスペクターの項目）

### MovingObstacle ※障害物に付いている

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| **Points** | 通る場所。**置いた位置からのずれ**（X＝東西、Z＝南北）で書く。2つ以上必要 | `(-6,0,0)` `(6,0,0)` |
| **Mode** | `PingPong`（行って戻る）／`Loop`（ぐるぐる回る） | PingPong |
| **Move Speed** | 動く速さ（1秒あたりのメートル） | 3 |
| Wait Seconds | それぞれの場所に着いたときに止まる秒数 | 0.5 |
| Ease In Out | ONにすると、動き出しと止まる直前がゆっくりになる | OFF |
| Start Offset Seconds | 動きを何秒ぶん先へずらすか。**同じ道すじに2つ置くときに間をあける**のに使う | 0 |
| Push Skin | 押し出すとき、ぴったりより少しだけ余分に離す距離（引っかかり防止） | 0.02 |

検証シーンの3つには、上とは別の値が入っている（シーンの表を参照）。

## 仕組み（分かる人向け）

- **位置は時刻の関数。** `Points` から「止まる→動く」の区間（`Leg`）の一覧を作り、1周の秒数で割った余りから、いまどの区間のどこにいるかを計算する。
  状態を持たないので、**同じ時刻なら必ず同じ位置**になる。
- **オンラインは共有の時計を読むだけ。** `NetworkManager` がつながっている間は `ServerTime` を使う。
  `ServerTime` は `Update` ごとにしか進まないので、`FixedUpdate` でそのまま読むとカクつく。
  そこで `Update` で「共有の時計 − このPCの時計」の差を測っておき、`FixedUpdate` では `Time.fixedTimeAsDouble + 差` で計算している。
  つながっていないときは、シーンを開いてからの秒数を使う。
- **動かし方はキネマティックの Rigidbody を `MovePosition`。** こうすると、ぶつかった物資（普通の Rigidbody）は物理で押しのけられる。
- **プレイヤーは自分で押し出す。** `CharacterController` は「自分で `Move` したとき」しか衝突しないので、動いてきた物に押されない。
  そこで毎物理フレーム、障害物のまわりを `OverlapBoxNonAlloc` で調べ、重なっている `CharacterController` を
  **真上から見た「長方形と円」の重なりが無くなるぶんだけ** `Move` で動かしている。
- **オンラインでは各PCが自分のプレイヤーだけを押す。** 「他の人のぶん」の `CharacterController` は `FishingNetPlayer` が切ってあるので、
  `enabled` なものだけを押せば、自然に自分のぶんだけになる。押された位置は `NetworkTransform` が全員に配る。

## できていないこと・既知の問題

- **⚠ まだ再生して確かめていない。** コンパイルが通ることだけ確認済み。
- **壁との間に挟まると、障害物がプレイヤーにめり込む**（`リスクリスト.md` に登録）。置き方で回避する。
- **フックは障害物をすり抜ける。** 壁をすり抜けるのと同じ（フック側が物資しか見ていないため）。
- **引き寄せ中の物資も障害物をすり抜ける。** 引き寄せ中は物理を止めているため（壁と同じ）。
- 回転しながら動く障害物は作れない（向きは置いたときのまま）。
- 見た目は仮（紫の箱）。
- オンライン会場（`FishingOnline`）には置いていない。**マップの雛形（`FishingMap〜`）には見本が1つ入っている**（上の「オンライン対戦で使うとき」参照）。
