## この機能は何か

**決まった間隔で上がり下がりする床（エレベーター）。**
STAGE_01 の真ん中にある**一段高い土台**に上がるための床として作った（大槻さんの設計図。2026/10/8）。

プレイヤーはジャンプできず、段差も 0.3m までしか登れない。そのため、土台の上に行くには**この床に乗って上がる**しかない。

あわせて、STAGE_01 を設計図どおりに作り直した（下の「STAGE_01 の作り」）。

---

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| 床が下にいる | 上面が地面より少しだけ高い（0.01m）ので、そのまま歩いて乗れる |
| しばらくすると | 床がゆっくり上がり、上面が土台の上面と同じ高さで止まる。そのまま土台へ歩いて移れる |
| 上でしばらく止まると | ゆっくり下がって地面の高さに戻る。これをくり返す |
| 床の上に立っている | **床と一緒に上がり下がりする** |
| 床の上に素材がある | 床に押し上げられる（物理で運ばれる） |

- 東西の2つと南北の2つは、**半分ずつずらして**動く。どれかが上にいる時間が長くなるようにするため
- 床は**地面より下まで伸びた柱**になっている。上がりきっても下にすき間ができず、下にもぐり込めない

## STAGE_01 の作り

大槻さんの設計図（SVG。リポジトリの外にある）を **1m＝10px** として読み取り、地面の中心を原点にした。

| 物 | 場所 | 大きさ（作ったときの目安） |
| --- | --- | --- |
| 床（`Ground`） | 真ん中 | 36m × 30m |
| ゴール（`GoalArea_West`・`GoalArea_East`） | 床の外の東西（x＝±20） | 4m × 5m。番号は今までどおり 3（西）・1（東） |
| 土台（`Base`。オレンジ） | 真ん中 | 20m × 10m、高さ 1.5m |
| 上下する床（`LiftFloor_West` `_East` `_North` `_South`。ピンク） | 土台の4辺の真ん中にくっつけて置いた | 2.4m 四方 |
| ノックバック爆弾（`BombPoints`） | 土台の上の四隅寄り（x＝±8、z＝±3.5） | — |
| 重いデブリ（`HeavyDebrisPoint`） | 土台の上の真ん中。**イベントの重いデブリと同じ物**（投げられず引きずるだけ・高得点・水色）。ゴールに入れたり場外に落ちたりして消えたら、少し待って同じ場所にまた出る | — |
| 素材の出る範囲（`SpaceJunkSpawner`） | 床全体（**土台の上にも出る**） | 36m × 30m |

- 設計図に壁が無いので、**床のまわりの壁は消した**（STAGE_07 と同じ。ゴールの囲いだけ残してある）。落ちたら復活時間のあと戻る
- 前の STAGE_01（30m × 30m・壁あり・土台なし）から作り直した

## 設定できる値（インスペクターの項目）

### `LiftFloor`（SpaceJunkLiftFloor）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Rise Height | 下から上まで何m上がるか | 1.49（土台の高さ 1.5 − 下にいるときの高さ 0.01） |
| Move Seconds | 上がる（下がる）のにかける秒数 | 1.5 |
| Wait Bottom Seconds | 下で止まっている秒数 | 2 |
| Wait Top Seconds | 上で止まっている秒数 | 2 |
| Time Offset Seconds | 動くタイミングをずらす秒数（STAGE_01 では南北の2つだけ、1周の半分ずらしてある） | 0 |
| Carry Height | 床の上面から、どの高さまでにいる人を「乗っている」とみなすか（m） | 1.5 |

**決まり（変えると壊れる）**

- **置いた位置が「下にいるとき」の位置。** 下にいるときの上面は、**地面より少しだけ（0.01m ほど）高く**置く。地面とぴったり同じ高さにすると、面が重なってちらつく（Zファイティング。2026/10/8 大槻さんの報告）
- **上がりきったときの上面を、土台の上面と同じ高さにする**（Rise Height ＝ 土台の高さ − 下にいるときの高さ）。土台の高さだけ変えると、上がりきっても土台に移れない
- 床（柱）の高さ（Scale の Y）は **Rise Height 以上**にする。足りないと、上がったときに下にすき間ができる
- 土台は、スポナーの **Drop Height より低く**する（それより高いと、土台の上に素材が出ない）
- 上の3つは自動テスト（`Stage01LayoutTests`）で確かめている。Unity の **Window → General → Test Runner** の EditMode から実行できる

### `SpaceJunkSpawner`（追加した項目）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Spawn On Raised Floor | ON にすると、**土台など一段高い床の上にも**素材を出す。OFF だと、高い床の上は「何かある」とみなされて出ない | OFF（STAGE_01 では ON） |

## 仕組み（分かる人向け）

- 床の高さは**時計から計算**する。通信中は全員で同期された時計（ServerTime）、1人用のときはシーンが始まってからの秒数。床そのものは通信しない（回転する床 `SpaceJunkRotatingFloor` と同じやり方）
- 動きは「下で待つ → 上がる → 上で待つ → 下がる」のくり返し。動き出しと止まる前はゆっくり（SmoothStep）
- 床は動く Rigidbody（キネマティック）で、物理の更新（FixedUpdate）で MovePosition する。上に乗った素材は物理で押し上げられる
- プレイヤー（CharacterController）は動く床に押されないので、**床の上の範囲にいるプレイヤーを、床が動いたぶんだけ自分で動かす**。動かすのは、**そのプレイヤーを動かしている本人のPCだけ**（回転する床と同じ理由）
- スポナーの Spawn On Raised Floor は、出す場所の真下の床の高さを調べ、そこを基準に「空いているか」を確かめる。プレイヤーと、物理で動く物（素材・爆弾）は床とみなさない

---

## できていないこと・既知の問題

- **オンラインで、ホスト以外のプレイヤーも一緒に運ばれるかはまだ確かめていない**（回転する床と同じ作りなので、運ばれるはず）
- 床が下がるときは、プレイヤーが一瞬だけ床から浮く（床より先にプレイヤーを動かせないため。重力ですぐ着地する）
- 素材の最大数は前の STAGE_01 のまま（15個）。床が広くなった（30m×30m → 36m×30m）ので、少なく感じたら Spawner の Max Objects を増やす
- ゴールの手前（プレイヤーが出てくる場所）は、ゴールから4m内側（x＝±16）。土台やエレベーターとは重ならない
