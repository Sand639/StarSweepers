## この機能は何か

宇宙ごみ集めのフックを、**ZR（Xbox の呼び方では RT）ひとつだけで遊べる投げ方**。
今の操作（左で撃つと引っ張る・右で撃つと投げる）とは**別の投げ方**として作り、**ポーズ画面の「設定」で切り替えられる**。

流れはこう：

1. ZR でフックを撃つ（押して溜めて、離すと飛ぶのは今と同じ）
2. 物資に引っ掛かると、**前へ投げる動き**に入る（物資が弧を描いて頭の上まで上がり、そこで構える）
3. その間に**スキルチェックのゲージ**が左から右へ1回だけ動く
4. **枠の中で ZR を押すと、後ろへ引っ張る**（物資がすばやく頭上を越えて、後ろへ飛んでいく）
5. **何も押さなければ、ゲージが右端に着いたところで前へ投げる**（向いている方向）

**ねらい（小野田さんの案）**：前へ投げるのは、ゲージが最後まで動くのを待つぶん**全体の時間が長くなる**。
だから途中で**後ろへ引っ張るほうが早く次へ移れる**というメリットが生まれる。ボタンが1つなので**操作も比較的楽**。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ポーズ画面 →「設定」→「投げ方」 | 「**投げ方：左右で使い分け**」（今までどおり）と「**投げ方：ZRワンボタン**」が切り替わる。**選んだものはPCに保存される** |
| ZR（RT）／右クリックを押して離す | フックが飛ぶ（溜めた長さで飛距離が決まる。今と同じ） |
| 物資に引っ掛かる | 物資が弧を描いて頭上へ上がり、頭上で構える。**ゲージが1回だけ動く**（真ん中に枠） |
| ゲージが**枠の中**にあるときに ZR | **後ろへ引っ張る。** 真ん中に近いほど強く（遠くまで）飛ぶ |
| ゲージが**枠の外**にあるときに ZR | **ミス。** もう引っ張れず、そのまま前へ投げる（連打で当てられないようにするため） |
| 何も押さない | ゲージが右端に着いたところで、**向いている方向へ前に投げる**（強さは一定） |

- ZRワンボタンのときは、**LT（左クリック）ではフックを撃たない。** 操作タイプBで LT を「向きだけ変える」に使っていても、ぶつからない
- **横取り**（ほかの人がつかんでいる物資にくっついて待つ）・**大型物件**（引っ張れる床など）・**重いデブリ**のゲージも、**ZR で押す**
- 今までは右で撃ったフックが重いデブリと大型物件に引っ掛からなかったが、ZRワンボタンでは**撃つのがいつも右なので、引っ掛かるようにした**（引っ掛かったあとの動きは今までと同じ。重いデブリは引きずるだけ）
- 画面の下のほうに、いま押せるボタンの案内が出る（「RT（ZR）・右クリック：枠の中で押すと後ろへ引っ張る　押さなければ前へ投げる」）

> **効くのは宇宙ごみ集めのプレイヤーだけ**（`ThrowController` の Style が `TwoButtons` のプレイヤー）。
> 釣りのプレイヤー（Style が `SweepOnce`）は、設定を変えても今までどおり。
>
> **操作タイプBとの関係**：タイプBの「引っ掛けたら物理で引き寄せる」動きより、**投げ方の設定のほうを優先**する。
> ZRワンボタンを選んでいる間は、タイプBでも上の流れになる（移動と向きの操作はタイプBのまま）。

調整したいときは `SpaceJunkPlayer.prefab` の `ThrowController` の「ZRワンボタン」の欄を変える（プレハブを編集することになるので、触る前に一声かける）。

### 確かめ方

1. 宇宙ごみ集めをいつもどおり始める（タイトル → 1人プレイ → ロビー → 試合）
2. Esc（コントローラーは Start）でポーズ → 「設定」→「投げ方：左右で使い分け」を押して「**投げ方：ZRワンボタン**」にする
3. 「もどる」→ ゲームに戻って、ZR（右クリック）で物資を撃つ

## 設定できる値（インスペクターの項目）

`ThrowController` の「**ZRワンボタン**」の欄。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| One Button Swing Seconds | 引っ掛けてから、押さなかったときに前へ投げるまでの秒数。**ゲージはこの秒数で左端から右端へ1回動く**。長いほど「前へ投げる」が遅くなり、後ろへ引っ張る得が大きくなる | 1.4 |
| One Button Lift Seconds | 引っ掛けてから頭上まで持ち上がる秒数。そのあとは頭上で構える | 0.6 |
| One Button Zone Center | スキルチェックの枠の真ん中（0＝左端、1＝右端） | 0.5 |
| One Button Zone Half Width | 枠の広さ（真ん中からの片側）。この中で押すと後ろへ引っ張る | 0.2 |
| One Button Forward Force | 前へ投げる力 | 14 |

後ろへ引っ張ったときの**強さと速さは、今の「引っ張る」と同じ値を使う**（`Pull Force Min / Max`・`Pull Lift`・`Pull Travel Seconds`）。
前へ投げるときの上向きの力は `Throw Lift` を使う。

## 仕組み（分かる人向け）

- 設定は `GameSettings.ThrowOperation`（`ThrowOperationType.TwoButtons` / `OneButton`）。`PlayerPrefs` の `StarSweepers.ThrowOperationType` に保存
- `ThrowController.UsesOneButton` ＝「Style が TwoButtons」かつ「設定が OneButton」。フックを撃つ側（`HookController.TickIdle`）も、引っ掛けたあと（`ThrowController`）もこれを見る
- 引っ掛けたら `BeginTwoButtons` → `StartForwardSwing`。段階 `TwoButtonStage.ForwardSwing` で、
  物資の位置は今の「投げる」の持ち上げと同じ軌道（`UpdateReelPosition(進み具合 × 0.5)`）、ゲージは `経過秒 ÷ One Button Swing Seconds`
- 枠の中で押したら、段階を今の「引っ張る」の途中（`PullTravel`）に切り替える。**いまの持ち上げの進み具合に合わせた秒数から始める**ので、物資は跳ばずにそのまま速く頭上へ進み、頭上で後ろへ投げ出される（`FinishAsPull`）
- 押さなかったら `FinishAsSwingForward` で、向いている方向へ `Launch`。オンラインの投げ（ホストが力を加える）は今の投げと同じ `Launch` を通るので、新しい通信は足していない
- ゲージで押すボタンは `SkillPressed()` にまとめた（いつもは左＝`PullPressed`、ZRワンボタンでは右＝`ThrowPressed`）

## できていないこと・既知の問題

- **Unity で遊んでの確認はまだ**（スクリプトのコンパイルが通ることだけ確かめた）。気持ちよさは秒数と枠の広さで大きく変わるので、遊んで詰める前提
- **オンラインの2人以上ではまだ試していない**。作りは今の「投げる」と同じ道すじ（持ち上げ → `Launch`）なので、新しい通信の心配は少ない
- 枠の外で押したら「ミスで前へ投げる」にした。「何度でも押し直せる」「外で押したら弱く引っ張る」にしたい場合は `質問リスト.md` の回答しだいで変える
- タイトル画面には設定のページが無いので、**切り替えはポーズ画面だけ**
- 1台のPCで複数人（席）のときも、**設定はPCで1つ**（全員が同じ投げ方になる）
