## この機能は何か

**キャラクターの前へ、水のような液体の流れがまっすぐ飛んでいく。流れのまわりには、細い水流がらせん状に巻きつき、回りながら先へ流れていく。**
[らせんをまとったビーム](らせんをまとったビーム.md)（緑の電撃）の**液体版**。操作も使い方も同じ。

- 流れは**波打ちながら**、太いところ・細いところのムラが根元から先端へ流れていく
- 先端は**しずくのようにふくらんでいる**
- 飛んでいる間は先端から**しぶき**が前へ飛び散り、届いたあとは流れのあちこちから**しずくが落ちる**
- 消えるときは、**根元から切れて、残りが先端へ流れ去る**

**色は途中で変えられる。** 「先端に物資がついたら色を変える」演出のために、
**先端から根元へ向かって、新しい色に染まっていく**変え方を用意した（すぐに全体を変えることもできる）。

形はプログラムで毎フレーム作っている（外部の素材は使っていない）。**当たり判定はまだ無い**（見た目だけ）。

## 遊ぶ人から見た動き

検証シーン `LiquidBeamTest.unity` を再生したときの操作：

| 操作 | 結果 |
| --- | --- |
| F を押し続ける | 溜める。口もとに液体の玉がふくらみ、届く距離の目安のうすい線がのびる。画面左上に「溜め ○%　→　○ m」と出る |
| F を離す | 液体が前へ飛ぶ |
| C | **先端に物資がついた想定。**先端から根元へ、オレンジ → 紫 → 緑 → 赤 の順に色が染まっていく |
| R | 最初の色（水色）に戻す |
| F（流れが出ている間） | 止める（根元から切れて消える） |
| H | 出しっぱなしのオン／オフ。**検証シーンでは最初からオン**（色の変わり方を見やすくするため）。オフにすると、届いて 0.6 秒で消える |
| 2 | キャラクターが円を描いて動く／止まる（落ちたしずくが置いていかれるかの確認） |

## 使い方（ほかのシーンで使うとき）

1. `Assets/Prefabs/Effect/LiquidBeam.prefab` を、キャラクターの子にドラッグする。**撃ち出したい位置に動かし、前（青い矢印）を撃つ向きに向ける**（検証シーンでは 0, 1.1, 0.4）
2. ボタンを押した瞬間に `BeginCharge()`、離した瞬間に `Release()` を呼ぶ
3. **先端に物資がついたら** `ChangeColorFromTip(物資の色)` を呼ぶ。戻すときは `ResetColor()`、すぐ変えたいときは `SetColor(色)`
4. 物資をつけている間ずっと出しておきたいなら、インスペクターで **Hold Until Stopped** をオンにし（またはコードで `HoldUntilStopped = true`）、放すときに `Stop()` を呼ぶ
5. 物資を先端にくっつけるときは、`HeadPosition`（先端のワールド座標）を使う

| 使える口（public） | 内容 |
| --- | --- |
| `BeginCharge()` / `Release()` | 溜め始める／撃つ |
| `Stop()` | 止める（出ていれば消し始め、溜め中なら溜めをやめる） |
| `ChangeColorFromTip(Color)` | 先端から根元へ、新しい色に染めていく。流れが出ていないときは、すぐ変わる |
| `SetColor(Color)` / `ResetColor()` | すぐ変える／最初の色に戻す |
| `LiquidColor` | いまの色（変えている途中なら、変えた先の色） |
| `HeadPosition` | 先端の位置（ワールド座標） |
| `HoldUntilStopped` | オンなら `Stop()` を呼ぶまで消えない |
| `IsCharging` / `IsFiring` / `IsHolding` / `Charge01` / `CurrentLength` | いまの状態（溜め中か、出ているか、届ききっているか、溜め具合、いま離したら届く距離） |

## 仕組み（分かる人向け）

**電撃版（`HelixBeam`）との違いは「作り直す」か「流す」か。** 電撃は 0.03〜0.07 秒ごとに形をランダムに作り直すが、
液体は**時間 `flowTime` を使った波で、毎フレーム少しずつ形を動かす**。

- **状態**：待機 → 溜め → 発射（先端が進む）→ 維持 → 消える → 待機（電撃版と同じ。維持は `HoldUntilStopped` で無期限にできる）
- **流れの中心線**：40点。横ゆれは `sin((z - flowTime × flowSpeed) × 2π / 波長)`。根元 1.5m は口から離れないよう小さくする
- **太さのムラ**：2つの波（`0.6 sin(a) + 0.4 sin(2.3a + 1.1)`）を重ねた値を、`LineRenderer.widthCurve` の目印10個に毎フレーム入れる。最後の2個が先端のふくらみ
- **質感**：実行時に作った小さなテクスチャを `_BaseMap` に渡す。線の幅方向に「ふちが濃く、真ん中がやや透ける」ので筒っぽく見える。真ん中に白寄りの細い線を重ねてつやを出す
- **まわりの水流**：1本ずつ寿命（0.3〜0.7秒）を持ち、その間 `startZ` が前へ進み、`phase` が回る。らせんの目印の点 → `LightningShape.SampleHermite` でなめらかにつなぐ（**ギザギザにはしない**）。出るときと消えるときは `sin(π × 経過/寿命)` で細くする
- **しぶき**：`ParticleSystem` を実行時に作り、`Emit` で1粒ずつ出す。**ワールド基準**なので、キャラクターが動いても落ちたしずくはその場に残る
- **色**：色は `LineRenderer` の**頂点カラー（グラデーション）**で付け、明るさ（HDR）は `_BaseColor` で掛ける。
  `ChangeColorFromTip` を呼ぶと、「元の色」と「新しい色」の境目（幅は流れの12%でぼかす）が先端から根元へ `Color Spread Seconds` かけて動く。
  境目の前後に目印を置くので、グラデーションは4つの目印で正確に表せる。水流・しぶき・ライトも、その場所の色を使う
- **消えるとき**：`tailDistance`（根元の切れ目）が 0 から先端まで進み、太さも細くなる。流れ全体から、しずくが多めに落ちる

## できていないこと・既知の問題

- **人がまだ再生して確かめていない。** AIは、画面なしで起動した Unity から静止画を書き出して、溜め・発射・維持・**先端から色が変わる途中**・消える途中の見た目だけ確認した。**動き（流れる速さ・回る速さ・しぶきの量）とブルームの光り方は未確認**
- **当たり判定が無い。** 物資をつけるなら、`Release()` のときに `Physics.SphereCast`（太さのある光線）で距離ぶん調べ、当たった物に `ChangeColorFromTip` と `HeadPosition` を使う形が簡単
- 撃ったあとにキャラクターが動くと、流れも一緒に動く（キャラクターの子にしているため。電撃版と同じ）。落ちたしずくだけはその場に残る
- 毎フレーム `widthCurve` と `colorGradient` を差し替えるので、ごく少しメモリの割り当て（ゴミ）が出る。本数を大幅に増やして重くなったら見直す
- オンライン対応はしていない。「溜め始めた」「撃った（距離）」「色を変えた（色）」だけを RPC で送り、見た目は各PCで作ればよい
