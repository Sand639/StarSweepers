## この機能は何か

爆発に巻き込まれたプレイヤーを、爆弾から離れる方向へ吹き飛ばす別版。
この爆弾ではスタンを与えず、吹き飛ばされている間も移動とフックの操作ができる。
通常の `FishingOnlineBomb` は従来どおりスタンを与える。
巻き込まれた「鉤で引っ掛けられる物資」も消さずに吹き飛ばす。引き寄せ中なら糸を外してから飛ばす。

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| フックで引っ掛ける | 従来どおり導火線に火がつく |
| 爆発に巻き込まれる | 外側へ押し出され、少し上へ飛ぶ。横方向の勢いはだんだん弱まる |
| プレイヤーの真上で爆発する | プレイヤーが向いている方向へ飛ぶ |
| 物資・別の爆弾が巻き込まれる | 消えずに外側と上へ飛ぶ。重さによらず同じ追加の勢いを受ける |
| 引き寄せ中の物資が巻き込まれる | 引き寄せとゲージが終わり、糸が戻る。物資は爆風で飛ぶ |
| 爆発した爆弾自身 | 従来どおり消える |

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Knockback Speed | 横方向へ吹き飛ばす速さ（m/s） | 10 |
| Knockback Lift | 上方向へ飛ばす速さ（m/s）。0で横方向だけ | 5 |
| Object Knockback Speed | 物資に加える横方向の速さ（m/s） | 12 |
| Object Knockback Lift | 物資に加える上方向の速さ（m/s） | 6 |

継承により表示される Player Stun Seconds は、この別版の効果には使わない。

## 仕組み（分かる人向け）

`ExplosiveObject` を継承し、`ApplyPlayerEffect` と `ApplyHookableEffect` を差し替えるため、既存のフック・導火線・カウントダウンがそのまま使える。
プレイヤーは `ILaunchable` を実装し、歩く速度と横方向の外力を合計して元の `CharacterController.Move` で一度に動かす。
上向きの勢いは元の重力処理へ渡し、天井に当たったら止める。オンラインでは本人の有効な移動処理だけが外力を受け取る。
プレイヤーへ Rigidbody は追加しない。連続で巻き込まれた場合は、新しい爆発の勢いで上書きする。
物資には `ForceMode.VelocityChange` で既存の速さへ勢いを足す。同じ物資が複数の当たり判定を持っていても、1回の爆発では1回だけ処理する。
引き寄せている人の処理を終了し、物理を元に戻してから飛ばす。オンラインではホストだけが判定し、引き掛けの予約を消して持ち主を取り戻す。
参加者へは糸を外す合図を送り、位置は既存の同期に任せる。投げ・ミスの追加の力は発生させない。
爆発のたびに番号を進め、爆発前に送られた古い鉤・投げ・解除の指示を拒否する。
遅れて届いた脱鉤や断りの合図は、爆発後に掛け直した新しい引き寄せには適用しない。
断りの合図は依頼番号と対象の物資も確認する。別の物資へ掛け直したあとに古い断りが届いても、その糸は外さない。
