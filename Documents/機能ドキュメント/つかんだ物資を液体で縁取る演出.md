## この機能は何か

**液体の糸（フック）が物資にくっつくと、くっついた所から液体が物資の表面を広がっていき、約0.5秒で物資全体を包んで、ふち（シルエット）が液体の色で光る演出。** リムライト（物の縁が光って浮かび上がる光り方）のイメージ。
「この物資を確保した」と一目で分かるようにするためのもの。

- 広がっている途中は、**広がる先が明るく光る**
- 包みきった瞬間に**一度強く光り**、くっついた所の反対側から**しぶき**が飛ぶ
- つかんでいる間は、ふちの光と外側の液体の膜が**ゆらゆら流れ続ける**（ときどき、しずくが落ちる）
- はなす（投げる・糸が消える）と、**膜が外へふくらみながら消える**。物資が消えた（ポケットに入ったなど）ときは、すぐ消える
- 色は、つかんだあとの糸の色（チームの濃い色）と同じ

物資の**本当の形**に沿って光る（箱なら箱の形、丸い物なら丸く）。物資のマテリアルや子オブジェクトは一切変えず、形を上から重ねて描いているだけ。

> 2026/10/20 の最初の版は「カメラ向きの四角い枠で囲う」形だったが、小野田さんの依頼で**リムライト風に作り直した**。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| フックで物資をつかむ | 糸の色が先端から濃く染まるのと同時に、くっついた所から物資を液体が包み、約0.5秒でふちが光る |
| つかんだまま引き寄せる | 光るふちが物資についてくる |
| 投げる・はなす | 膜が外へふくらみながら消え、しぶきが飛ぶ |

### 検証シーン `LiquidBeamTest.unity` で試す（シーンの作り直しは不要）

| 操作 | 結果 |
| --- | --- |
| F を長押しして離す | 液体のビームを撃つ（出しっぱなし） |
| **G** | **先端に箱をくっつけて、液体で縁取る**（箱はくるくる回るので、向きでふちの光が変わるのも見られる）。もう一度 G で、はなす |
| F（流れが出ている間） | 流れを止める。箱もはなす |

フックで試すなら、釣りや宇宙ごみ集めのシーン（`FishingHookTest.unity` など）でそのまま物資をつかめばよい。

## 設定できる値（インスペクターの項目）

**`LiquidBeam.prefab` を開き、子の「LiquidWrap」を選ぶと変えられる。** 宇宙ごみ・釣りのフックすべてに効く。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Rim Material / Droplet Material | 縁取りのマテリアル（LiquidRim）／しぶきのマテリアル（LiquidAlpha） | ― |
| Brightness | 明るさ（1 より大きいとブルームで光る） | 1.6 |
| Rim Power | ふちの細さ（大きいほど細い）。箱のような平らな面は面ごと光りやすいので大きめ | 4 |
| Rim Strength | ふちの光の強さ（物資の表面の、横を向いた所が光る） | 0.5 |
| Fill Strength | 物資全体にうっすらかかる色（0 でふちだけ） | 0.02 |
| Shell Offset | ふちの光を表面から浮かせる距離（m） | 0.005 |
| Outline Width / Outline Alpha | シルエットの外側を囲う液体の膜の厚さ（m）／濃さ | 0.05 / 0.9 |
| Wobble | 膜の厚さのゆれ | 0.35 |
| Glow Width / Glow Alpha | 膜のさらに外の、うっすらした光の幅（m）／濃さ | 0.12 / 0.25 |
| Flow Speed / Flow Scale | 液体の模様が流れる速さ／細かさ | 2 / 4 |
| Wrap Seconds | くっついてから包みきるまでの時間（秒） | 0.5 |
| Edge Softness | 広がる先のぼかし幅（m） | 0.25 |
| Front Glow | 広がる先の明るさ | 1.5 |
| Close Flash | 包みきった瞬間に一度強く光る強さ | 0.8 |
| Burst Seconds / Burst Expand | はなしてから消えるまでの時間（秒）／外へふくらむ量（m） | 0.3 / 0.35 |
| しぶきの各値 | くっついた時・包みきった時・はなした時の数、落ちるしずくの数、大きさ・速さ・寿命 | ― |

フック側（`HookLine`）で変えられるのは次の3つ。

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Use Wrap | オンなら、物資をつかんだときに縁取る（Use Liquid がオンのときだけ） | オン |
| Wrap Search Radius | つかんだ物資を探す範囲（フックの先からの距離。m） | 0.8 |
| Wrap Max Size | これより大きな物（大きな板など）は縁取らない（m）。物資（HookableObject）には効かない | 5 |

## 仕組み（分かる人向け）

- **描き方**：物資の `MeshRenderer` のメッシュを、`Graphics.RenderMesh` で `LiquidRim` マテリアルを使って毎フレーム**重ね描き**する。物資側には何も足さない（通信の物体にも安全）。値は `MaterialPropertyBlock` で渡す
- **シェーダーの2つのパス**
  - ふちの光（`UniversalForward`・加算）：表面のフレネル（カメラから見て横を向いている所ほど 1）で光らせる
  - 外側の膜（`SRPDefaultUnlit`・半透明）：物資を**中心から外へ押し出して**ふくらませた形の**裏側だけ**を描く。物資の内側は物資自体に隠れるので、シルエットの外側だけが帯になって残る（よくある輪郭線の作り方）。法線で押し出さないのは、箱の角で面が離れてすき間ができるため
  - さらに外の「うっすらした光」は、膜だけを太く・薄くしてもう1回描いている
- **広がり方**：くっついた所（物資から見た位置で覚えるので、物資が動いても回ってもずれない）からの距離が `_Reveal` 以内の所だけ描く。`_Reveal` を 0 から「くっついた所から物資のいちばん遠い角まで」へ `1 − (1 − t)²` で広げる。広がる先は sin の積で波打たせ、明るくする
- **何をつかんだか**：`HookLine.SetGrabbing(true)` の瞬間に、フックの先の近くから探す。物資（`HookableObject.All`）を優先し、無ければ `Physics.OverlapSphere`（自分の体とフックの先は除く）。
  **ほかの人のフックには「何をつかんだか」が通信で届かない**ので、自分のときも同じ探し方にしてある（どの画面でも同じように出る）
- **しぶき**：液体のビームと同じ作りの `ParticleSystem`（ワールド基準・重力あり）を `Emit` で出す

## できていないこと・既知の問題

- **人がまだ再生して確かめていない。**（AIは、コンパイルと、画面なしで起動した Unity の静止画で、箱とカプセルの見た目だけ確認した。**ブルームの光り方と動き**は未確認。静止画にはブルームが効いていない）
- 箱のような**平らな面の物**は、ふちの光が線ではなく面ごと少し色づく（フレネルの性質）。気になるなら Rim Strength を下げ、膜（Outline）を主にする
- `SkinnedMeshRenderer`（骨で動くモデル）と `SpriteRenderer` の物資は縁取られない（`MeshRenderer` だけ）
- 物資自体が半透明だと、膜が物資の内側にも透けて見える（膜は「物資に隠れる」ことで外側だけ残す作りのため）
- 外側の膜は、物資の中心から放射状にふくらませているので、細長い物では長い辺の横の膜が少し細くなる
- `Physics.OverlapSphere` で探すとき、「自分の体」は `transform.root` の下にある物として除いている。プレイヤーがマップ全体の親の下に置かれていると、物資以外（大きな板など）は見つからなくなる（物資は `HookableObject.All` から探すので影響しない）
