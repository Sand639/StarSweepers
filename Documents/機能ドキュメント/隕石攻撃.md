## この機能は何か

宇宙ごみ集めの試合中、設定した床の範囲内へ定期的に隕石が落ちる仕掛け。
地面に危険範囲が先に表示され、数秒後に隕石が落下する。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 危険範囲から離れる | 隕石の爆風を避けられる |
| 爆風に入る | プレイヤーは外側へ吹き飛ばされ、設定した秒数だけ操作できなくなる |
| 素材や爆弾が爆風に入る | 外側へ吹き飛ばされる。爆弾は同時に導火線へ火がつく |

可拉扯大型方塊（`IHookPullable` の大型物）は動かさない。

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Interval Seconds | 前の隕石の終了を待たず、次の攻撃ラウンドを始める間隔 | Prefabは10秒、スクリプト初期値は3秒 |
| Meteors Per Round | 1ラウンドで同時に予告する隕石の数（有効なArea数が上限） | 1個 |
| Warning Seconds | 地面に予告を出してから着弾するまで | 5秒 |
| Fall Seconds | 隕石が上空から地面まで落ちる時間 | 1秒 |
| Spawn At Area Center | 選ばれたAreaの中心へ固定して落とすか | OFF |
| Impact Radius | 爆風と地面予告の半径 | 4m |
| Player Knockback Speed | プレイヤーを横へ飛ばす速さ | 12m/s |
| Player Knockback Lift | プレイヤーを上へ飛ばす速さ | 6m/s |
| Player Stun Seconds | 命中したプレイヤーが操作できなくなる時間。0ならスタンなし | 2秒 |
| Object Knockback Speed | 素材と爆弾を横へ飛ばす速さ | 14m/s |
| Object Knockback Lift | 素材と爆弾を上へ飛ばす速さ | 7m/s |
| Active Areas | 隕石を落としてよい範囲の一覧 | 空 |

## Unityへの設置手順

1. 隕石を追加したい宇宙ごみのマップを開く。
2. Hierarchyで、隕石を落としてよい床を複数選択する。
3. `Tools > StarSweepers > Space Junk > Meteor > Add To Current Scene` を実行する。
4. 場面に `MeteorManager` が1つ作られ、選んだ床の子に `○○_MeteorArea` が作られたことを確認する。
5. 各 `MeteorArea` の緑色の BoxCollider を、床からはみ出さない大きさへ調整する。元の床のColliderは変更されない。
6. `MeteorManager` の `Active Areas` に使いたいAreaが並んでいることを確認し、頻度・予告時間・攻撃半径を調整する。
7. シーンを保存する。

床を選ばずにメニューを実行した場合はManagerだけが置かれる。
その場合は `MeteorArea.prefab` を床の子へ置き、Managerの `Active Areas` へ手で登録する。

見た目は `Assets/Prefabs/SpaceJunk/Gimmick/Meteor/` の各Prefabを直接調整する。
生成メニューは**すでに存在するPrefabを上書きしない**ため、あとから調整した値は消えない。

### 確認すること

- HostとClientで同じ場所・同じ時刻に予告と着弾が見える。
- プレイヤーが爆心から外へ飛び、設定時間だけ移動・フック・引っ張り操作が止まる。
- 得点素材が爆心から外へ飛ぶ。
- 爆弾は飛びながら導火線が点火する。
- `PullAblePlate` などの大型物は動かない。
- 隕石の中心が選ばれたArea内にある。

## STAGE_03への設置

`Assets/Scenes/Prototype/SpaceJunk/Stage/STAGE_03.unity` には設置済み。

- ドーナツ床の外周半径15m・内周半径9mに合わせ、8方向へ `MeteorArea` を配置した。
- 4秒ごとに1ラウンドを始め、1ラウンドで重複しないAreaを3個選ぶ。前の攻撃の終了は待たない。
- 予告は4秒、`Impact Radius` は5m、`Spawn At Area Center` はON。
- 現仕様のAreaは落下中心を決める範囲で、爆風円全体を床内へ収める制限には使わない。
- 真ん中の回転床、東西の橋、ゴール前の床は `Active Areas` に含めていない。
- `Tools > StarSweepers > Space Junk > Meteor > Install Into STAGE_03` を実行すると、同じ配置を作り直さずに再設定できる。

## 仕組み（分かる人向け）

1. `MeteorManager` はホストだけで待ち時間を数え、ラウンドごとに有効な `MeteorArea` を設定数だけ重複なしで選ぶ。
2. `MeteorArea` は BoxCollider 内の落下中心を返す。中心固定がONならAreaの中央、OFFならArea内のランダム位置になる。
3. ホストが選んだ数だけ `MeteorStrikeEvent` の NetworkObject を生成する。前のラウンドのEventが残っていても、設定間隔で次のラウンドを開始する。
4. 全PCがサーバー時刻を使って同じ予告・落下・着弾を表示する。
5. プレイヤーは各自のPCで吹き飛ばしと既存の `PlayerStun` を受ける。素材と爆弾はホストだけが吹き飛ばし、爆弾は既存の `FishingNetBomb` で導火線を同期する。
