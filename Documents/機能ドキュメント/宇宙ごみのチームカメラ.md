## この機能は何か

**自陣を画面の手前にしたまま、自分と味方がいつも画面に入るように映すカメラ。**

前からある「自陣カメラ」は自分だけを追いかけるので、味方が画面の外に出てしまう。
チームカメラは、味方が離れると**少し引いて（ズームアウトして）**、全員が入るようにする。

ただ、ふつうに「チームの真ん中」を追いかけると、**自分が止まっているのに、味方が動くたびに自分の画面が動いて気持ち悪い**。
そこで、次の工夫を入れてある。どれもインスペクターで強さを変えられる。

| 工夫 | 何をするか |
| --- | --- |
| **遊び** | 見たい場所のズレが小さいうちは、**カメラを横に動かさない**。決めた範囲からはみ出した分だけ動く |
| **自分に寄せる** | 画面の真ん中を、チームの真ん中より**自分寄り**にする。いっぱいまで寄せると、味方が動いても横には動かず、**ズームだけ**で味方を入れる |
| **寄るのは待ってから・ゆっくり** | 味方が離れたら**すぐ引く**（画面から出ないように）。近づいてきたときは、**少し待ってからゆっくり寄る**（行ったり来たりでズームが揺れないように） |
| **上下の揺れを抑える** | ジャンプや段差での上下の動きには、ゆっくりしか付いていかない |
| **追いすぎない** | 遠く離れた味方・落ちた味方は追わず、**自分を優先**する |

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **`C` キー**（コントローラーは **Back**） | 「全体 → チーム → 自分 → 全体 …」の順にカメラが切り替わる（なめらかに移る） |

- 切り替わるのは**自分の画面だけ**
- 画面の左上に「［C／Back］でカメラ切り替え　いま：チーム（全体／チーム／自分）」と出る
- どのカメラでも、**W＝画面の奥**に進む
- 始まったときは、いまは**全体カメラ**（2026/10/6 の大槻さんの決めのまま）。チームカメラから始めたいときは、プレハブの `SpaceJunkCameraModeSwitch` の **First Mode** にチームカメラの部品をドラッグする

## 試し方（検証シーン）

**`Assets/Scenes/Test/SpaceJunkTeamCameraTest.unity`** を開いて再生する。**通信なしで、1台で A と B を別々に動かせる。**

| 操作 | 結果 |
| --- | --- |
| WASD ／ Space | A（自分）を動かす ／ ジャンプ |
| 矢印キー ／ 右 Shift | B（味方）を動かす ／ ジャンプ |
| B の「Wander（勝手に歩く）」 | ON（最初から ON）だと、キーを押していない間 B が勝手に歩き回る。**「A が止まっていて B だけ動く」場面**がすぐ作れる |
| C | カメラの種類を切り替える |
| Tab | 「自分」を A ⇔ B で入れ替える（**B のPCの画面がどう見えるか**を確かめられる） |
| Q ／ E | 自陣の向きを 90 度ずつ回す（自陣が南・東・北・西のチームの見え方） |

- 再生中に、カメラ（`SpaceJunkStageCamera`）の **SpaceJunkTeamGroupCamera** の値を変えると、すぐ効く
- **シーンビュー**には、黄色の四角（遊びの範囲）・水色の点（見たい場所）・緑の線（映している人）が出る。水色の点が黄色の四角から出ると、カメラが動く
- 再生を止めると値は戻る。**気に入った値は、部品の右上の「︙」→ Copy Component → 止めてから Paste Component Values** で残す
- 検証シーンのカメラは**ステージと同じプレハブ**。値を決めたら、カメラを選んでインスペクター上部の **Overrides → Apply All** でプレハブに書き戻すと、STAGE_01〜05 にもそのまま入る（**プレハブの変更になるので、ほかの人に一声かけてから**）
- 検証シーンを作り直すとき：`Tools > StarSweepers > 宇宙ごみのチームカメラの検証シーンを作り直す`

## 調整のしかた

| こう感じたら | 触る値 |
| --- | --- |
| 自分が止まっているのに、味方が動くと画面が動く | **Dead Zone Width／Depth を広げる**、または **Self Weight を 1 に近づける** |
| カメラがなかなか付いてこない・急にまとめて動く | Dead Zone を狭める、Follow Sharpness を上げる |
| ズームが行ったり来たりする | **Zoom In Delay を長く**、Zoom In Sharpness を下げる、Zoom In Dead Band を上げる |
| 味方が画面の端で切れる | Screen Margin を上げる、Zoom Out Sharpness を上げる |
| 引きすぎて自分が小さい | Max Distance を下げる（入らない味方は画面の外に出る）、Teammate Max Distance を下げる |
| ジャンプで画面が上下に揺れる | Height Sharpness を下げる |
| 画面が回るのが気持ち悪い | Turn Sharpness を下げる |

### 組み合わせの例（目安）

| ねらい | Self Weight | Dead Zone（幅×奥行き） | Zoom In Delay |
| --- | --- | --- | --- |
| **自分の画面をなるべく動かさない**（ズームだけで味方を入れる） | 1 | 4×3 | 1.5 |
| **バランス**（実装したときの初期値） | 0.5 | 6×4 | 0.8 |
| **チーム全体を見渡す**（2人で協力する場面が多いとき） | 0 | 8×6 | 0.8 |

## 設定できる値（SpaceJunkTeamGroupCamera）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Display Name | 画面の案内に出す名前。空なら「チーム」 | 空 |
| In Cycle | C キーの切り替えに入れるか | ON |
| Pitch | 見下ろす角度 | 58 |
| Face Own Side | 自陣を手前に回すか（OFF なら全員北向き） | ON |
| Turn Sharpness | 向きが変わるときの回りのなめらかさ | 6 |
| Self Weight | 画面の真ん中を、どれだけ自分に寄せるか（0＝チームの真ん中、1＝自分） | 0.5 |
| Include Teammates | 味方を映すか（OFF で自分だけ。比べる用） | ON |
| Teammate Max Distance | これより離れた味方は映さない（メートル） | 40 |
| Ignore Below Height | この高さより下の人は映さない（落ちた人） | -4 |
| Member Padding ／ Member Height | 人のまわりの余白・頭の高さ（メートル） | 1.5 ／ 2 |
| Dead Zone Width ／ Depth | 遊びの幅（画面の横）・奥行き（メートル）。0 で遊び無し | 6 ／ 4 |
| Follow Sharpness | 遊びからはみ出したときに追いかけるなめらかさ | 5 |
| Height Sharpness | 上下への付いていき方 | 1.5 |
| Min Distance ／ Max Distance | カメラの距離のいちばん近い・遠い | 18 ／ 36 |
| Screen Margin | 画面の端に空けるすき間（割合） | 0.12 |
| Zoom Out Sharpness ／ Zoom In Sharpness | 引く・寄るなめらかさ | 4 ／ 1 |
| Zoom In Delay | 寄り始めるまで待つ秒数 | 0.8 |
| Zoom In Dead Band | 必要な距離との差がこの割合より小さければ寄らない | 0.1 |
| Draw Gizmos | シーンビューに遊びの範囲などを描く | ON |

切り替えの部品（`SpaceJunkCameraModeSwitch`）・全体カメラ・自分カメラの値は `宇宙ごみのカメラ切り替え.md`。

## ほかのカメラの案（まだ作っていない）

チームカメラの調整で足りなければ、次の案がある。`やりたいことリスト.md` にも載せた。

| 案 | どんなものか | よいところ ／ 気になるところ |
| --- | --- | --- |
| **自陣固定カメラ** | 自陣の半分（自分のゴールと真ん中あたり）が収まる位置で**止まったまま** | 味方が動いても**絶対に動かない**。敵陣に攻め込むと自分が画面から出る |
| **全体カメラを自陣向きに** | 全体カメラの「Face Own Side」を ON にする（**設定だけで試せる。作ってある**） | 動かないうえ、自陣が手前で操作の向きと合う。ステージが大きいと人が小さい |
| **画面の外の味方に矢印** | 味方が画面の外に出たら、画面の端に矢印と名前を出す | 「自分カメラ」でも味方の場所が分かる。カメラを動かさずに済む |
| **進む方向を少し先に見る** | 自分が走っている方向へ、画面の真ん中を少しずらす | 先が見えて遊びやすい。動きが増えるので酔いやすい人もいる |
| **段階ズーム** | ズームを「近い・中くらい・遠い」の3段だけにして、間を素早く移る | 常にじわじわ動くのが無くなる。切り替わる瞬間は目立つ |
| **Cinemachine（Unity公式のカメラの部品）** | 遊び・複数人を映す・揺れの抑えが最初から入っている | 調整の項目が多く、高機能。**パッケージを足すので大槻さんの確認が要る** |

## 仕組み（分かる人向け）

毎フレーム、選ばれている間だけ `TryGetPose` が呼ばれ、「カメラを置きたい位置と向き」を返す（実際に動かすのは `SpaceJunkCameraModeSwitch`）。

1. 映す人を集める：自分（`FishingNetPlayer.IsOwner`）＋同じチーム（`SpaceJunkSession.TeamOf`）の人。離れすぎ・落ちた人は外す
2. 向き：自陣が手前（`SpaceJunkCameraMode.OwnSideYaw`。自分カメラと同じ）
3. 見たい場所 ＝ 「全員を囲む範囲（画面の向きで測る）の真ん中」と「自分」を Self Weight で混ぜた点
4. 遊び：見る点との差を、画面の横・奥行きに分けて、遊びの半分をはみ出した分だけ目標を動かし、なめらかに追う。高さは別のなめらかさ
5. ズーム：全員（足元のまわりと頭）が画面の端から Screen Margin 内側に入る、いちばん近い距離を二分探索（カメラは動かさず、投影の計算だけで判定）。引くときはすぐ、寄るときは Zoom In Delay 待ってからゆっくり。寄り始めたら最後まで寄りきる

検証シーンでは `SpaceJunkCameraTestTargets` があると、通信のプレイヤーの代わりにそこに入れた人を「自分」「味方」として使う。

通信なしで計算だけ確かめた結果（2026/10/7）：A が止まっていて B が小さく動き回る間、**カメラの移動量は 0**。B が 20m 離れると引いて 2人とも画面内。B が戻ると最小の距離まで寄る。B が 60m 先・落下したときは B を追わない。

## できていないこと・既知の問題

- **オンラインで遊んでの確認がまだ。** 味方の位置は通信で届いた位置なので、届き方がガタつくと画面も揺れる可能性がある（遊びがあるので、小さなガタつきは吸収されるはず）
- 敵は映さない（味方だけ）
- 3人以上のチームでも動く作りだが、試したのは2人
- 始まりのカメラは全体カメラのまま（チームカメラを主にするなら First Mode を変える。上の「遊ぶ人から見た動き」）
