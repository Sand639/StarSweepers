## この機能は何か

キャラクターの服の色と顔の表情を切り替えるための部品。ゲームから呼び出すための入口がある。既存プレイヤーや通信への接続は未確認。

## 遊ぶ人から見た動き

| 操作 | 結果（コードから確認した内容。再生未確認） |
| --- | --- |
| 服の色を指定 | 元の色または指定した色で表示する |
| 表情を指定 | Null・Neutral・Yes・No・Annoyed・Huh・Excitedの画像に切り替える |
| 再生中に待つ | Neutral・Annoyed・Huhでは、自動まばたきが有効なら一時的にNullの画像へ切り替える |

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 |
| --- | --- |
| Character Renderer | 見た目を変更するモデルの表示部品 |
| Body / Face Material Index | 体と顔のマテリアルの番号 |
| Color Property・Color Mode・Custom Color | 色の項目名、元の色と指定色の選択、指定する色 |
| Expression Textures・Current Expression | 各表情の画像と表示する表情 |
| Enable Blinking・まばたき間隔と時間 | 自動まばたきの有効・無効とタイミング |

## 仕組み（分かる人向け）

MaterialPropertyBlockで、対象Rendererのマテリアル番号ごとに色や画像を指定する。表情は `SetExpression` または `SetExpressionByIndex`、服の色は `SetCustomColor` などで変更する。まばたきは再生中のみ動く。

- Unityでの読み込み、表情・色・まばたき、ビルド、通信同期は未確認。
- シーンには両スクリプトへの参照が保存されているが、再生して動作を確認したものではない。
