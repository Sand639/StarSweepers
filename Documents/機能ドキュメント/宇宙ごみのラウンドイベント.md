## この機能は何か

**宇宙ごみ集めのラウンドの途中で「イベント」が起きる仕組み。**

ラウンドが始まって（**START から**。始まりの演出の間は数えない）**20秒たつと**、あらかじめ用意した**イベントの候補の一覧から1つがランダムに選ばれて**始まる。
イベントごとに「何秒続くか」が決めてあり、0秒ならラウンドの終わりまで続く。

いまあるイベントは3つ。

| イベント（初期の名前） | 中身 | 続く時間（初期値） |
| --- | --- | --- |
| **デブリセット** | チームごとにデブリ4〜6個のお題が出る。そのうち3個を入れると10点 | ラウンドの終わりまで |
| **期間限定高価値デブリ** | デブリの種類が1つ選ばれ、時間内はその種類が +2点 | 15秒 |
| **特殊デブリ** | 重さを決めた大きなデブリが出る。投げられず、引きずってゴールへ入れると高い得点 | ラウンドの終わりまで |

**画面に出るイベントの名前と説明は、設定で自由に変えられる**（下の「設定できる値」）。

これまでの「同じ種類を3回続けて入れると +5点」は、**デブリセットに置き換えて廃止した**（2026/9/29・大槻さん）。

## 遊ぶ人から見た動き

| いつ | どうなるか |
| --- | --- |
| START〜20秒 | デブリをゴールに入れると **1個1点**。ボーナスは無い |
| 残り5秒前から | 画面の上に「**イベントまで 5・4・3…**」と出る |
| 20秒たったとき | 画面に「**イベント発生！　（名前）**」と説明が4秒間出る |
| イベント中 | 画面の上に「イベント：（名前）」と出続ける。時間が決まっているイベントは「**残り ○ 秒**」も出る |
| 時間が過ぎたとき | 「**イベント終了：（名前）**」に変わる。ボーナスはもう入らない |

### デブリセット

- **チームごとに、デブリを4〜6個ランダムに選んだ「お題」が出る**（例：白・白・紫・橙・橙）
  - **お題の個数は、イベントが始まったときに1回だけ決まり、全チーム同じ**（4個なら全チーム4個）。**中身はチームごとにばらばら**
  - デブリは3種類（白＝装甲板、紫＝回路基板、橙＝燃料タンク）しか無いので、**同じ種類が2個以上入ることもある**
- **お題のうち、どれでも3個を自陣のゴールに入れると 10点**。そのあと**次のお題が出て、0から集め直す**（次のお題も同じ個数）
- 順番の扱いは2通りあり、設定（Debris Set Ordered）で切り替える

  | 設定 | 進み方 |
  | --- | --- |
  | **順不同（OFF・初期値）** | お題に入っていて、まだ足りていない種類なら進む |
  | 順番どおり（ON） | **お題の先頭から順に、次の1個と同じ種類のときだけ進む**（先頭から3個で完成） |

- お題に無いデブリや、もう足りているデブリを入れても、**ふつうの1点は入る**

画面の左のチームの欄に、得点の下にお題が出る。印はデブリの色で、**■ はもう入れた、□ はまだ**。

- 順不同のとき … 「**お題 1/3 → +10　■□ □ ■□**」のように、入れた数と、同じ種類をまとめた印が並ぶ
- 順番どおりのとき … 「**お題 1/3 → +10　■ ▶□ □ □ □**」のように**左から順に**並び、**次に入れる1個に ▶** が付く

### 期間限定高価値デブリ

- 始まると、**デブリの種類（白・紫・橙）から1つがランダムに選ばれる**
- **15秒のあいだ、その種類を自陣のゴールに入れると +2点**（ふつうの1点と合わせて3点）
- 始まったときの合図と、画面の上の「イベント：〜　残り ○ 秒」の横に、「**紫（回路基板）のデブリが +2点**」のように**その種類の色で**出る
- デブリの見た目は変わらない（種類の色で見分ける）

> 2026/9/29 に作り直した。最初は「金色に光るデブリが3個降ってきて、時間内に入れると10点」だった。

### 特殊デブリ

- 始まると、**重さを決めた大きなデブリ**が降ってくる（初期値は **3個**。**重さは1個ずつ、1〜3 の間からランダム**（小数第1位まで。例：1.4、2.8）。水色に光る。重いほど大きい）
  - 重さの範囲 X〜Y は設定で変えられる。**X と Y を同じにすると、全部その重さになる**
- ゴールに入れると、1点の代わりに **20点**。**重さボーナスを ON にすると、重いほど高い**（初期値は OFF。下の「設定できる値」）
- 画面の上に「**特殊デブリ あと ○ 個（1個 20点・引きずるだけ）**」と出る。レーダーでは水色の大きめの点
- **投げられない。引きずることしかできない**

  | 操作 | どうなるか |
  | --- | --- |
  | 右クリック（RT）でフックを撃つ | **引っ掛からない。** 当たってもそのままフックが戻る |
  | 左クリック（LT）でフックを撃つ | くっついた場所で止まって、ゲージが出る |
  | ゲージ | **往復しない。** 左端から右端へ1回だけ進み、**重いほど速い** |
  | ゲージの途中で左クリック（LT） | **頭上は越えずに、地面を引きずってプレイヤーのほうへ寄せる**。距離は下の式で決まる |
  | 押さずに右端まで行った | **少しだけ**引きずって終わる（0.8m ÷ 重さ） |

  **引きずる距離（m）＝ 引っ張る強さ（6m）÷ 重さ ×（1 − ゲージの真ん中からのずれ）**

  | 重さ | ど真ん中 | 真ん中と端の間 | 端・押さなかった |
  | --- | --- | --- | --- |
  | 1 | 6m | 3m | 0.8m |
  | 2 | 3m | 1.5m | 0.4m |
  | 3 | 2m | 1m | 約0.27m |

  - 「ずれ」は、真ん中で0、端で1。**いちばん短くても 0.8m ÷ 重さ は動く**（少し引っ張る）
  - **プレイヤーの手前 1.5m で止まる**（重なったり追い越したりしないように）
  - 2026/9/29 に「プレイヤーとの中間まで」（離れているほど大きく動く）から、**離れ具合に関係ない決まった距離**に変えた

- 何回か引きずってゴールまで運ぶ遊びになる（重いほど回数が要る）
- **ゴールの上まで引きずって手を離せば入る**（つかまれたまま入ったデブリも、手を離した時点で数える）
- 画面の下の案内は「重い！（重さ 2）　左クリック（LT）：引きずる　真ん中ほど遠くまで」

> 画像の後半（「ゴールに入れたあと、一定時間後に新しい特殊超高価物品が出る。後から出るものほど高得点」）は、
> **今回は作っていない**（2026/9/29・大槻さんの判断）。

## 設定できる値（インスペクターの項目）

`SpaceJunkSession.prefab` の **「イベント（得点制のときだけ起きる）」** の欄。

### 全体

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Start Seconds | ラウンドが始まってから、何秒後にイベントを始めるか。**ラウンドの最大時間より長いと、イベントは起きない** | 20 |
| Pool | **イベントの候補の一覧。** 1行ごとに下の5つを決める。空ならイベントは起きない | デブリセット・期間限定高価値デブリ・特殊デブリ の3行 |

### Pool の1行ごと

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Kind | どのイベントか（`DebrisSet` ／ `HighValueDebris` ／ `HeavyDebris`。`None` にすると「今回は何も起きない」の当たりになる） | ― |
| **Display Name** | **画面に出す名前。** 空なら初期の名前 | 「デブリセット」「期間限定高価値デブリ」「特殊デブリ」 |
| **Description** | 始まったときに出す一言の説明。**空なら初期の説明**（設定の値に合わせて文が変わる） | 空 |
| Duration Seconds | 続く秒数。**0 ならラウンドの終わりまで** | デブリセット 0 ／ 高価値デブリ 15 ／ 特殊デブリ 0 |
| Weight | 選ばれやすさ。ほかの行と比べた比で決まる（1 と 2 なら 2 のほうが2倍）。0 なら選ばれない | 1 |

> **名前と説明はホストの値が全員へ配られる。** 参加者のPCの設定は使われない。

### デバッグ用（1つのイベントを固定で出す）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| **Debug Force Event** | `None` 以外にすると、**抽選せずに毎回そのイベントを出す**（Weight は無視）。Pool にその種類の行があれば、その行の名前・説明・続く秒数を使う。無ければ初期の名前で、ラウンドの終わりまで続く | None |

- **確かめ終わったら `None` に戻すこと。** 戻し忘れに気づけるよう、固定で出したときはホストの Console に黄色の警告が出る
- 早く確かめたいときは、あわせて **Start Seconds**（何秒後に始めるか）を小さくするとよい

## 新しいイベントの足し方（分かる人向け）

1. `SpaceJunkEvents.cs` の `SpaceJunkEventKind` に種類を1つ足し、`DefaultName` と `DefaultDescription` に初期の名前と説明を書く
2. `SpaceJunkRoundEvents.cs` の `ServerStartEvent`（始まったときにやること）・
   `ServerEventBonusOnCollect`（デブリが入ったときのボーナス）・`ServerFinishEvent`（時間が過ぎたときの片付け）に、その種類の分岐を足す
3. 画面に進み具合を出すなら、`SpaceJunkMatchUI.cs` の `DrawEventProgress` か `DrawEventNotice` に足す
4. `SpaceJunkSession.prefab` の Pool に1行足す（**入れないと選ばれない**）。
   スクリプトの初期値（`SpaceJunkEventSettings.pool`）に足しても、**プレハブで一度でも Pool を触っていれば、そちらが優先される**ので注意

## 仕組み（分かる人向け）

- **判定するのはホストだけ。** 何秒後に始めるか・どのイベントか・名前と説明・お題の中身・高価値の種類・どれが重いデブリか・得点は、ホストが決めて全員へ配る
  （`NetworkVariable` / `NetworkList`）。参加者のPCは受け取って出すだけ
- 時刻は残り時間と同じく**全員で同期された時計（ServerTime）**で持っているので、カウントダウンや残り秒数はどのPCでも同じになる
- `SpaceJunkRound` を `partial`（1つのクラスを複数のファイルに分けて書く書き方）にして、イベントの部分を `SpaceJunkRoundEvents.cs` に分けた。
  **マップのシーンに部品を足さずに済む**ようにするため（マップが6つあり、全部に足すのは手間で競合も起きやすい）
- デブリセットのお題は「並び順そのもの」（チーム4つ × 8枠）と「種類ごとに何個必要か」（チーム4つ × 種類3つ）の両方で持っている。順番どおりのときは前者と「何個目まで入れたか」、順不同のときは後者で判定する
- デブリセットの個数は、イベントの始まりにホストが1回だけ決めて覚えておき、どのチームがお題を引き直すときもその個数を使う
- **重いデブリは、ふつうのデブリのプレハブをそのまま使っている。** ホストがスポナーに新しく出させ、「通信の番号（NetworkObjectId）と重さ」の一覧を配る。
  各PCは一覧を見て、そのデブリに `HeavyHookable`（大きさ・質量）と `SpaceJunkHighValueMark`（水色）を実行中に付ける（プレハブを変えずに済むように）。
  色は元のマテリアルを書き換えず上から塗り重ねている（MaterialPropertyBlock）ので、外せば元の色に戻る。
  大きさは通信で同期していない（デブリの NetworkTransform は大きさを送らない設定）が、全員が同じ一覧から同じ大きさにするのでそろう
- **フックの操作（`ThrowController` / `HookController`）は釣りと共用。** 重い物の扱いは「`HeavyHookable` が付いていて、宇宙ごみ式（TwoButtons）のとき」だけ効く。
  釣りでは `HeavyHookable` を付けないので、**釣りの動きは変わらない**
- 引きずっている間は、ほかの引き寄せと同じく物理を止めて位置を直接動かしている（引っ掛けた人が持ち主なので、その人の位置が全員に配られる）
- **得点制（Score）のときだけ起きる。** 前のルール（ThreeKinds）ではその場で決着がつくので、イベントは起きない

## できていないこと・既知の問題

- **遊んでの確認はまだ。** コンパイルが通ることだけ確かめた（2026/9/29）。とくに**重いデブリの水色の見た目**（マテリアルの色の名前が `_BaseColor` 以外だと色が変わらない）と、**複数人で大きさ・色がそろって見えるか**を確かめてほしい
- **ロビーのゲーム設定からは変えられない。** 秒数・候補・名前はプレハブのインスペクターで変える
- **イベントは1ラウンドに1回だけ。** 終わったあとに別のイベントが始まることはない
- デブリセットのお題は完全なランダムなので、**同じ種類ばかり（白・白・白・白・白など）が出ることもある**。
  偏って困るようなら、スポナーの出やすさ（Plate / Circuit / Fuel Weight）に合わせる等を検討する
- 重いデブリは**ふつうのデブリの上限（60個）を無視して**足される（上限いっぱいでも出るように）
- **重いデブリを引きずるとき、壁は考えていない。** まっすぐプレイヤーのほうへ動かすので、間に壁があるとめり込む・すり抜ける可能性がある（`リスクリスト.md`）
- 重いデブリの大きさは、元のデブリに対する倍率。**ふつうのデブリの形のまま大きくなるだけ**で、専用の見た目は無い
- 特殊デブリの続く秒数を決めた場合、時間が過ぎると残りは**ふつうのデブリに戻る**（消えない）
- 画面の表示は `OnGUI` の仮のもの
