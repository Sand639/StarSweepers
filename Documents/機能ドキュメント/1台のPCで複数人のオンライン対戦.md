## この機能は何か

宇宙ごみ集めのオンライン対戦で、**1台のPCから2人以上が参加できる**ようにした。
たとえば「PC A に2人、PC B に2人」の4人対戦や、「ホストのPCだけで2人」の対戦ができる。

ロビーにいる間、画面の右に「**このPCで遊ぶ人数**」の小窓が出る（ロビーの画面のプレハブとは別の、ドラッグで動かせる窓）。ここを 2 以上にすると、
そのPCのプレイヤーが人数ぶん出てくる。それぞれ**別々のキーボード＋マウス、またはコントローラ**で動かす。

**人数が 1（初期値）のままなら、今までとまったく同じ動き。**

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ロビーの「このPCで遊ぶ人数」で「＋」を押す | このPCのプレイヤーが1人増える（ホストが出す）。ロビーの一覧に「（1人目の名前） P2」のように出る |
| 「－」を押す | 増やしたプレイヤーが消える（1人目は消えない） |
| キーを押す／マウスを動かす／コントローラのボタンを押す | 押した順に P1・P2… に入る。欄に「P1：キーボード ○ マウス ○ コントローラ －」のように出る |
| 「キーボード・マウスを登録」 | 決まったキーボード・マウスを決まった P に固定する（`席ごとの入力と機器の固定登録.md` と同じ。画面の案内どおりに押す） |
| 「割り当てをやり直す」 | 押した順の割り当てを消してやり直す |
| P1 の機器で操作 | そのPCの1人目が動く。P2 の機器なら2人目 |
| ホストがチーム分けを開く | 同じPCの2人も**別々に**チームを選べる（同じチームでも別のチームでもよい） |

- 人数はロビーにいる間だけ変えられる。試合が始まったら、試合が終わってロビーに戻るまでそのまま。
- 人数は全部のPCを合わせて最大 8 人（`SpaceJunkTeams.MaxPlayers`）。1台は最大 4 人。

## 設定できる値（インスペクターの項目）

インスペクターの項目は無い。人数はロビーの画面で決める。
コードで変えるときは `LocalMultiplayer.PlayerCount = 2;`（ロビーの画面が変化に気づいて、ホストへ伝える）。

## 仕組み（分かる人向け）

- **2人目以降の出し方**：NetworkManager は「つないだPC1台につき1人」しか自動では出さない。
  そこで、各PCがロビーの画面から `SpaceJunkSession.RequestLocalPlayerCount(人数)` でホストへ頼み、
  **ホストが Player Prefab を `Instantiate` して `SpawnWithOwnership(そのPC, false)` で出す。**
  持ち主がそのPCなので、そのPCで動かせる（1人目と同じ「動きは本人」の形）。`false` はシーンを切り替えても消さない指定で、1人目と同じくマップへ付いていく。
  出す前に `FishingNetPlayer.ServerInitLocalSeat(何人目)` で「そのPCの何人目か」を決めておく（出したときに全員へ届く）。
- **人ごとの番号（`PlayerKey`）**：チーム分けの席（`SpaceJunkPlayerSlot.ClientId`）は、これまで接続番号＝PC1台だった。
  **接続番号の上の桁（56ビット目から）に「何人目か」を入れた番号**を使うようにした。**1人目は接続番号そのまま**なので、1台1人のときは何も変わらない。
  接続番号に戻すときは `LocalMultiplayer.ClientOf`、何人目かは `LocalMultiplayer.SeatOf`。
- **どの機器で動くか**：そのPCの持ち主のプレイヤーは、毎フレーム `PlayerInputSource.SeatIndex` を「人数が2以上なら何人目か、1なら -1」にする。
  席（P1・P2…）の管理役 `InputSeatManager` は、人数を2以上にしたときに `LocalMultiplayer` が**シーンをまたいで残る形で1つ作る**（マップに移っても割り当てが消えない）。
  画面のマウスカーソルは隠さない（ロビーの画面のボタンを押せるように）。
- **画面に1つしか無い物**（カメラの追いかけ・フックのゲージ・レーダー・戻るキーの案内・狙い方の表示）は、**そのPCの1人目にだけ**結びつける。
- **物の取り合い**：引っ掛けは「参加番号（PlayerIndex）」で見分けていたのでそのまま動く。
  ただ「断りを返す相手」と「答え合わせで外してよい人か」の2か所が「そのPCの誰か」で探していたので、参加番号で探すようにした。
- **抜けたとき**：PCの接続が切れると、Netcode がそのPCの持ち物（2人目以降も含む）を消す。席も接続番号でまとめて消す。
  1秒ごとの席の答え合わせ（`ServerCheckSlots`）も、2人目以降の席が残っていないか・無い人がいないかを見る。

## できていないこと・既知の問題

- **キーボード・マウス・コントローラを実際につないで遊ぶ確認はまだ。**
- **develop の新しいロビーの画面（プレハブ）に合わせたあとの動きは、まだ Unity で確かめていない**（コンパイルが通ることだけ確認）。人数の欄は、プレハブを触らずに済むよう OnGUI の小窓にした。ロビーの画面に組み込むなら、ロビーの画面の担当（大槻さん）に相談してから。
- 2人目以降の名前は、PCごとに1つしか名前を入れないので「（1人目の名前） P2」になる。人ごとに名前を付けるならタイトル画面から作り替えが要る。
- 1台で複数人のときは、このPCの人どうしを見分けられるように、**自分たちの頭の上にも名前のタグを出す**。
- **人数を減らす（「－」で2人目以降を消す）動きは、まだ試していない。**
- **フックのゲージ（`HookChargeUI`）は画面に1つしか無いので、2人目以降には出ない。** 引っ張る・投げるのタイミングのゲージが見えないまま遊ぶことになる。
  人ごとにゲージを出すには、ゲージを体の上に出す形などへ作り替えが要る → `リスクリスト.md`
- **カメラは1人目を追いかける。** 追いかけるカメラのマップでは、2人目が画面の外へ出てしまう。**全体が映るカメラ（`SpaceJunkStageCamera` の全体表示）で遊ぶ**のが前提。
- 画面の「自分のチーム」の表示（`SpaceJunkMatchUI`）や自陣向きのカメラは、そのPCの1人目のチームを使う。同じPCの2人が別のチームだと、2人目から見ると逆になる。
- 復活までの残り秒数の表示は1人目のぶんだけ。
- 試合中に人数は変えられない（ロビーに戻ってから）。
- 1台に1人のPCと、1台に複数人のPCが混ざっていても遊べる作りだが、組み合わせの確認はまだ。
