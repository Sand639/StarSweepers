## この機能は何か

**ラウンドが始まるときの演出。** 前はマップに着いた瞬間に始まっていたが、マップを見せてからカウントダウンで始まるようにした。

### いまの流れ（2026/10/20〜）

| 順番 | 何が起きるか | 長さ（初期値） |
| --- | --- | --- |
| ⓪ 読み込み待ち | 全員の読み込みを待つ。カメラは ① の回り始めの位置で止まったまま。真ん中に**マップの名前**と「**ラウンド ○**」 | 1.5 秒 |
| ① マップの紹介 | **マップの中央（0,0,0）を向いたまま**、真上（Y軸）から **45度** 傾けた所を、中央を中心に **180度** 回る。最後に自分のチームの側に来る | 5 秒 |
| ② 自分のチームに寄る | 自分のチームの後ろ（マップの外側、少し上）へ寄る | 1.5 秒 |
| ③ カウントダウン | 「**3**」「**2**」「**1**」。カメラは ② の位置で止まる | 3 秒 |
| ③-1 チームの周りを回る | チームの中央を中心に **220度** 回る。② の位置から回り始め、**少し下・少し近く**へ移りながら回る（180度のところでマップの内側を通る） | 2 秒 |
| ③-2 全体カメラへ戻る | ふだんのカメラ（全体カメラ）の位置へ戻る | 1.7 秒 |
| ④ START! | **動けるようになる。**「START!」を出す | 1 秒表示 |

- ⓪〜③-2 の間は**誰も動けず、素材・爆弾・隕石も出ない**（カウントダウンのあとの回る・戻るの間も動けない）
- 「チームの中央」は、自分と同じチームのプレイヤー全員の位置の平均。味方が離れているほど、少し離れて映す
- **残り時間とイベント（お題セットなど）は START から数える**（演出のぶん減らない）。**演出中は、決めた制限時間（60秒なら 60）のまま止まって見える**
- 列車・回転する床・ベルトコンベアは、演出中も動いている（全員で同期された時計で動くため）
- **時間は全員で同期された時計で決めている**ので、どのPCでも同じタイミングで START になる

### 前の流れ（2026/10/7〜10/19。参考）

マップの上をぐるっと160度回る（4秒）→ 自分のプレイヤーの後ろへ寄る（1.5秒）→ 3・2・1 → START! と同時に動けるようになり、0.7秒でふだんのカメラへ戻る。マップの中央はゴールの位置の平均から求めていた。

## 設定できる値（マップに置いた SpaceJunkRound の「始まりの演出」）

**いろいろ試すために、秒数と角度は全部ここで変えられる。**
ラウンドごとにマップのシーンを読み込み直すので、**再生中に変えた値は次のラウンドで元に戻る。** 試すときは再生を止めてからマップのシーンで変えて保存する（シーンの変更になるので、ほかの人と同じマップを同時に触らないこと）。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Play Intro | OFF にすると演出をせず、すぐに始まる | ON |
| Intro Lead Seconds | ⓪ 全員の読み込みを待つ秒数 | 1.5 |
| Intro Flyover Seconds | ① マップを回って見せる秒数 | 5 |
| Intro Look Center | ① カメラが向き続ける場所（マップの中央） | (0, 0, 0) |
| Intro Flyover Tilt | ① 真上から何度傾けた所から見るか（0 で真上、90 で真横） | 45 |
| Intro Flyover Degrees | ① マップの中央を中心に回る角度 | 180 |
| Intro Zoom Seconds | ② 自分のチームに寄る秒数 | 1.5 |
| Intro Countdown Seconds | ③ カウントダウンの秒数 | 3 |
| Intro Team Orbit Seconds | ③-1 チームの周りを回る秒数（0 で回らない） | 2 |
| Intro Team Orbit Degrees | ③-1 チームの周りを回る角度 | 220 |
| Intro Team Orbit Distance | ③-1 回るときの、チームの中央からの距離 | 5 |
| Intro Team Orbit Height | ③-1 回るときの高さ（② で寄ったときは 3.5） | 1.5 |
| Intro Return Seconds | ③-2 全体カメラへ戻る秒数。戻り終わると START! | 1.7 |

- ① のカメラの遠さは、マップの大きさ（中央からいちばん遠いゴール＋4）から自動で決めている
- ② で寄ったときの距離（後ろへ 6・高さ 3.5）は、いまはコードの中の決まった値。試したくなったら設定に出す

## 仕組み（分かる人向け）

- `SpaceJunkRound` に `playStartServerTime`（NetworkVariable）がある。ホストが開始時に「いま＋待ち＋①＋②＋③＋③-1＋③-2」を入れる。`endServerTime` とイベントの開始時刻もここから数える
- 演出の各段階の切れ目は、`IntroStartServerTime`（＝ `playStartServerTime` − 演出の長さ）からの経過時間で決める。設定の秒数は、どのPCも同じシーンの値を使うので一致する
- `IsIntro` ＝ Playing 中で、まだ `playStartServerTime` より前。`IsPlaying` は演出中 false なので、`PlayAllowed` を見ているもの（スポナー・爆弾・隕石・操作）は全部止まる
- 演出が終わった瞬間（`IsIntro` が true → false）に、全員のPCで自分の操作を戻す
- カメラは**ふだんのカメラとは別のカメラ**（`RoundIntroCamera`、深さを上げて重ねる）を一時的に作って動かす。ふだんのカメラの動きには手を出さない。③-2 で `Camera.main`（ステージのカメラ。最初は全体カメラ）の位置へ寄せ、START で止める
- チームは `SpaceJunkSession.TeamOf(クライアントID)` で見る。チームが分からないとき（セッションが無い検証など）は自分のプレイヤーだけを使う

## できていないこと・既知の問題

- **2026/10/20 の作り直しは、Unity 上での見た目をまだ確認していない**（コンパイルが通ることだけ確認）
- 「全体カメラへ戻る」は、正確には「**いまのステージのカメラ**へ戻る」。最初は全体カメラなので同じだが、演出中に C キーで切り替えると、切り替えたカメラへ戻る
- 文字はコードで作っている（プレハブではない）。見た目を凝りたくなったらプレハブにする
- 演出中に列車がプレイヤーにぶつかると、止まったまま押される
- ラウンドの最中に入ってきた人には演出は出ない（すでに START 後のため）
