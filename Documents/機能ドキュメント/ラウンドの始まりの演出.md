## この機能は何か

**ラウンドが始まるときの演出。** 前はマップに着いた瞬間に始まっていたが、マップを見せてからカウントダウンで始まるようにした。

| 順番 | 何が起きるか | 長さ（初期値） |
| --- | --- | --- |
| 0. 待ち | 全員の読み込みを待つ（遅いPCでも最初から見られるように） | 1.5 秒 |
| ① マップの紹介 | カメラがマップの上をぐるっと回る。真ん中に**マップの名前**と「**ラウンド ○**」 | 4 秒 |
| ② 自分に寄る | カメラが自分のプレイヤーの後ろへ寄る（最後に自分の側に来るように回る） | 1.5 秒 |
| ③ カウントダウン | 「**3**」「**2**」「**1**」 | 3 秒 |
| ④ START! | **動けるようになる。** カメラがふだんの位置へ戻る | 0.7 秒で戻る |

- 演出の間は**誰も動けず、素材・爆弾・隕石も出ない**
- **残り時間とイベント（お題セットなど）は START から数える**（演出のぶん減らない）
- 列車・回転する床・ベルトコンベアは、演出中も動いている（全員で同期された時計で動くため）
- **時間は全員で同期された時計で決めている**ので、どのPCでも同じタイミングで START になる

## 設定できる値（マップに置いた SpaceJunkRound の「始まりの演出」）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Play Intro | OFF にすると演出をせず、すぐに始まる | ON |
| Intro Lead Seconds | 全員の読み込みを待つ秒数 | 1.5 |
| Intro Flyover Seconds | マップをぐるっと見せる秒数 | 4 |
| Intro Zoom Seconds | 自分に寄る秒数 | 1.5 |
| Intro Countdown Seconds | カウントダウンの秒数 | 3 |

## 仕組み（分かる人向け）

- `SpaceJunkRound` に `playStartServerTime`（NetworkVariable）を足した。ホストが開始時に「いま＋待ち＋紹介＋寄る＋カウントダウン」を入れる。`endServerTime` とイベントの開始時刻もここから数える
- `IsIntro` ＝ Playing 中で、まだ `playStartServerTime` より前。`IsPlaying` は演出中 false なので、`PlayAllowed` を見ているもの（スポナー・爆弾・隕石・操作）は全部止まる
- 演出が終わった瞬間（`IsIntro` が true → false）に、全員のPCで自分の操作を戻す
- カメラは**ふだんのカメラとは別のカメラ**（`RoundIntroCamera`、深さを上げて重ねる）を一時的に作って動かす。ふだんのカメラ（全体／自陣）の動きには手を出さない。START のあと、ふだんのカメラの位置へ寄せてから消す
- マップの真ん中と大きさは、そのマップのゴールの位置から求める（ゴールが無ければ見える物の範囲）

## できていないこと・既知の問題

- 文字はコードで作っている（プレハブではない）。見た目を凝りたくなったらプレハブにする
- 演出中に列車がプレイヤーにぶつかると、止まったまま押される
- ラウンドの最中に入ってきた人には演出は出ない（すでに START 後のため）
