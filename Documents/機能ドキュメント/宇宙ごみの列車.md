## この機能は何か

**15秒に1回、ステージの真ん中を北から南へ高速で通り過ぎる列車。**
当たったプレイヤーや物資は弾き飛ばされる。ステージの壁も外したので、**飛ばされると下へ落ちていく**。

企画メモ（呉さん）のねらい：物を投げるのを邪魔する・真ん中にいる人を落とす（「避けられない！」「おい！ふざけんな！」）。

---

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| 15秒ごと | 北の画面の外に列車が現れ、南の画面の外まで一直線に走る（約2秒） |
| 列車に当たる（プレイヤー） | 線路の外側＋列車の進む向き＋少し上へ飛ばされる。1回の通過で1回だけ |
| 列車に当たる（素材・爆弾・特殊デブリ） | 同じように飛ばされる。フックで引っ掛けていたら外れる |
| ステージの外へ落ちる（プレイヤー） | **高さ -8m より下で、自動で出てくる場所に戻る**（ラウンド中は3秒動けない）。もともとある仕組み |
| ステージの外へ落ちる（物資） | 高さ -5m より下で消える。素材はスポナーが補充し、爆弾・特殊デブリは3秒後に元の場所へまた出る |

- 走っていないときは、列車は見えず当たらない
- 最初の列車が来るまでの時間は、ラウンド開始から 0〜15秒 のどこか（全員で同じ時計を使っているため）

## 使い方（STAGE_02）

1. Unityで `STAGE_02.unity` を開く
2. メニュー **`Tools > StarSweepers > 開いているマップに STAGE_02 の列車を置き、ゴール以外の壁を外す`** を実行する
   - `Train`（列車）ができる。子の `Body` が見た目
   - 壁 `Wall_North` `Wall_South` と、ゴールの左右に伸びる壁 `Segment_L` `Segment_R`（東西とも）を**無効**にする
     （消してはいない。Hierarchy でチェックを入れれば戻る）。ゴールの囲い（`Pocket_*` `Pad_*` `GoalArea_*`）は残す
   - シーンは自動で保存される
3. `SpaceJunkLobby.unity` から始めて、STAGE_02 を選んで遊ぶ

何度実行してもよい（列車は作り直す。**Train の値を変えていたら初期値に戻る**ので注意）。

## 設定できる値（`Train` の SpaceJunkTrain）

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Interval Seconds | 何秒ごとに来るか | 15 |
| Move Speed | 走る速さ（m/s）。南へ向かう | 45 |
| Start Position | 現れる場所（北の画面の外） | (0, 1.25, 45) |
| End Position | 消える場所（南の画面の外） | (0, 1.25, -45) |
| Train Size | 列車の大きさ（幅・高さ・長さ）。当たり判定もこの大きさ。**仮の値** | (3, 2.5, 10) |
| Player Side Speed / Forward Speed / Lift | プレイヤーを横・進む向き・上へ飛ばす速さ | 14 / 8 / 6 |
| Object Side Speed / Forward Speed / Lift | 物資を横・進む向き・上へ飛ばす速さ | 14 / 10 / 6 |
| Body | 見た目（子の Body） | ― |

- `Train` を選ぶと、走る道筋が黄色の線、列車の大きさが現れる場所に枠で見える
- 見た目を差し替えるときは `Body` の中身を変える（Body の Scale は Train Size で上書きされる）

## 仕組み（分かる人向け）

- 列車は通信しない（NetworkObject を持たない）。**`NetworkManager.ServerTime.Time` を Interval Seconds で割った余り × 速さ**で位置を決めるので、全PCで同じ場所を走る。1人用のときは `Time.timeSinceLevelLoad`
- 当たりは毎フレーム `Physics.OverlapBox` で調べる（列車の箱には当たり判定を付けていない）
- プレイヤーは `FishingPlayerController.Launch` を呼ぶ。動かしている本人のPCでだけ効く
- 物資は `FishingNetSupply.ServerApplyExplosion`（ホストでだけ効く。引っ掛けを外してから飛ばす）。爆弾の吹き飛ばし（`KnockBackExplosiveObject`）と同じ道を使っている
