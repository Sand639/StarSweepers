## この機能は何か

**決まった間隔で、ステージの真ん中を高速で通り過ぎる列車。** 北→南、南→北、交互、ランダムから走る向きを選べる。
当たったプレイヤーや物資は弾き飛ばされる。ステージの壁も外してあるので、**飛ばされると下へ落ちていく**。

企画メモ（呉さん）のねらい：物を投げるのを邪魔する・真ん中にいる人を落とす（「避けられない！」「おい！ふざけんな！」）。

---

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| 決まった間隔ごと | 線路の端（画面の外）に列車が現れ、反対の端まで一直線に走る |
| 列車に当たる（プレイヤー） | 線路の外側＋列車の進む向き＋少し上へ飛ばされる。1回の通過で1回だけ |
| 列車に当たる（素材・爆弾・特殊デブリ） | 同じように飛ばされる。フックで引っ掛けていたら外れる |
| ステージの外へ落ちる（プレイヤー） | **高さ -8m より下で、自動で出てくる場所に戻る**（ラウンド中は3秒動けない）。もともとある仕組み |
| ステージの外へ落ちる（物資） | 高さ -5m より下で消える。素材はスポナーが補充し、爆弾・特殊デブリは3秒後に元の場所へまた出る |

- 走っていないときは、列車は見えず当たらない
- 最初の列車が来るまでの時間は、ラウンド開始から 0〜間隔 のどこか（全員で同じ時計を使っているため）

### いまの STAGE_02 の置き方（大槻さんの配置）

| 列車 | 線路の位置 | 向き | 間隔 |
| --- | --- | --- | --- |
| `Train (1)` | x = -4 | 北→南 | 10秒 |
| `Train (2)` | x = +4 | 南→北 | 10秒 |

2本とも同じ時計・同じ間隔なので**同時に来る**（すれ違う）。ずらしたいときは片方の Time Offset Seconds を変える（例：5）。

## 使い方

プレハブ **`Assets/Prefabs/SpaceJunk/Online/Train.prefab`**（大槻さんが作成）をシーンにドラッグして置く。

- **置いた場所が線路の真ん中**。線路は列車の奥行き（青い矢印 Z）の向きに、前後 Run Half Length（45m）ずつ伸びる
- 回していなければ、**奥（＋Z）が北、手前（−Z）が南**
- 線路を2本にしたいときは、2つ置いて左右（X）にずらす
- 選んでいなくても、シーン画面に線路が黄色の線、両端に列車の大きさの枠で見える

壁は、`Wall_North` `Wall_South` と、ゴールの左右に伸びる壁 `Segment_L` `Segment_R`（東西とも）を**無効**にしてある
（消してはいない。Hierarchy でチェックを入れれば戻る）。ゴールの囲い（`Pocket_*` `Pad_*` `GoalArea_*`）は残してある。

> 以前あったメニュー `開いているマップに STAGE_02 の列車を置き、ゴール以外の壁を外す` は**廃止した**（プレハブで置くようにしたため）。

## 設定できる値（Train の SpaceJunkTrain）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Direction | 走る向き。**North To South（北→南）／South To North（南→北）／Alternate（1回ごとに交互）／Random（毎回ランダム）** | North To South |
| Interval Seconds | 何秒ごとに来るか | 15（`Train.prefab` は 10） |
| Time Offset Seconds | 来るタイミングをずらす秒数（2本を同時に来させたくないとき） | 0 |
| Move Speed | 走る速さ（m/s）。**マイナスにすると Direction と逆向き** | 45 |
| Run Half Length | 置いた場所から線路の端（現れる・消える場所）までの距離。画面の外になるようにする | 45 |
| Train Size | 列車の大きさ（幅・高さ・長さ）。当たり判定もこの大きさ。**仮の値** | (3, 2.5, 10) |
| Player Side Speed / Forward Speed / Lift | プレイヤーを横・進む向き・上へ飛ばす速さ | 14 / 8 / 6（`Train.prefab` は 15 / 25 / 8） |
| Object Side Speed / Forward Speed / Lift | 物資を横・進む向き・上へ飛ばす速さ | 14 / 10 / 6（`Train.prefab` は 15 / 25 / 8） |
| Body | 見た目（子の Body） | ― |

- 見た目を差し替えるときは `Body` の中身を変える（Body の Scale は Train Size で上書きされる）

## 仕組み（分かる人向け）

- 列車は通信しない（NetworkObject を持たない）。**`NetworkManager.ServerTime.Time` を間隔で割った余り × 速さ**で位置を決めるので、全PCで同じ場所を走る。1人用のときは `Time.timeSinceLevelLoad`
- 親（置いた場所）は動かず、**子の Body だけが線路の上を動く**
- ランダムの向きは「何回目の通過か」の番号から決める（全PCで同じになる）
- 当たりは毎フレーム `Physics.OverlapBox` で調べる（列車の箱には当たり判定を付けていない）
- プレイヤーは `FishingPlayerController.Launch` を呼ぶ。動かしている本人のPCでだけ効く
- 物資は `FishingNetSupply.ServerApplyExplosion`（ホストでだけ効く。引っ掛けを外してから飛ばす）。爆弾の吹き飛ばし（`KnockBackExplosiveObject`）と同じ道を使っている
