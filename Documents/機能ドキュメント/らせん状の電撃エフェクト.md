## この機能は何か

**キャラクターの体のまわりを、緑色の電撃がらせん状にびりびり走る**エフェクト（『僕のヒーローアカデミア』のフルカウルのようなイメージ）。

電撃の形は**毎回ランダムに作り直される**ので、同じ形は二度と出ない。
ふだんは細い電撃がちらちら走り、**攻撃やダッシュの瞬間に「Burst」を呼ぶと、一瞬だけ本数が増えて激しくなる**。

Unity の標準の部品（LineRenderer＝線を描く部品）とプログラムだけで作っている。外部のツールや素材は使っていない。

---

## 遊ぶ人から見た動き

検証シーン `LightningTest.unity` を再生したときの操作：

| 操作 | 結果 |
| --- | --- |
| （何もしない） | カプセルのまわりを、緑の電撃がらせん状に走り続ける |
| Space | 0.4秒だけ電撃が激しくなる（本数・広がり・明るさが増える） |
| 1 | 電撃を出す／消す |
| 2 | キャラクターが円を描いて動く／止まる（電撃がついてくるかの確認） |

## 使い方（ほかのシーンで使うとき）

1. `Assets/Prefabs/Effect/HelixLightning.prefab` を、キャラクターの子にドラッグする（**足元に置く**。位置は 0,0,0 のまま）
2. 攻撃した瞬間などに、スクリプトから `GetComponent<HelixLightning>().Burst();` を呼ぶ
3. **光って見えるには、カメラの Post Processing をオンにし、ブルームの入った Volume を置く必要がある**（無いと、ただの緑の線に見える）

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Glow Color / Core Color | 外側の光の色／芯の色（1 より大きい値で光る） | 緑 (0.15, 3, 0.45)／(0.9, 4, 1.2) |
| Glow Width / Core Width | 外側の光の太さ／芯の太さ | 0.16 / 0.025 |
| Bolt Count | ふだん出ている電撃の本数 | 5 |
| Burst Extra Bolts | Burst のときに増える本数 | 5 |
| Center Height / Body Height | らせんの中心の高さ／電撃が走る範囲の高さ | 1 / 1.8 |
| Radius | らせんの半径 | 0.45 |
| Turns Range | 1本が何周回るか（最小〜最大） | 0.4〜1.3 |
| Length Range | 1本の長さ（体の高さに対する割合） | 0.35〜0.8 |
| Control Point Count | らせんの目印の点の数（多いほど曲がりくねる） | 6 |
| Samples Per Segment | 目印の間を何分割するか（多いほど細かいギザギザ） | 5 |
| Jitter | ギザギザの大きさ（メートル） | 0.05 |
| Regenerate Interval | 形を作り直す間隔（秒） | 0.03〜0.08 |
| Visible Chance | 作り直したときに見えている確率（点滅の多さ） | 0.8 |
| Branch Chance / Branch Length Range | 枝分かれが出る確率／枝の長さ | 0.5 / 0.15〜0.4 |
| Flicker Light / Light Intensity | 一緒にちらつくライト／その明るさ | なし / 3 |
| Burst Radius / Jitter / Brightness Scale | Burst 中に広がり・ギザギザ・明るさを何倍にするか | 1.5 / 1.8 / 1.6 |

## 仕組み（分かる人向け）

1本の電撃は、次の手順で**0.03〜0.08秒ごとに作り直す**（1本ごとに間隔もランダムなので、全部が同時には切り替わらない）。

1. **らせん状の制御点**：体の上方向を軸に、角度 `phase + 向き × t × 周回数 × 2π`、高さ `開始位置 + t × 長さ` で点を置く。半径は点ごとに 0.8〜1.25 倍ゆらす
2. **エルミート補間**：制御点の間を `HelixLightning.Hermite()` で補間する。接線は前後の点の差の半分（Catmull-Rom と同じ求め方）
3. **ギザギザ**：補間した各点を、進む向きに直角な面の上でランダムにずらす。ずらす量は `sin(πt)` の平方根で、端は 0、真ん中が最大
4. **枝分かれ**：芯の真ん中あたりから、外向き＋ランダムな方向へ5点の短い線を出す
5. **描画**：太い線（Glow）と細い線（Core）の2本の LineRenderer を重ねる。色は `MaterialPropertyBlock` で HDR の `_BaseColor` を渡し、ブルームで光らせる

線はすべて `useWorldSpace = false`（付けたオブジェクト基準）なので、キャラクターが動いても一緒についてくる。

## できていないこと・既知の問題

- **人がまだ再生して確かめていない。** AIは、画面なしで起動した Unity から静止画を書き出して確認しただけ（形と色は確認済み。ブルームのにじみ具合とちらつきの速さは未確認）
- **オンラインでの同期はしていない。** 見た目だけのものなので、各PCで別々にランダムに動けばよい（形がPCごとに違っても問題ない）。Burst を呼ぶきっかけ（攻撃したこと）だけを通信で伝える想定
- Burst 中は線が重なって、緑より水色〜白に寄って見える。気になるなら `Burst Brightness Scale` を下げる
- 火花の粒（パーティクル）はまだ無い。足すと見栄えがかなり上がる
- 電撃の線に質感（テクスチャ）が無く、のっぺりした線。デザイナーに電撃用のテクスチャを描いてもらうと良くなる
