## この機能は何か

**ゲームを起動して最初に出る画面。** サーバーを作る・探す・設定・終了ができる。**タイトル専用のシーン（TitleScene）**で出る（2026/10/6 にロビーから分けた）。

| 起きること | 移る先 |
| --- | --- |
| タイトルでサーバーを作った（ホストになった・1人で練習） | **ホストが全員をロビー（SpaceJunkLobby）へ移す** |
| タイトルでサーバーに入った（参加者） | ホストがいるシーン（ふつうはロビー）へ自動で移る |
| 参加者がポーズ画面の「ロビーに戻る」で抜けた・ホストとの通信が切れた | **タイトルへ戻る** |
| ホストがポーズ画面の「ロビーに戻る」 | 今までどおり、全員でロビーへ戻る |
| ロビーのシーンを直接再生した（どこにもつながっていない） | タイトルへ移る |

**通信の管理役（NetworkManager）はプレハブ** `Assets/Prefabs/SpaceJunk/Online/SpaceJunkNetworkManager.prefab` **にした。** タイトルとロビーの両方に置いてある（あとから読み込んだ方は自動で消える）。設定を変えるときはプレハブを直せば両方に効く。

**ビルド**：`Tools > StarSweepers > 宇宙ごみ集めの検証用のビルドを作る` は、**タイトル → ロビー → マップ**の順に入れる（タイトルが起動時に開く）。Build Profiles のシーン一覧の先頭にも TitleScene を入れた。自動接続の `.bat` は、タイトルでつないでからロビーへ移る。

## 画面と、できること

| 画面 | できること |
| --- | --- |
| **メイン** | 「サーバーを作る」「サーバーを探す」「設定」「ゲームを終了」。左上にタイトル（ロゴ）と自分の名前、右下にバージョン |
| **サーバーを作る** | ゲーム内で表示する名前（16文字まで）／最大人数（2〜8人、−1・＋1）／サーバーの名前（25文字まで）／**つなぎかた（インターネット・LAN）**／プライベートサーバー（ON だとパブリックの一覧に出ない）→「サーバーを作成」。**「1人で練習する（通信を使わない）」**もここ |
| 〃（インターネット） | 参加コードは、作成すると発行され、ロビーの左上の「接続」に出る |
| 〃（LAN） | **このPCのIPアドレス**を出す。参加する人はその番号を入れる（展示会場はこちら） |
| **サーバーを探す** | 3つから選ぶ：**プライベートサーバーを探す**（参加コードを入れて参加）／**パブリックサーバーを探す**（公開されているサーバーの一覧から選んで参加。名前と人数が出る）／**LANのサーバーに参加する**（IPアドレスを入れて参加。前に入れた番号を覚えている） |
| **設定** | タブで切り替え。**サウンド**：音量／**グラフィック**：解像度・スクリーンモード（＋適用ボタン）・フレームレート上限・垂直同期・画質／**ゲーム全般**：マウス感度・操作タイプ（コントローラー） |

- つないでいる途中は「部屋を作っています…」などが出る。失敗したら理由と「戻る」、LAN でつながらないときは「やめる」が出る
- **戻る**：Esc（コントローラーは B）、または左下の「戻る」
- コントローラーでは十字キー／スティックで選んで A
- 設定は保存され、次に起動したときも使われる（ポーズ画面の設定と同じ値）
- 名前は保存される。**ロビーの一覧と、プレイヤーの頭の上のタグに出る**（`プレイヤーの名前と頭上の名前タグ.md`）

めっちゃカメレオンにあって、入れていないもの：言語の切り替え（このゲームは日本語だけ）、フレンドのサーバー（Steam のフレンドが必要）、Discord・X のリンク、ID の表示、地域・サーバータグ、クロスプレイ、Mod。必要になったら足す。

## 見た目を変える（UI画像の差し替え）

**`Assets/Resources/TitleScreenTheme.asset` を選ぶと、インスペクターで画像と色を差し替えられる。** 画面のコードは触らなくてよい。
**画像を入れていない所は、色だけの四角で描く**（今は背景以外は色だけ）。

| 項目 | どこに使うか | いま |
| --- | --- | --- |
| Background | 画面いっぱいの背景（縦横比を保ったまま、はみ出す分は切る） | `Assets/Art/Sprites/title.png` |
| Logo | 左上のタイトルロゴ。空なら Title Text を文字で出す | 空（「Star Sweepers」を文字で出す） |
| Button / Button Hover | ボタンの画像（ふだん／マウスが重なった・コントローラーで選んだとき） | 空（色だけ） |
| Panel | 入力欄・設定の行・一覧の下地 | 空（色だけ） |
| Accent Panel | 参加コードの枠・サーバーのカードの下地 | 空（紫） |
| 色・文字の大きさ・メインボタンの大きさ | 名前のとおり | 緑のふち・白い文字（めっちゃカメレオン風） |

- 画像は **Texture Type を「Sprite (2D and UI)」** にして読み込む
- ボタンや枠の画像は、**Sprite Editor で Border（9スライス）を付けておくと**、大きさが変わっても角がつぶれない（付けていなければ引き伸ばす）
- テーマのファイルを作り直したいときは、Project で右クリック → `Create > StarSweepers > タイトル画面のテーマ`（**名前は TitleScreenTheme、置き場所は Assets/Resources** のまま）

## 仕組み（分かる人向け）

- `TitleScreen` は `RuntimeInitializeOnLoadMethod` で自動で1つ作られ、シーンをまたいで残る。**アクティブなシーンが `TitleScene` で、`NetworkManager` が IsServer でも IsConnectedClient でもない間だけ**画面を出す
- 画面は uGUI をコードで組み立てる（日本語フォントを実行時に借りる必要があるため。`UiFont.Find`）。見た目の材料はすべて `TitleScreenTheme` から読む
- インターネット：`InternetConnection.HostGame(名前, 人数, 非公開)` / `JoinGame(コード)` / `QueryPublicSessionsAsync()` / `JoinGameById(id)`。パブリックの一覧は `MultiplayerService.QuerySessionsAsync`（非公開の部屋は出ない）
- LAN：`UnityTransport.SetConnectionData` ＋ `StartHost` / `StartClient`（ポートは NetworkManager の設定のまま）
