## この機能は何か

**ゲームを起動して最初に出る画面。** サーバーを作る・探す・設定・終了ができる。**タイトル専用のシーン（TitleScene）**で出る（2026/10/6 にロビーから分けた）。

| 起きること | 移る先 |
| --- | --- |
| タイトルでサーバーを作った（ホストになった・1人で練習） | **ホストが全員をロビー（SpaceJunkLobby）へ移す** |
| タイトルでサーバーに入った（参加者） | ホストがいるシーン（ふつうはロビー）へ自動で移る |
| 参加者がポーズ画面の「ロビーに戻る」で抜けた・ホストとの通信が切れた | **タイトルへ戻る** |
| ポーズ画面の「タイトルにもどる」（ロビーでも試合中でも出る） | **タイトルへ戻る。ホストなら全員がタイトルへ戻る**（参加者はホストとの通信が切れるので、見張り役が戻す） |
| ホストがポーズ画面の「ロビーに戻る」 | 今までどおり、全員でロビーへ戻る |
| ロビーのシーンを直接再生した（どこにもつながっていない） | タイトルへ移る |

**通信の管理役（NetworkManager）はプレハブ** `Assets/Prefabs/SpaceJunk/Online/SpaceJunkNetworkManager.prefab` **にした。** タイトルとロビーの両方に置いてある（あとから読み込んだ方は自動で消える）。設定を変えるときはプレハブを直せば両方に効く。

**ビルド**：`Tools > StarSweepers > 宇宙ごみ集めの検証用のビルドを作る` は、**タイトル → ロビー → マップ**の順に入れる（タイトルが起動時に開く）。Build Profiles のシーン一覧の先頭にも TitleScene を入れた。自動接続の `.bat` は、タイトルでつないでからロビーへ移る。

## 画面と、できること

| 画面 | できること |
| --- | --- |
| **メイン** | 「**クイックプレイ**」「サーバーを作る」「サーバーを探す」「設定」「ゲームを終了」。左上にタイトル（ロゴ）と自分の名前、右下にバージョン |
| **クイックプレイ**（2026/10/15） | 押すと、**公開されているサーバー（パブリック）に入る。** 入れるサーバー（満員でない・パスワードなし）のうち、**いちばん人の多いところ**に入る（人がばらばらに分かれないように）。**1つも無ければ、初期の設定でパブリックのサーバーを作る**（名前は「（名前）のサーバー」・定員8人・パスワードなし）。探している途中は「サーバーを探しています…」が出る。インターネットにつながらないときは理由と「戻る」が出る |
| **サーバーを作る** | ゲーム内で表示する名前（16文字まで）／最大人数（2〜8人、−1・＋1。**初期値は8人**。2026/10/15）／サーバーの名前（25文字まで）／**パスワード**（空ならなし。パブリック・プライベートのときだけ）／**部屋の公開のしかた：□パブリック □プライベート □LAN**（3つのチェック。1つ押すとほかは外れる。**最初はパブリック**（2026/10/15）。パブリック＝インターネットで一覧に出る、プライベート＝インターネットで参加コードを知っている人だけ、LAN＝同じネットワークのPCだけ。2026/10/15 から。前は「つなぎかた（インターネット／LAN）」のボタンが別の行にあった）→「サーバーを作成」。**「1人で練習する（通信を使わない）」**もここ |
| 〃（インターネット） | 参加コードは、作成すると自動で決まり、**ロビーの左上に出る**（パブリックの部屋でも、参加コードで入れる） |
| 〃（LAN） | **このPCのIPアドレス**を出す。作った部屋は**同じネットワークに自動で知らせる**ので、参加する人の「LANのサーバーに参加する」の一覧に出る（2026/10/15。出ないときはこの番号を入れてもらう。展示会場はこちら） |
| **サーバーを探す** | 4つから選ぶ：**プライベートサーバーを探す**（参加コードを入れて参加）／**パブリックサーバーを探す**（公開されているサーバーの一覧から選んで参加。名前と人数が出る）／**フレンドのサーバーを探す**（Steam のフレンドの部屋。`Steamのフレンドのサーバー.md`）／**LANのサーバーに参加する**（**下に、同じネットワークで見つかった LAN の部屋が並び、押すと参加できる**（2026/10/15）。見つからないときは IPアドレスを入れて参加。前に入れた番号を覚えている）。パスワードの付いた部屋には、パスワードの欄に入れてから入る |
| **設定** | タブで切り替え。**サウンド**：音量／**グラフィック**：解像度・スクリーンモード（＋適用ボタン）・フレームレート上限・垂直同期・画質／**ゲーム全般**：マウス感度・操作タイプ（コントローラー） |

- つないでいる途中は「部屋を作っています…」などが出る。失敗したら理由と「戻る」、LAN でつながらないときは「やめる」が出る
- **戻る**：Esc（コントローラーは B）、または左下の「戻る」
- コントローラーでは**右スティックでスコープレンズのポインターを動かし、LT か A で押す**（2026/10/11。`スコープレンズのポインター.md`）。**左スティック・十字キーでも選べる**（何も選ばれていなければ「サーバーを作る」から。A で決定。2026/10/13）。Windows のカーソルは隠し、マウスのときもスコープレンズが出る
- 設定は保存され、次に起動したときも使われる（ポーズ画面の設定と同じ値）
- 名前は保存される。**ロビーの一覧と、プレイヤーの頭の上のタグに出る**（`プレイヤーの名前と頭上の名前タグ.md`）

めっちゃカメレオンにあって、入れていないもの：言語の切り替え（このゲームは日本語だけ）、Discord・X のリンク、ID の表示、地域・サーバータグ、クロスプレイ、Mod。必要になったら足す。

## パスワード（2026/10/6）

- **サーバーを作る**：「パスワード」を入れると、パスワード付きの部屋になる。**空ならパスワードなし。** **1〜32文字**。32文字を超えると、欄の右に「パスワードは32文字までです」と赤く出て、作れない。LAN のときは出ない
- 中継サーバーは 8 文字以上しか受け付けないので、**8文字に足りないときは、中で後ろに「a」を足して渡す**（「B」→「Baaaaaaa」）。作る側も入る側も同じ足し方なので、遊ぶ人は「B」と入れるだけでよい
- **サーバーを探す**：プライベート（参加コード）・パブリック（一覧）・フレンドの画面に「パスワード」の欄がある。パスワードの付いた部屋に入るときだけ入れる。一覧では「（パスワードあり）」と出る
- パスワードが違うと「部屋に入れませんでした。パスワードが違うか…」と出る
- パスワードはロビーのゲーム設定でホストが変えられる（`ロビーの画面.md`）。**パスワードなしで作った部屋に、あとから付けることはできない**
- 参加コードは今までどおり自動で決まる（部屋を見つけるための番号。パスワードとは別）


## 見た目と配置を変える（プレハブ）

**画面そのものはプレハブ `Assets/Resources/TitleScreen.prefab`。TitleScene に置いてある**（2026/10/6 にプレハブへ組み直した）。
**ボタン・文字・枠は、エディタで自由に動かし、大きさ・画像・色・文言を変えてよい。** 自動で並べる仕組みは使っていない（パブリックサーバーの一覧の中だけは自動）。

- Project でプレハブをダブルクリックして開くか、TitleScene の Hierarchy の `TitleScreen` から直す
- **画面（ページ）は1つずつ表示を切り替える。** 最初は `MainPage` だけ表示されている。ほかの画面を直すときは、`CreatePage` などのチェック（表示）を入れて直し、**終わったら外しておく**（再生すれば自動で切り替わるので、外し忘れても動きはする）
- 設定画面の中身も同じ。`SoundGroup`（表示）／`GraphicsGroup`・`GeneralGroup`（非表示）
- 背景は `Background/Picture` の Image、ロゴは `MainPage/Title` の文字（画像にしたいときは、文字を消して Image を置く）
- 編集中は文字がUnityの標準フォントで出る。**再生すると、パソコンの日本語フォントに差し替わる**（日本語のフォントはプレハブに保存できないため）

### コードは「印」で部品を見つける

部品の**名前や並び順は見ていない**ので、名前を変えても・入れ物を移しても動く。**印を消すと、コードから動かなくなる。**

| 印（コンポーネント） | 何を決めるか | 例 |
| --- | --- | --- |
| **Title Menu Button** の Action | ボタンを押したときにすること | OpenCreate（サーバーを作る画面へ）、Back（戻る）、CreateServer（作成） |
| **Title Part** の Role | 画面（ページ）・コードが書き換える文字・一覧の入れ物など | PageMain、PlayerNameText（「名前：○○」が入る）、BusyOverlay |
| **Title Input** の Kind | 入力欄に何を入れるか | PlayerName、ServerName、PrivateCode、LanAddress、CreatePassword、JoinPassword |
| **Title Setting Row** の Kind | 設定の1行が何の設定か | Volume、Resolution、VSync |

- **ボタンを足したいとき**：今あるボタンを複製（Ctrl+D）して、Action を選び直す
- コードが書き換える文字（Role が付いた文字）は、**再生すると中身が入れ替わる。** 位置・大きさ・色・フォントの大きさは、エディタで決めたものが使われる
- 右下のバージョンの文字の `{version}` は、再生すると Project Settings の Version に置き換わる
- パブリックサーバーの一覧の `ServerCardTemplate`、フレンドのサーバーの一覧の `FriendCardTemplate` は**カード1枚の見本**。再生すると隠れ、見つかった数だけ複製される

### ボタンの見た目は、テーマでまとめて変える

**`Assets/Resources/TitleScreenTheme.asset`** で、**全部のボタン**の画像と色（ふだん／マウスが重なったとき）をまとめて変えられる。編集中でもすぐ反映される。

- このボタンだけ別の見た目にしたいときは、そのボタンの **Use Theme を OFF** にして、Image を直接変える（重なっても見た目は変わらなくなる）
- 画像は **Texture Type を「Sprite (2D and UI)」** にして読み込む。**Sprite Editor で Border（9スライス）を付けておくと**、大きさが変わっても角がつぶれない

### 最初の状態に作り直す

`Tools > StarSweepers > タイトル画面のプレハブを作り直す`。**手で直した配置・画像・色は消える**ので、ふだんは使わない。
プレハブが無いときは、Unity が読み込んだときに自動で1回だけ作り、TitleScene に置く。

**部品が増えたとき（版が上がったとき）は、作り直さずに足りない部品だけを足す**（版 3 から。手で直した配置は消えない）。いまは版 7（メインのクイックプレイ。2026/10/15）。

## 仕組み（分かる人向け）

- `TitleScreen` は TitleScene に置いたプレハブの上で動く。`OnEnable` で `IsVisible = true`、シーンが変わって消えると false
- `Awake` で、印（`TitlePart` / `TitleMenuButton` / `TitleInput` / `TitleSettingRow`）を `GetComponentsInChildren(true)` で集めて、ボタンの `onClick` などをコードでつなぐ（プレハブに保存された呼び出し先は使わない）
- 文字のフォントは `Awake` で `UiFont.Find` に差し替える（Use Os Japanese Font）
- `TitleSceneFlow` は `RuntimeInitializeOnLoadMethod` で自動で1つ作られ、シーンをまたいで残る。タイトルでホストになったら `NetworkManager.SceneManager.LoadScene(ロビー)`、ロビーでどこにもつながっていなければタイトルへ。TitleScene にタイトル画面が無ければ Resources から出す
- インターネット：`InternetConnection.HostGame(名前, 人数, 非公開, パスワード)` / `JoinGame(コード, パスワード)` / `QueryPublicSessionsAsync()` / `JoinGameById(id, パスワード)`
- LAN：`UnityTransport.SetConnectionData` ＋ `StartHost` / `StartClient`（ポートは NetworkManager の設定のまま）。「サーバーを作る → LAN」のホストは `LanRoomDiscovery.StartAdvertising` で1秒ごとに部屋を知らせ（UDP のブロードキャスト。ポート 47777）、「LANのサーバーに参加する」画面を開いている間は `StartListening` で聞いて一覧に並べる（3.5秒聞こえない部屋は消す）
- ホストに切られて戻ってきたとき（満員など）は、`NetworkManager.DisconnectReason` を「部屋に入れませんでした：（理由）」として、つないでいる途中の表示の枠に出す（「OK」で閉じる）
- 印の種類（enum）の数字はプレハブに保存されるので、**足すときは空いている番号を使い、途中の番号を変えないこと**
