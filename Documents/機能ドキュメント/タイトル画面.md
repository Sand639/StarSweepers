## この機能は何か

**ゲームを起動して最初に出る画面。** 名前を入れて、1人で遊ぶか、みんなで遊ぶ（部屋に入る・部屋を作る）かを選ぶ。**タイトル専用のシーン（TitleScene）**で出る。

| 起きること | 移る先 |
| --- | --- |
| 「1人プレイ」・部屋を作った（ホストになった） | **ホストが全員をロビー（SpaceJunkLobby）へ移す** |
| 一覧の部屋に入った（参加者） | ホストがいるシーン（ふつうはロビー）へ自動で移る |
| 参加者がポーズ画面の「ロビーに戻る」で抜けた・ホストとの通信が切れた | **タイトルへ戻る** |
| ポーズ画面の「タイトルにもどる」（ロビーでも試合中でも出る） | **タイトルへ戻る。ホストなら全員がタイトルへ戻る** |
| ホストがポーズ画面の「ロビーに戻る」 | 今までどおり、全員でロビーへ戻る |
| ロビーのシーンを直接再生した（どこにもつながっていない） | タイトルへ移る |

**通信の管理役（NetworkManager）はプレハブ** `Assets/Prefabs/SpaceJunk/Online/SpaceJunkNetworkManager.prefab`。タイトルとロビーの両方に置いてある（あとから読み込んだ方は自動で消える）。

**ビルド**：`Tools > StarSweepers > 宇宙ごみ集めの検証用のビルドを作る` は、**タイトル → ロビー → マップ**の順に入れる（タイトルが起動時に開く）。

## 画面の流れ（2026/10/13 から）

```
起動
 ↓
はじめの画面：名前を入れる欄と「START」
 ↓
えらぶ画面：左に「1人プレイ」「マルチプレイ」。右に、選んでいるほうの表示
 ├ 「1人プレイ」を押す → そのままロビーへ
 └ 「マルチプレイ」を押す → 右が部屋の一覧に変わる
      ├ 部屋を押す → その部屋に入ってロビーへ（パスワード付きなら、小さい窓でパスワードを聞く）
      └ 一番下の「＋」 → 小さい窓：パスワード（空ならなし）と「インターネットで作る」「LANで作る」
                           → 押すとすぐ部屋ができてロビーへ
```

| 画面 | できること |
| --- | --- |
| **はじめ** | 名前を入れる（16文字まで。保存される）→「START」。**名前が空だと進めない**（「名前を入れてください」）。右下にバージョン |
| **えらぶ** | 左に「1人プレイ」「マルチプレイ」。**ポインターを重ねた（十字キーで選んだ）ほうが、右に大きく出る**（マリオカートの選び方。いまは「シングルプレイ」「マルチプレイ」の文字。のちのち人の絵にする） |
| **部屋の一覧** | 「マルチプレイ」を押すと右に出る。**インターネットの公開の部屋**と、**同じネットワーク（LAN）の部屋**が並ぶ（「部屋名（LAN）」「（パスワードあり）」「1/4人」「満員」）。インターネットの部屋は5秒ごとに取り直す（**「マルチプレイ」を何度押しても、前に取ってから5秒たつまでは取り直さない**。取れなかったら15秒待ってから。2026/10/13：連打で「頼みすぎ（429）」と断られたため）。LAN の部屋は聞こえたらすぐ出る |
| **部屋を作る窓**（「＋」） | パスワード（空ならなし。1〜32文字。インターネットの部屋だけ）と、「インターネットで作る」「LANで作る」。部屋の名前は「（自分の名前）の部屋」、最大4人 |
| **パスワードの窓** | パスワード付きの部屋を押したときに出る。入れて「参加する」 |

- つないでいる途中は「部屋を作っています…」などが出る。失敗したら理由と「戻る」、LAN でつながらないときは「やめる」が出る
- **戻る**：Esc（コントローラーは B）、または左下の「戻る」。小さい窓が開いていれば、窓を閉じる
- コントローラー：**右スティックでスコープレンズのポインターを動かし、LT か A で押す**。**左スティック・十字キーでも選べる**（A で決定）（`スコープレンズのポインター.md`）
- インターネットの部屋は**公開**で作る（ほかの人の一覧に出る）。参加コードはロビーの左上に出る（Steam の「ゲームに参加」は今までどおり使える）
- LAN の部屋は、作った PC が**同じネットワークに部屋を知らせる**ので、IPアドレスを打たなくても一覧に出る（`LANでの複数人プレイ.md`）。ロビーの左上には今までどおり IP アドレスが出る
- 名前は保存される。**ロビーの一覧と、プレイヤーの頭の上のタグに出る**（`プレイヤーの名前と頭上の名前タグ.md`）

## パスワード

- **部屋を作る窓**で入れると、パスワード付きの部屋になる。**空ならパスワードなし。** **1〜32文字**。32文字を超えると、欄の右に「パスワードは32文字までです」と赤く出て、作れない。LAN の部屋では使わない
- 中継サーバーは 8 文字以上しか受け付けないので、**8文字に足りないときは、中で後ろに「a」を足して渡す**（「B」→「Baaaaaaa」）。遊ぶ人は「B」と入れるだけでよい
- 一覧では「（パスワードあり）」と出る。押すとパスワードの窓が出る。違うと「部屋に入れませんでした。パスワードが違うか…」と出る
- パスワードはロビーのゲーム設定でホストが変えられる（`ロビーの画面.md`）。**パスワードなしで作った部屋に、あとから付けることはできない**

## 見た目と配置を変える（プレハブ）

**画面そのものはプレハブ `Assets/Resources/TitleScreen.prefab`。TitleScene に置いてある。**
**ボタン・文字・枠は、エディタで自由に動かし、大きさ・画像・色・文言を変えてよい。** 自動で並べる仕組みは使っていない（部屋の一覧の中だけは自動）。

- Project でプレハブをダブルクリックして開くか、TitleScene の Hierarchy の `TitleScreen` から直す
- **画面（ページ）は1つずつ表示を切り替える。** 最初は `StartPage` だけ表示されている。`ModePage`・`CreateWindow`・`PasswordWindow` を直すときは表示のチェックを入れて直し、**終わったら外しておく**（再生すれば自動で切り替わるので、外し忘れても動きはする）
- 右側の「シングルプレイ」「マルチプレイ」は `ModePage/SoloPreview`・`MultiPreview` の文字。**人の絵にするときは、文字の代わりに Image を置き、同じ印（Title Part の Role：SoloPreview・MultiPreview）を付ける**
- 背景は `Background/Picture` の Image（タイトルのロゴは背景の絵に入っている）。はじめの画面では `StartPage/StartBox` が名前の欄と START の後ろの暗い箱。えらぶ画面では `ModePage/Backdrop` で背景を暗くしている
- 編集中は文字がUnityの標準フォントで出る。**再生すると、パソコンの日本語フォントに差し替わる**

### コードは「印」で部品を見つける

部品の**名前や並び順は見ていない**ので、名前を変えても・入れ物を移しても動く。**印を消すと、コードから動かなくなる**（自動テスト `TitleScreenPrefabTests` で気づける）。

| 印（コンポーネント） | 何を決めるか | 例 |
| --- | --- | --- |
| **Title Menu Button** の Action | ボタンを押したときにすること | Start、PlaySolo（1人プレイ）、ShowMulti（マルチプレイ）、OpenCreateRoom（＋）、CreateRoomInternet、CreateRoomLan、CloseWindow、ConfirmJoinPassword、Back |
| **Title Part** の Role | 画面（ページ）・窓・コードが書き換える文字・一覧の入れ物など | PageStart、PageMode、SoloPreview、MultiPreview、RoomListPanel、RoomListContent、RoomCardTemplate、CreateRoomButton、CreateWindow、PasswordWindow、BusyOverlay |
| **Title Input** の Kind | 入力欄に何を入れるか | PlayerName、CreatePassword、JoinPassword |

- 部屋の一覧の `RoomCardTemplate` は**カード1枚の見本**。再生すると隠れ、見つかった部屋の数だけ複製される。「＋」（CreateRoomButton）はいつも一覧の一番下に置き直される
- 右下のバージョンの文字の `{version}` は、再生すると Project Settings の Version に置き換わる

### ボタンの見た目は、テーマでまとめて変える

**`Assets/Resources/TitleScreenTheme.asset`** で、**全部のボタン**の画像と色（ふだん／マウスが重なったとき・選ばれているとき）をまとめて変えられる。

- このボタンだけ別の見た目にしたいときは、そのボタンの **Use Theme を OFF** にして、Image を直接変える
- 画像は **Texture Type を「Sprite (2D and UI)」** にして読み込む。**Sprite Editor で Border（9スライス）を付けておくと**、大きさが変わっても角がつぶれない

### 最初の状態に作り直す

`Tools > StarSweepers > タイトル画面のプレハブを作り直す`。**手で直した配置・画像・色は消える**ので、ふだんは使わない。
プレハブが無いとき・**作りの版が 5 より古いとき**は、Unity が読み込んだときに自動で作り直す（2026/10/13 の作り直しで版 5 にした）。

## 仕組み（分かる人向け）

- `TitleScreen` は TitleScene に置いたプレハブの上で動く。`OnEnable` で `IsVisible = true`、シーンが変わって消えると false
- `Awake` で、印（`TitlePart` / `TitleMenuButton` / `TitleInput`）を `GetComponentsInChildren(true)` で集めて、ボタンの `onClick` などをコードでつなぐ（プレハブに保存された呼び出し先は使わない）
- 右側の表示は、毎フレーム「1人プレイ」「マルチプレイ」のボタンの `TitleMenuButton.IsHighlighted`（ポインターが重なっているか・十字キーで選ばれているか）を見て切り替える
- 1人プレイ：`UnityTransport.SetConnectionData("127.0.0.1", ポート, "127.0.0.1")` ＋ `StartHost`（このPCの中だけで待つので、ほかのPCからは入れない）
- インターネット：`InternetConnection.HostGame(名前, 4, 公開, パスワード)` / `QueryPublicSessionsAsync()` / `JoinGameById(id, パスワード)`。**一覧を取っている間は作る・入るができない**（係が1つのことしかできない）ので、「少し待って」と出す
- LAN：作るときは `0.0.0.0` で待って `StartHost` し、`LanRoomDiscovery.StartAdvertising` で1秒ごとに UDP のブロードキャスト（ポート 47777）で部屋を知らせる。一覧を開いている間は `LanRoomDiscovery.StartListening` で聞き、3.5秒聞こえない部屋は消す。入るときは知らせてきた PC のアドレスとポートで `StartClient`
- 印の種類（enum）の数字はプレハブに保存されるので、**足すときは空いている番号を使い、途中の番号を変えないこと**（前の画面の番号も残してある）
