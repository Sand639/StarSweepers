## この機能は何か

**Escape を押すと開く、ポーズ画面。** 開いている間、**自分の操作は受け付けなくなる。**

**1人で遊んでいるときは、世界の時間も止まる。**
**通信でつながっているときは止まらない**（他の人は動き続けているため）。

| 項目 | 押すとどうなるか |
| --- | --- |
| **ゲームをつづける** | 画面を閉じて、続きから遊ぶ |
| **設定** | 音量・マウス感度・操作タイプ（コントローラー）を変える画面へ |
| **ロビーに戻る** | **宇宙ごみの試合中だけ出る。** 確かめる画面を出してから、試合を抜けてロビーへ戻る（下の「ロビーに戻る・ゲームをやめる」） |
| **タイトルにもどる** | **つながっている間は、ロビーでも試合中でも出る（ホスト以外にも出る）。** 確かめる画面を出してから、タイトルへ戻る。ホストなら全員がタイトルへ戻る（2026/10/6） |
| **ゲームをやめる** | 確かめる画面を出してから、ゲームを終了する（**エディタでは再生を止めるだけ**） |

**マウスで選ぶ。** もう一度 Escape を押しても閉じられる。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| **Escape**／コントローラーの **Start** | **ポーズ画面が開く。** 後ろが暗くなり、自分の操作が止まる（1人で遊んでいるときは世界の時間も止まる）。マウスカーソルが出る |
| **項目にマウスを重ねる** | **色が変わり、少し大きくなり、左に「▶」が出る** |
| **項目をクリック** | その項目が実行される |
| **Escape**／**Start**（開いている間） | 閉じて、続きから遊ぶ |
| **十字キー／左スティック**（コントローラー） | 項目を選ぶ。選んだ項目はマウスを重ねたときと同じ見た目になる。**開いたときは一番上の項目が選ばれている** |
| **A**（コントローラー） | 選んだ項目を実行する |
| **B**（コントローラー） | 設定の画面なら最初の画面へ戻る。最初の画面なら閉じる |

**閉じるとカーソルは消えて、視点操作に戻る。**

### マウスが重なったときの見せ方

**3つ同時に変えている。** 1つだけだと気づかれにくいため。

- **色**が明るくなる
- **少しだけ大きくなる**（5%）
- **左に「▶」が出る**

変化は**なめらかに**動く。ポーズ中でも動くように、**止まっても進む時間**を使っている。

### 設定の画面

| 項目 | 内容 |
| --- | --- |
| **音量** | ゲーム全体の音の大きさ |
| **マウス感度** | 視点を回す速さの倍率（1でそのまま） |
| **操作タイプ** | コントローラーの操作タイプ A／B の切り替え（`釣りフックの操作.md`） |

**次に遊ぶときも、変えた値は残る**（パソコンに保存している）。

### ロビーに戻る・ゲームをやめる（2026/10/6 追加）

どちらも、押すとすぐには実行せず、**確かめる画面**を出す。上の項目を選ぶと閉じて遊びに戻り、下の項目で実行する。
コントローラーでは**上の「つづける」側が選ばれた状態**で開く（うっかり抜けないように）。B で最初の画面へ戻る。

| 押した項目 | 確かめる画面の文 | 選べる項目 |
| --- | --- | --- |
| ロビーに戻る | 試合から抜けてロビーに戻ります<br>※ホストの場合は全員がロビーに戻されます | 試合をつづける ／ ロビーに戻る |
| タイトルにもどる | 試合から抜けてタイトル画面に戻ります（ロビーでは「ロビーから抜けて…」）<br>※ホストの場合は全員がタイトル画面に戻されます | ゲームをつづける ／ タイトルにもどる |
| ゲームをやめる | 試合から抜けてゲームを終了します（試合中でなければ「ゲームを終了します」）<br>※ホストの場合は全員がタイトル画面に戻されます | ゲームをつづける ／ ゲームをやめる |


「タイトルにもどる」を決めたとき（2026/10/6 追加）：

| 押した人 | どうなるか |
| --- | --- |
| ホスト | 通信を止めて（部屋も閉じる）タイトルへ。**参加者はホストとの通信が切れるので、見張り役（`SpaceJunkDisconnectWatcher`）が全員をタイトルへ戻す**（「ホストがゲームを抜けたか、接続が切れたので、タイトルに戻りました」と出る） |
| 参加者 | 自分だけ部屋から抜けてタイトルへ。ほかの人は続く |

「ロビーに戻る」を決めたとき：

| 押した人 | どうなるか |
| --- | --- |
| ホスト | 試合を打ち切って、**全員でロビーへ戻る**（試合が終わったときと同じ戻り方） |
| 参加者 | **自分だけ通信を切って部屋から抜け、タイトル画面に戻る**（2026/10/6 から。つなぐのはタイトルで行うため）。ほかの人の試合は続く （**部屋から抜け終わるのを待ってから**通信を止める。2026/10/6 修正：先に止めていたせいで中継サーバーに参加の記録が残り、もう一度入れなくなっていた） |
| 通信していない（エディタで直接マップを再生） | タイトルのシーンを開くだけ |

「ロビーに戻る」は**宇宙ごみの試合中（ラウンドの進行役がいるとき）だけ**出る。釣りやロビーでは出ない。
ポーズ画面は共通の部品なので、宇宙ごみのことは知らない。ポーズ画面の差し込み口（`PauseMenu.CanReturnToLobby` / `PauseMenu.ReturnToLobby`）に、
`Assets/Scripts/SpaceJunk/SpaceJunkLeaveMatch.cs` が宇宙ごみの処理を入れている。**ほかの遊びでも、同じ差し込み口に入れれば出せる。**

## シーンに置く手順

**置かなくてよい。** どのシーンでも、**再生すると自動で用意される。**

置き忘れたまま「Escape を押しても何も起きない」と悩むことが多いため、
**シーンのどこにも無ければ、ゲーム側が自分で1つ作る**ようにしてある。

見た目や色を**そのシーンだけ変えたい**ときは、手で置けばそちらが使われる。

1. 置きたいシーンを開く
2. メニューの **`Tools > StarSweepers > アーカイブ > 共通の部品 > ポーズ画面を置く`** を実行

**カメラもUIも要らない**（足りない物はこちらで作る）。

> **止まっている間は、シーンに何も見えない。**
> 画面は**再生したときに組み立てられる**ため（理由は下に書いてある）。
> 再生して Escape を押すと出てくる。

## 仕組み（分かる人向け）

### 画面をコードで組み立てている理由

**プレハブに画面を作り込んでいない。** 再生したときに、`PauseMenu` が自分で作る。

理由は**日本語のため。**
Unityに最初から入っている文字は**日本語を持っていない**ので、
そのままだと項目名が**四角（□□□）**になってしまう。

**パソコンに入っている日本語フォントを借りてくる**必要があるが、
それは**保存できない**（プレハブに残らない）。
そのため、画面を作るところまで含めてコードにしてある。

> **日本語のフォントを持つ形（TextMeshProの日本語フォント）を用意すれば、
> 普通にプレハブで作れるようになる。** 見た目を凝りたくなったら、そのとき作り直すのがよい。

### Escape の取り合い

**Escape は、もともとカメラ側が「カーソルを出す」ために使っていた。**
そのままだと、ポーズ画面と取り合いになる。

**「止まっている間だけカメラが手を引く」では足りなかった。**
閉じる瞬間は**同じ1フレームの中で**「止まっていない」に戻るため、
そのあとにカメラ側が同じ Escape をもう一度拾ってしまい、
**閉じたのにカーソルが出たまま**になっていた。

そこで、**ポーズ画面があるなら Escape はカメラ側では一切見ない**ことにした。

| | ポーズ画面があるとき | 無いとき |
| --- | --- | --- |
| カメラ | **Escape を見ない**（クリックでカーソルを固定するのは今までどおり） | Escape でカーソルを出す |
| ポーズ画面 | Escape で開く／閉じる | ― |

あわせて、**ポーズ画面は他の部品より先に動く**ようにした（`DefaultExecutionOrder(-100)`）。
順番が決まっていないと、同じフレームでの取り合いが再び起きるため。

**ポーズ画面が Escape を譲る場面**（2026/10/6）：タイトル画面が出ている間（Esc は「戻る」に使う。`TitleScreen.IsVisible`）と、ロビーのゲーム設定が開いている間・Esc で閉じたフレーム（`SpaceJunkLobbyScreen.BlocksEscape`）は、ポーズ画面は開かない。

**複製配置システムも Escape を「やめる」に使っている。**
止まっている間は入力を受け取らないようにしたので、
ポーズ画面を開いても**置きかけの複製が消えない。**

> ⚠️ **ただし、閉じるときは同じ取り合いが残っている可能性がある**（2026/9/14の点検でコードを読んで気づいた。**未確認**）。
> Escape で閉じると、そのフレームで「止まっていない」に戻り、あとから動く複製配置が**同じ Escape を拾って置きかけの物を消す**かもしれない。
> 「ゲームをつづける」をクリックして閉じた場合も、**同じクリックで物が置かれる**かもしれない。
> 結果として、**複製配置の「Escape でやめる」はいまは使えない**。`リスクリスト.md` に登録してある。

### 止まっているのに動かしたいもの

1人で遊んでいるときは `Time.timeScale` を 0 にするので、**歩く・落ちるは自動的に止まる。**

> **通信でつながっている間は `Time.timeScale` を変えない**（2026/9/20）。
> 自分のPCだけ時間を止めても他の人は動き続けるので、閉じた瞬間に相手が飛んで見える。
> ホストが止めると、**ホストが動かしている物が全員の画面で空中に止まる**のに、
> 試合の残り時間（共有の時計で数えている）だけは減り続けてしまう。
> そのため、**つながっている間は「自分の操作だけ止める」**形にしてある
> （`GamePause.SetPaused` が `NetworkManager.Singleton.IsListening` を見て分ける）。
> **止まらないぶん、入力を読む側が `GamePause.BlocksInput` を見ていることが大事になる。**

止まっているときは、2つだけ自分で気をつける必要がある。

- **マウスでの視点移動は止まらない**（動いた量をそのまま使っているため）
  → `GamePause.IsPaused` を見て止めている
- **`Time.deltaTime` が 0 になる**ので、そのままだとUIのアニメーションも止まる
  → マウスが重なったときの変化は `Time.unscaledDeltaTime` を使っている

### クリックを受け取る仕組み

UIのクリックには `EventSystem` が要る。**無ければ自動で作る。**

このプロジェクトは**新しい入力方式（Input System）**を使っているので、
古い受け取り方（`StandaloneInputModule`）を付けるとエラーになる。
**`InputSystemUIInputModule`** のほうを付けている。

## できていないこと・既知の問題

- **見た目の大きさや色は調整前の値。** 遊びながら詰めること
- **自動で用意される画面は、インスペクターの値が初期値のまま**になる。
  色や文字の大きさを変えたいシーンでは、`ポーズ画面を置く` で手で置くこと
- **フォントはパソコン任せ。** 游ゴシックなどが入っていないパソコンでは、
  別のフォントになるか、文字が四角になる可能性がある
- ~~キーボードやコントローラーでは選べない~~ → 2026/9/22 にコントローラーで選べるようにした（上の「遊ぶ人から見た動き」）
- **設定は音量・マウス感度・操作タイプの3つだけ。** 画面の大きさ・画質などはタイトル画面の「設定」で変える（`タイトル画面.md`）。操作の割り当ては未対応
- ~~「ゲームをやめる」に確認画面が無い~~ → 2026/10/6 に確かめる画面を付けた
- ~~ホストが「ゲームをやめる」と、参加者は何も起きない（タイトル画面がまだ無い）~~ → 2026/10/6 にタイトル画面ができ、参加者はホストとの通信が切れるとタイトルへ戻る（`SpaceJunkDisconnectWatcher`。ロビーでも試合中でも）
- **音は止まらない。** 音を入れたら、`GamePause` で `AudioListener.pause` も切り替えること
- 通信（マルチプレイ）では、**世界の時間は止まらない**（2026/9/20）。
  止まるのは自分の操作だけで、他の人と物は動き続ける。
  自分だけ時間を止めると、閉じた瞬間に相手が飛んで見えるため
