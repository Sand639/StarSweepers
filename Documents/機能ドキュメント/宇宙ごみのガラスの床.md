## この機能は何か

**踏むと割れて、3秒後に元に戻るガラスの床**を並べたステージ。設計は大槻さんの SVG（`ステージ設計/SVG/アセット 1.svg`、1m＝10px、中心が 0,0）。

| 物 | 大きさ・場所 |
| --- | --- |
| 床 | 36m×30m。北と南に**東西いっぱいのガラスの帯**（幅5m）が2本。帯はそれぞれ 8.5m・19m・8.5m の3枚に分かれていて、1枚ずつ割れる |
| ゴール | 4m×5m。東西の端の真ん中（x=±20） |
| 壁 | 真ん中のスポナーの東西に、3m×10m の壁（高さ2m） |
| 動く壁 | 真ん中の 5m×10m の壁が、**南北に8mずつ往復**する（ガラスの帯の上まで来る） |
| スポナー | 真ん中の 13m×10m。素材5種類・最大10個（爆弾なし） |

---

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| プレイヤーがガラスに乗る | ヒビが入り、ふちが赤く点滅する |
| ヒビが入ってから1秒 | 割れる。乗っていた人や物は下へ落ちる（人は高さ -8m で戻る。物は消えて補充される） |
| 割れてから3秒 | **元に戻る** |

- 割れるのは**プレイヤーが乗ったとき**だけ（物資や爆弾が乗っても割れない）

---

## 使い方

プレハブ **`Assets/Prefabs/GravityRace/GravityGlassFloor.prefab`**（月面運動会のガラスの床。`重い重力で割れるガラスの床.md`）を置き、置いた側で次の値を変えている。**プレハブそのものは変えていない**（月面運動会の動きは同じ）。

| 項目名 | 意味 | STAGE_07 の値（プレハブの値） |
| --- | --- | --- |
| Break Gravity | この重力以上のときに踏むと割れる。**0 にすると、踏んだだけで割れる** | **0**（10） |
| Seconds Until Break | ヒビが入ってから割れるまでの秒数 | **1**（0.5） |
| Respawn Seconds | 割れてから元に戻るまでの秒数。0 なら戻らない | **3**（0） |
| Only Characters | ON なら人だけで割れる | ON |

大きさは Scale の X・Z で変える（厚みは 0.3m。上面が床と同じ高さになるよう、Y は -0.15 に置いている）。
