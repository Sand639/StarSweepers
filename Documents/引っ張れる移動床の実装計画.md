# 引っ張れる移動床の再設計 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `MovableBlock` の既存動作を保ったまま、8方向の柱、場外 Anchor、Player の同時移動、固定地図との衝突除外を持つ Plate 専用システムを作る。

**Architecture:** Block は従来の `MovableBlock`／`MovableBlockPullPoint` に閉じ、Plate は `PullAblePlate` と専用 PullPoint／PassengerArea／Anchor に分離する。Hook の共通経路には Player 別の使用可否を確認する任意インターフェースだけを追加し、Plate は Collider 単位の `Physics.IgnoreCollision` と `CharacterController.Move` で衝突除外と乗員移動を行う。

**Tech Stack:** Unity 6000.3.14f1、C#、Input System、CharacterController、Rigidbody、Unity Test Framework（NUnit）、YAML prefab。

**Spec:** `Documents/機能ドキュメント/引っ張れる移動床の再設計案.md`

## Global Constraints

- Unity は `6000.3.14f1` から変更しない。
- `.unity` Scene は一切変更しない。場外 Anchor は prefab の作成までとし、配置は担当者が行う。
- `Assets/` 以下のファイルを OS 操作で移動・リネーム・削除しない。既存フォルダだけを使う。
- `Assets/` 以下の新規ファイル名は半角英数字にする。
- `MovableBlock.prefab` の操作感、移動距離、Front／Back／Left／Right の動作を変えない。
- `PullAblePlate.prefab` は既存 Scene の位置・大きさ override を壊さない。
- Plate のネットワーク同期は今回の対象外。現在と同じローカル動作に限定する。
- Prefab を変更したこと、ネットワーク同期が未対応であることを最終報告する。

## Review Focus

- Player が Anchor のゲージ中に Plate から降りた場合、Plate を動かさず Hook を解除する。Task 4 のテストで固定する。
- OFF の柱は見えず、Collider も Hook 判定も無効になる。Task 3 と Task 6 のテストで固定する。

- 後から有効化された Plate／固定 Collider も、移動開始前の更新で衝突除外される。Task 5 のテストで固定する。
- Anchor と Plate の水平位置が同じ場合、ゼロ方向として移動を開始しない。Task 4 のテストで固定する。
