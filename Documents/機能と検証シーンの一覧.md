# 機能と検証シーンの一覧

**いまプロジェクトにある機能を、1枚で見渡すための早見表。**

機能ドキュメントが増えて、「何があるのか」「どのシーンを開けば試せるのか」が
ファイルを1つずつ開かないと分からなくなってきたため作った（2026/9/14）。

- 詳しい中身は、各行の「ドキュメント」列のファイル（`機能ドキュメント/` の中）を読むこと。
- **機能を追加したら、ここにも1行足す。** 状態が変わったら書き換える。
- 「状態」は、**人が実際に遊んで確かめたかどうか**を基準にしている（AIはUnityの再生で操作を確かめられないため）。

## Unityのメニュー（`Tools > StarSweepers`）

**いま作っている2つの遊び（釣り・宇宙ごみ集め）は直下に、それ以外は `アーカイブ` の中に
ゲームごとに分けてある**（2026/9/20。メニューが30個に増えて探しにくくなったため）。

> ⚠️ **「作り直す」と付いているものは、手で調整した内容が消える。** 押す前に確かめること。

### 釣り（直下）

| メニュー | 何をするか |
| --- | --- |
| `釣りフックの検証シーンを作る` | フックの操作だけを試す基本のシーン |
| `釣りフックのステージ検証シーンを作る` | 壁とゴールのあるステージのシーン |
| `釣りの障害物の検証シーンを作る` | 動く障害物を試すシーン |
| `釣りのオンライン用シーンを作る（ロビー＋会場）` | ロビーと会場。**オンラインはここから** |
| `釣りのスポナーを作る（ステージ検証＋オンライン会場）` | 物資と爆発物を降らせる係を組み込む |
| `釣りの新しいマップを作る（オンライン）` | 床・壁・ゴールだけの**まっさらなマップ** |
| `釣りの対戦用マップを作る（大きな遮り）` | **対戦用に形を作り込んだマップ** |
| `釣りのマップをビルドの一覧に登録し直す` | マップの名前を変えた・複製したあとに押す |
| `開いている釣りマップを点検する` | 今開いているマップに足りない物が無いか調べる |
| `釣りのオンライン検証用のビルドを作る` | `StarSweepers/Build/FishingOnlineTest/` に4人で試す `.exe` |
| `釣りのアンカー検証シーンを作る` | 青いキューブの固定アンカーを置いた検証シーンとプレハブ |
