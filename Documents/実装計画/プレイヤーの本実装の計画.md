## 大きな方針

- **今あるプレイヤー（`SpaceJunkPlayer` / `FishingOnlinePlayer`）と、その部品（`HookController` / `ThrowController` など）には手を入れない。**
  `ThrowController` は 2584 行あり、釣り・宇宙ごみ・ボット・通信・横取り・重い物・大型物件が入り組んでいて、
  他の人（鈴木さんなど）も触っている。分岐を足すと今の機能を壊しやすいので、**新しい部品を別のファイルで作る。**
- 新しい部品の名前の頭には **`Sweeper`** を付ける（作品名 StarSweepers から）。
- まずは**通信なし・専用の検証シーンだけ**で作る（`Assets/Scenes/Test/SweeperPlayerTest.unity`。メニューから作り直せる形）。
  宇宙ごみの試合やオンラインへの組み込みは、人が遊んで確かめたあとの別の段階でやる。
- そのまま使う今の部品：`HookableObject`（引っ掛けられる物の目印）、`ThrowPassThrough`（投げた物が自分に当たらない）、
  `LiquidBeam`（光線の見た目）、`SpaceJunkTeams.TeamColor`（チームの色）、`PlayerInputSource`（席ごとの入力）、
  `GamePause`、`PlayerStun`、`UiFont`、`TopDownCameraFollow`

## 部品

| 部品 | 役割 |
| --- | --- |
| `SweeperPlayer` | まとめ役。**名前とチーム**を持ち、リング・名前・狙いの帯・光線・カーソルに色を配る。ロビーから名前を受け取る入口（`SetProfile(名前, チーム)`） |
| `SweeperMover` | 移動（左スティック／WASD、カメラの向き基準）。**移動方向へ向き直す**。狙っている間は狙う方向を向く。外から「動けない」にできる |
| `SweeperAim` | 狙う向き。マウスは**プレイヤー中心の半径1mの円の中だけ動く仮のカーソル**（Windows のカーソルは隠す）。右スティックは倒した方向 |
| `SweeperRing` | 足元のリング。形は 円／三角／四角／星／六角形。チームの色。自作シェーダー `SweeperRing.shader` で形を計算して描く |
| `SweeperAimArea` | 狙っている間、リングの縁から狙う方向へ矢印の帯（AOE）を伸ばす。矢印は長さに合わせて繰り返す（UV×回数） |
| `SweeperShooter` | 長押しで溜める → 離すと光線が伸びる → 当たれば巻き取りへ／外れれば戻る。動けない時間の管理 |
| `SweeperReel` | 巻き取り。床に置いたまま一定時間（初期値1.5秒）で手前へ。途中で押す＝後ろへ投げる／押さない＝前へ投げる／決まった瞬間に押す＝クリティカル |
| `SweeperNameTag` | 頭の上の名前（チームの色） |
| `SweeperAnimation` | 発射の瞬間に `A_SHOOT`、終わったら `A_AIM_01`。Animator が無いうち（カプセルのうち）は何もしない |

## 決まったこと（2026/10/27・小野田さん）

| 問い | 決まったこと |
| --- | --- |
| 狙いの帯（AOE）の長さ | **押すと最短の長さから、押している間に最大まで伸びる。** 最短・最大・溜める時間はインスペクターで変えられる。離したときの長さまで光線が伸びる |
| 狙っている間の体の向き | **狙っている間は狙う方向を向き、それ以外は移動方向を向く** |
| 動けない時間 | **離した瞬間から、投げ終わる（外れたら光線が戻りきる）まで動けない。** 狙っている（押している）間は動ける |
| 後ろへ投げる動き | **投げる瞬間の位置から、プレイヤーの頭を越える放物線を描いて後ろへ飛ぶ** |
| 前へ投げる動き | （おすすめで決定）床すれすれに前へ飛ばす |
| 引っ張れる物 | **まずは今の物資（`HookableObject`）だけ。** 重い物・大型物件は後で |
| 狙いの帯の色 | 仮素材 `004_狙う` は小野田さんの物で、変更してよい。**色を抜いた白い版を作り、プログラムでチームの色を付ける** |

## AIが決めたこと（変えたければ言ってもらう）

- **巻き取り中は向きだけ変えられる**（移動はできない）。「前へ投げる」は**投げた瞬間に向いている方向**へ飛ぶ。
- 巻き取りの途中で押したのが**クリティカルの受付時間の外**なら、ふつうの「後ろへ投げる」。1回押したらそれで決まる（連打で当てられない）。
- **クリティカルの合図**：受付が始まった瞬間に、物資の足元に光の輪が広がる。その間に押せばクリティカル（もう一度強く光り、遠くまで飛ぶ）。
  合図のエフェクトは**プレハブを差し替えられる**（空なら仮の光の輪を出す）。
- 光線が壁（引っ掛けられない物）に当たったら、そこで戻り始める。
- リングは体と一緒に回る（三角などで前が分かる）。インスペクターで止められる。
- リングは床の少し上に板を置いて描く。床の中から直接描く（URP のデカール）方法は、全員共通の描画設定（`PC_Renderer`）を変える必要があるので**今回はやらない**（大槻さんの判断が要る）。
- 置き場所：スクリプトは `Assets/Scripts/Player/`、シェーダーは `Assets/Art/Shaders/`、画像は `Assets/Art/Sprites/`、
  マテリアルは `Assets/Art/Materials/`、プレハブは `Assets/Prefabs/Common/SweeperPlayer.prefab`。**新しいフォルダは作らない。**

## 素材

- 仮素材 `共有フォルダ/20_デザイン素材/10_画像素材/仮素材/004_狙う/` に、色を抜いた版 `E_AIM_LENGTH_00_01.png`（繰り返す部分）・`E_AIM_LENGTH_00_02.png`（先端）を足した。
  オレンジの塗りを白にし、白はそのまま、黒の縁は黒のまま。
- 同じ物を `Assets/Art/Sprites/AimLengthBody.png`・`AimLengthTip.png` として入れた（ゲームではこちらを使う）。
- **白い版に色を掛けるので、もとの絵の「白い内側の矢印」もチームの色になる**（塗りと区別が付くのは黒の縁だけ）。
  白いまま残したくなったら、内側だけ別の色（例：灰色）にした画像を作り、シェーダーで塗り分ける。
