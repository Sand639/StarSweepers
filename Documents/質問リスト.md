# 質問リスト

急ぎではないが、**大槻さん・サブリーダー・プロジェクトリーダーに聞きたいこと**を書き溜めておく場所。

- 誰でも書いてよい。AIが代わりに書き足してもよい。
- 急ぎの質問は、ここではなく**チームDiscord**で聞くこと。
- 回答がついたら、状態を「回答済み」に変える。行は消さない（同じ疑問を持つ人の助けになる）。

## 書き方

下の「一覧」の表に、1行足すだけでよい。各列の意味は次のとおり。

| 列 | 何を書くか |
| --- | --- |
| 日付 | 質問を書いた日 |
| 質問した人 | 自分の名前。AIが代わりに書いた場合は「Claude Code」「Codex」など |
| 宛先 | 下の対応表から選ぶ |
| 質問 | 聞きたいこと。**背景も1行添える**と回答が早い |
| 回答 | 回答をもらったら書く。書くのは回答した人でもAIでもよい |
| 状態 | `未回答` ／ `回答済み` ／ `保留` |

**宛先の選び方**

| 聞きたい内容 | 宛先の書き方 |
| --- | --- |
| Git・GitHub、AI（Codex / Claude Code）、技術的な方針 | `大槻` |
| 企画・仕様の方針 | `サブリーダー` |
| デザイン・グラフィックの方針 | `プロジェクトリーダー` |

> 「リーダー」とだけ書くと**サブリーダーと紛らわしい**ので、デザイン系の宛先は `プロジェクトリーダー` と書く。
