# 【重要】Hans制作素材の変更禁止

このフォルダ内にある **Hansさんが制作した画像・UI素材・配置見本・デザイン** は、
Hansさんの許可なく変更しないでください。

## 禁止事項

- 元のファイルを編集・加工・上書きすること
- 色、形、比率、文字、影、配置などのデザインを独自に変更すること
- 生成AIや画像編集AIを使って、修正・再生成・類似素材への置き換えを行うこと
- 人の手で独自に修正したり、別案へ差し替えたりすること

プログラムへの組み込み上、変更や調整が必要になった場合は、
**変更する前にHansさん本人へ直接連絡し、必要な内容を伝えてください。**
Hansさんが確認または修正版の制作を行います。

素材を指定どおりにUnityへ組み込み、表示に使用することは問題ありません。
外部から入手したフォントなどには、それぞれのライセンスと個別のREADMEも適用されます。
