# フォントの使い方

> **【重要】Hansさんが指定したUIデザインや使い方を、本人の許可なく変更しないでください。**
> 人の手でも生成AIでも独自に変更せず、変更が必要な場合は、作業前にHansさん本人へ直接連絡してください。
> フォントそのものには、付属のライセンス条件も適用されます。

## UIで基本的に使うフォント

ゲーム内のUIテキストには、基本的に **HarmonyOS Sans Black**
（`HarmonyOS_Sans_SC/HarmonyOS_Sans_SC_Black.ttf`）を使用する。

このフォントをゲーム内で使用したときは、**どこで使ったかをHansさんに伝えること。**
画面、シーン、プレハブ、UIの名前など、使用箇所が分かるように伝える。

## 今後追加するフォント

このフォルダには、今後さらにフォントが追加される予定。
現在入っているフォントだけで最終決定だと考えず、新しいフォントが追加されていないか確認すること。

配布されたフォントファイルは改変せず、付属のライセンス情報も一緒に残すこと。
