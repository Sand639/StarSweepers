# カウントダウンUIの配置見本

> **【重要】Hansさんが制作した画像・UI素材・配置見本は、本人の許可なく変更しないでください。**
> 人の手でも生成AIでも、編集・加工・再生成・差し替えを行わないでください。
> 変更や調整が必要な場合は、作業前にHansさん本人へ直接連絡してください。

このフォルダの画像は、カウントダウンUIを**画面のどこに、どのくらいの大きさで表示するか**を伝えるための見本です。

## 実装するときの注意

- `Screen_Preview/` の画像は配置確認用です。ゲーム内にそのまま表示しないでください。
- 実際のゲームでは、隣の `Countdown/` フォルダにある背景が透明な画像を使用してください。
- 数字と `START!` は画面の中央に表示してください。
- 白い文字と、右下へずれた黒い影の見た目を保ってください。
- 画像の縦横比を変えないでください。
- 実装上の都合で位置、大きさ、色、影などを変える必要がある場合は、変更する前にHansさんへ伝えてください。
